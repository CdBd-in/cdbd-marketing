## 4. 발견·해결한 사고

### 사고 #1 — A1 DECO placeholder 점선 노출 (해결, 룰 정착 후보)

**증상**: A1 (`477:366`) 빌드 후 1차 검수에서 우상단에 빈 점선 사각형 노출. 시안 노이즈.

**원인**: A 상단·서브 슬롯(`338:3131`)에 박혀있는 DECO placeholder frame(`246:3` 또는 clone 후 `477:371`)이 자동화의 `bringDecoToTop` 함수에서 인식되지 않음. 함수는 `name === "crown"|"envelope"|...` 필터만 적용 → placeholder는 비어있는 frame이라 name 매칭 ❌ → fills/strokes도 안 비워짐 → 점선만 노출.

**해결** (fix call): placeholder frame이 비어있고(자식 0개) 작은 크기(<100×100)일 때 paper IMAGE FIT으로 채워서 데코로 활용. 빈 placeholder가 시각 노이즈가 되는 문제 + 데코 추가 두 가지를 동시에 해결.

**룰 갱신 후보** (P1):
- [[2. 자동화 체크리스트]] §자주 놓치는 #12 보강 — "DECO placeholder 빈 frame은 fills/strokes 비우거나 자산으로 채워야 함. `bringDecoToTop` 함수는 name 매칭 외에 'placeholder 작은 frame' 위치 fallback 필요"
- [[1-2-1. 레이아웃 규칙]] §2.4 — A 상단·서브 슬롯 338:3131의 DECO placeholder 자동 정리 표준 추가

### 사고 #2 — A2 DECO 누락 (해결, 룰 정착 후보)

**증상**: A2 (`477:375`) 빌드 후 검수에서 mockup 1개만 시각 무게 → A1·D1·D2 4안 모두 데코 있는데 A2만 없음 → 다양성 ❌.

**원인**: A 하단·서브 슬롯(`338:3107`)은 DECO placeholder 자체가 없음 (가이드 §2.4 표 "❌ 없음 / 자동화가 동일 좌표로 신규 생성"). 빌드 코드의 `applyMockup` + `bringDecoToTop`만으로는 DECO 신규 생성 로직이 빠져있음 — VIP A2 사례에서 envelope IMAGE FIT 신규 생성으로 해결한 패턴을 이번 빌드 코드가 누락.

**해결**: fix call에서 `figma.createFrame()`으로 75×75 frame 신규 생성 → x503.5/y58.5 위치 (A1과 동일 좌표) → wallet IMAGE FIT fill. VIP 사례 패턴 그대로 복제.

**룰 갱신 후보** (P1):
- [[2. 자동화 체크리스트]] §자주 놓치는 추가 — "A 하단·서브 슬롯 338:3107은 DECO placeholder 없음 → 자동화가 신규 생성 분기 필수. VIP A2 envelope + ROI A2 wallet 2회 반복된 사고 → 빌드 코드에 'A 하단 = DECO 신규' 기본 분기 박아야 함"
- [[1-2-1. 레이아웃 규칙]] §2.4 표 보강 — A 하단 데코 신규 생성 표준 좌표 명시
