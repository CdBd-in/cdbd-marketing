## 1. 대표 — 3단 (폰 3대) `347:2809` ⭐

> 같은(또는 연관) viewer 페이지를 폰 3대로. 중앙 폰 elevation(위로 올림). 글 도입 대표 비주얼.

**구조 — 폰=고정 / 화면=교체**

| 슬롯 | 폰 프레임 | 화면(교체) rect | 비고 |
|---|---|---|---|
| 좌 | `358:2081` @133,216 513×1068 | `363:1577` (481×1036, ar 0.464) | 고정=`iphone 1` 베젤 |
| 중앙 | `358:2084` @710,86 | `363:1579` | elevation(위로) |
| 우 | `358:2087` @1287,216 | `363:1581` | |

- 🔄 **교체** = 각 폰 안 `Frame 427324063 > rounded-rectangle`(스크린샷) IMAGE fill. aspect 0.464 → identity transform 왜곡 0.
- 🔒 **고정** = `iphone 1` 베젤(그림자 베이크). 텍스트 노드 없음 — 화면이 곧 메시지.
- 🔴 **3폰 같은 캡처 복붙 ❌** — viewer를 사람처럼 읽어 **3개 의미 섹션**(또는 다른 페이지)을 각 폰에 ([[1-2-3. 이미지 제작 가이드]] §2.1).

## 2. 모바일+데스크탑 `358:2034` (#기능+페이지)

> 폰(좌) + 노트북(우)을 나란히 — "모바일에서도, 데스크탑에서도" 또는 기능 설명 맥락.

| 슬롯 | 디바이스 프레임 | 화면(교체) | 비고 |
|---|---|---|---|
| 폰 | `358:2075` @120,115 466×970 | `363:1583` (436×1027) | 고정=`iphone 1` |
| 데스크탑 | `358:2078` @646,115 1590×970 | `363:1586` `image 317` (1303×842) | 고정=`macbook 1` |

- 폰 화면(세로 ar) + 노트북 화면(가로 ar)은 **다른 캡처** — 폰=viewer 모바일, 노트북=같은 페이지의 데스크탑 뷰 또는 에디터.
- 변형 1/2/3(`358:2034`/`357:1964`/`347:2821`)은 배치 미세차 — 본문 소재에 맞는 것 픽.

## 4. 서비스 페이지 (#서비스페이지) — 통계 요약 `347:3656` · 제출된 답변 `347:3658`

> 폰 목업이 아니라 **CdBd 관리·서비스 화면**(통계 대시보드·응답 집계 등)을 **마킹 없이 그대로** 보여줌. 정사각 1000×1000, 화면 1장이 곧 메시지. ⑥ 기능 출시·④ 비용·효과 글에서 "이런 화면이 제공된다"를 담백하게 보여줄 때.

| 템플릿 | 노드 | 화면(교체) rect | 보여주는 것 |
|---|---|---|---|
| 통계 요약 | `347:3656`(S) | `347:3657` `image 125` (866×728) | 페이지뷰·클릭수·클릭률 + 라인차트 |
| 제출된 답변 | `347:3658`(S) | `347:3659` `image` (1056×798) | 응답 집계(파이차트·경로별 답변) |

- 🔄 **교체** = 프레임 안 `rounded-rectangle`(스크린샷)에 통계/응답 화면 캡처 IMAGE fill. 🔒 라운드 카드 BG·여백은 고정.
- 🔴 **강조와 구분**: 화면을 **그대로** 보여주면 기본(#서비스페이지) / **핵심지표를 확대·마킹**하면 **② 강조**([[1-2-1-3. 강조]]). "어느 수치가 핵심인지"를 짚어야 하면 강조로.
- 자산: 통계·응답 화면은 컴포넌트/캡처 재사용 ([[1-2-3. 이미지 제작 가이드]] §1).

## 🔴 원칙

- **강조 장치 금지** — 마킹 박스·확대 크롭·커서·퍼플 pill을 넣는 순간 **② 강조**다. 기본은 깨끗한 목업만.
- **라벨 최소** — 화면만으로 명확하면 텍스트 없음(전 유형 공통, [[1-2-1-1. 공통]] §2).
- **캡처 aspect = 슬롯 aspect** (폰 0.464) → identity transform, 왜곡 0. ([[1-2-3. 검수 체크리스트]])
