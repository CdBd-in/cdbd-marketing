## 1. 강조 장치 — 3종 (이 유형의 정체성) ⭐

> 화면은 평범하게 깔고, **아래 장치로 "어디를 보라"를 만든다.** clone하면 스트록·데코가 함께 상속 — 직접 그리지 말 것.

| 장치 | 용도 | 시각 |
|---|---|---|
| **퍼플/블루 마킹 + pill + 커서** | 버튼·액션(클릭) 강조 | 강조 영역 박스 + 떠 있는 **퍼플 pill 라벨** + **손 커서**(클릭일 때만) |
| **그린 대시 마킹 박스** | **기능 영역·데이터 주입 위치** 표시 | 디자인 보드 패널/개인화 필드를 그린 대시로 감쌈 |
| **확대 크롭 오버레이** | 화면 속 핵심부를 잘라 키워 얹음 | 흰 카드 + 보더 + 그림자로 "떠 보이게" |

- 🔴 **한 이미지 = 한 강조** — 강조가 두 곳이면 메시지가 분산. 핵심 1곳만.
- pill 카피 = **화면이 하는 일 한 줄 명사형** ([[1-2-2-3. 텍스트 작성 가이드]]). 자명하면 생략.

## 3. 대표 — 개인화 데이터 `363:1541` (#데이터 #개인화)

> 폰 3대, 각 화면의 **개인화 필드(이름·호칭)** 를 **그린 대시 박스**로 마킹 — "이 자리에 고객별 데이터가 꽂힌다".

| 폰 | 화면 rect | 그린 마킹 박스 |
|---|---|---|
| 좌 `363:1542` | `363:1557` | `363:1567` `Rectangle 9` @222,756 335×94 |
| 중앙 `363:1545` | `363:1553` | `363:1560` @763,200 407×82 |
| 우 `363:1548` | `363:1555` | `363:1569` @1359,801 369×49 |

- 🔄 화면 = 개인화된 초대장/페이지 캡처(이름이 보이게). 🔒 그린 마킹 박스는 **개인화 값 위치에 맞춰 이동만**(스타일 고정).
- 3폰 = 서로 다른 고객/페이지 변형(같은 캡처 복붙 ❌).

## 🔴 원칙 · 검수

- 강조 없으면 **① 기본**, 강조가 생기면 **② 강조**. 둘의 분기 = "콕 집어 설명하나?".
- 마킹 박스·커서·확대 크롭·pill은 **clone으로 상속** — raw 프레임에 직접 그리지 말 것(스트록·섀도 누락 사고).
- 통계/대시보드 화면을 강조할 땐 **핵심지표(1위 등) 확대** 필수 — 단순 캡처 ❌. ([[1-2-3. 검수 체크리스트]] TOP)
