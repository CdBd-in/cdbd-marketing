**두 변형**

|---|---|---|---|---|

- **화면 fill**: 3폰 = **같은 페이지의 다른 버전**(같은 캡처 복붙 ❌은 아니지만, 버전 차이를 배지·수정 마킹으로 드러냄). 원페이지 목업 규칙([[1-2-2-2. 이미지 제작 가이드]] §2.0a) 적용.
- **배지 교체**: pill 텍스트를 게시 시각(`2026.05.10 게시` 등)으로 교체 가능.

### 🔴 수정 마킹 박스 = 페이지 배경색 + 가상 수정 텍스트 (2026-07-01 확정)
> 버전 누적 이미지에서 "이 버전에서 **무엇이 바뀌었나**"를 보여주는 마킹. **실제로 화면 픽셀을 바꾸지 않고**, 변경 지점에 박스를 얹어 **가상의 수정 내역 텍스트**를 넣는다.
- ❌ (구) 투명 대시 박스만 얹어 밑 콘텐츠가 비쳐 "빈 표시"만 됨.
- ✅ (신) 마킹 박스의 **fill = 그 화면(페이지)의 배경색과 동일** → 밑 콘텐츠를 깔끔히 덮음 → 박스 안에 **가상의 수정된 텍스트 내역**(예: 바뀐 장소·직함·구성)을 입력. 옆에 `○○ 수정` 퍼플 태그 유지.
- 페이지 배경색은 화면마다 다름(초대장=크림/베이지, 명함=네이비 등) → 해당 화면 배경색을 스포이드로 맞춘다.
