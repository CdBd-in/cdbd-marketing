> **언제**: 카테고라이징 · 조건/유형/타겟 분류 · 사례 나열 · "이 페이지는 이런 카드로 구성된다".

## 1. 카테고라이징 (세로 컬럼) `347:3473` ⭐

> 세로 구분선으로 컬럼을 나누고, 각 컬럼 = 번호 + 유형명 + 3D 아이콘들.

**구조 — 컬럼 3개(각 597×1000)**

| 컬럼 | 프레임 | 번호+타이틀 text | 아이콘 그룹 |
|---|---|---|---|
| ① 영엽형 | `373:2311` @60,100 | `373:2326` "➊ 영엽형" | `373:2494`(아이콘 2개) |
| ② 전시형 | `373:2327` @662,100 | `373:2342` "➋ 전시형" | `373:2505` |
| ③ 정기배포형 | `373:2306` @1263,100 | `373:2309` "➌ 정기배포형" | `373:2305`(3개) |

- 🔄 교체 = 각 컬럼의 **타이틀 text**(`➊ 유형명`) + **3D 아이콘**(`Frame 4273239xx` 안 라벨 pill + 아이콘). 컬럼 수는 본문 항목 수(2~4)에 맞춤.
- 🔒 고정 = `Group 1818` 그리드 배경 + 컬럼 구분선 `Vector 120`.
- 항목당 **3D 아이콘 + 검정 라벨 pill**(예: "B2B 산업재"·"VIP 마케팅"). 아이콘은 thiings에서 항목 의미에 맞게 ([[1-2-3. 이미지 제작 가이드]] §4).

> 십자 분할 2×2, 중앙에 개념 pill, 사분면마다 라벨 + 3D 아이콘.

| 영역 | 레이어 |

- 🔄 중앙 pill = 묶음 개념(N조건/N유형), 사분면 = 4개 동등 항목(라벨 + 3D 아이콘). 항목 4개 정형.

## 3. 카드 구성 (카드 쌓기) `347:3604` (S)

> 한 페이지를 이루는 **카드들**을 겹쳐 쌓아 보여줌 — "이 페이지 = 제품상세 + 제품영상 + 상담문의".

| 레이어 | 처리 |
|---|---|
| 스크린샷 카드 `347:3645`·`347:3646`·`347:3647` (겹침 배치) | 🔄 각 카드 화면 캡처 IMAGE fill |
| 라벨 pill `347:3649` "제품 상세" · `347:3651` "상담 문의" · `347:3653` "제품 영상" (퍼플) | ✏️ 카드명 교체 |

- 🔄 카드 = 실제 viewer의 카드 영역 발췌. 라벨 = 카드 종류명(퍼플 pill).

## 🔴 원칙 · 검수
- **동등 위계** — 한 항목만 크게/강조하면 ④ 나열이 아니라 ② 강조. 모든 항목 같은 비중.
- **3D 아이콘은 항목 의미와 일치** — 엉뚱한 아이콘 ❌. 소싱 thiings([[1-2-3. 이미지 제작 가이드]] §4).
- 라벨 = 공통 명사 골격으로 병렬([[1-2-4. 텍스트 작성 가이드]]).
- 그리드 배경·구분선은 **고정**(clone 상속) — 직접 그리지 말 것.
