# ⑤ 프로세스

> 🎯 **플로우·사용법을 순서대로 도식화.** 트리(분기) 또는 step별 가이드로, 다소 복잡한 기능을 이해시킨다.
> **언제**: 개인화 데이터 흐름 · 복사본 공유 · 개별 URL 일괄 생성 · "1→2→3 사용법".
> ⬆️ 개요 [[1-2-1-1. 공통]] · 캡처·자산 [[1-2-3. 이미지 제작 가이드]] · 카피(단계 라벨) [[1-2-4. 텍스트 작성 가이드]]

## 0. 하위 유형 — 두 가지 도식 골격

| 하위 | 골격 | 템플릿 · 노드 |
|---|---|---|
| `#기능 #사용법 #가이드` | **스텝형** (Step.1→2→3) | **사용법 `347:3268` ⭐** |
| `#플로우` | 플로우(흐름) | 복사본 공유 `347:4193` |
| `#일괄 #개별 #개인화` | **트리형** (분기) | **개인화 URL `347:4251` ⭐** · 개별 URL 일괄 생성 `347:4341` |

> 공통 자재: 그래프지 그리드 배경(고정) · 상단 타이틀(Bold) · 퍼플 pill · 화살표/커넥터 vector(검정).

## 1. 스텝형 — 사용법 `347:3268` ⭐

> 상단 타이틀 + `Step.1 → Step.2 → Step.3` 가로 나열. 각 스텝 = pill + 화면(+커서) + 하단 라벨.

**구조 (1920×1200)**

| 요소 | 레이어 |
|---|---|
| 타이틀 | `347:3276` "개인화 메시지 사용법" (Bold) |
| Step.1 | 프레임 `377:4701` · pill `377:4740` · 하단 라벨 `377:4749` "목적별 템플릿 선택" · 콘텐츠 `Templates` 인스턴스 `377:5000`·`377:5003` + 커서 `377:4966` |
| Step.2 | `377:4717` · pill `377:4737` · 라벨 `377:4747` "엑셀 명단 업로드" · `Card-Dropdown` `377:4809` + 커서 `377:4832` |
| Step.3 | `377:4685` · pill `377:4734` · 라벨 `377:4745` "개별 URL 배포" · `Modal/Alert/Icon` 인스턴스 `377:4935` |
| 스텝 간 화살표 | `377:4681`·`377:4753` (→) 🔒 |

- 🔄 교체 = 각 스텝 **콘텐츠**(화면 크롭·에디터 컴포넌트·모달 인스턴스) + **하단 라벨**(단계명) + 클릭 단계 **커서**.
- 🔴 **스텝 3개 권장**(4개까지). 각 스텝 다른 화면(같은 캡처 복붙 ❌). 클릭 단계만 커서, 입력·확인 단계는 커서 `remove()`.
- 단계 라벨 = 동사형 짧게("목적별 템플릿 선택"·"엑셀 명단 업로드"·"개별 URL 배포"), 병렬 골격 ([[1-2-4. 텍스트 작성 가이드]]).

## 2. 트리형 — 개인화 URL `347:4251` ⭐

> 상단 타이틀 + 기준 URL pill → 분기 커넥터 → 다중 노드(고객별 전용 링크).

**구조 (1920×1200)**

| 요소 | 레이어 |
|---|---|
| 타이틀 | `347:4339` "고객 1명만을 위한 '개인화 마케팅' 실현" |
| 기준 URL pill | `347:4292` "https://cdbd.in/brand/ **26spring**" |
| 중간 라벨 | `347:4332` "고객별 '전용 링크' 활성화" |
| 분기 노드 4개 | `347:4295` 그룹 — A/B/C/D 고객 각 (배지 라벨 `3회 방문`·`VIP`·`신규 고객`·`재방문 유도` + 이름 pill + `…26spring/01~04`) |
| 커넥터 | `347:4335`·`347:4336`·`347:4338` 등 (검정 직각 분기) 🔒 |

- 🔄 교체 = 타이틀·URL·노드 라벨/이름/번호 텍스트. 노드 수는 본문 케이스 수.
- 🔒 고정 = 그리드 배경 + 직각 분기 커넥터(수직/수평만, 사선 ❌).

## 🔴 원칙 · 검수
- **순서/분기가 핵심** — 화면을 그냥 나열만 하면 ① 기본·④ 나열. 화살표·트리로 **흐름**을 보여야 ⑤ 프로세스.
- 커넥터·화살표 = **수직·수평만**, 검정. clone으로 상속(직접 그리지 말 것).
- 스텝 콘텐츠는 에디터 컴포넌트·모달 인스턴스를 DS에서 ([[1-2-3. 이미지 제작 가이드]] §1).
- 단계마다 **다른 화면/상태** — 같은 캡처 반복 ❌. ([[1-2-3. 검수 체크리스트]])
