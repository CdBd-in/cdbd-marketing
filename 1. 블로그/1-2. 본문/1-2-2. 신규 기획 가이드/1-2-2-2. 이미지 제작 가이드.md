## 2. 목업 화면 소싱 (폰/데스크탑 화면 rect에 넣는 것) ⚡

> 목업 프레임의 화면 rect에 채울 픽셀을 **어디서 캡처하나.**
> 🔴 **2026-06-30 기준 — 기본 소스**: 모바일 = **`cdbd.in/templates` 템플릿 미리보기 영역**(§2.0a) · 데스크탑 = **템플릿 상세 / 디자인 파일**(§2.0b).

### 2.0a. 🔴 모바일 목업 (2026-06-30 신규 기준 — 이 규칙이 우선)

> 예시 — 블로그 이미지 파일 모바일 목업 노드 `358:2090`. "phone" 그룹 안에 **오토레이아웃 프레임**이 있고, 그 안에 CdBd 페이지 스크린샷이 **width=fill**로 들어간다.

- **오토레이아웃 align (반복 실수 지점 ⚠️)**: **원페이지 = `align=top`**(최상단부터 보이게) / **멀티페이지 = `align=center`**(가운데 정렬).
- **캡처 시작점**: 원페이지 내 특정 카드, 멀티페이지 내 특정 페이지를 강조하는 게 **아니면** → 각 페이지의 **시작 부분**을 캡처(**원페이지=최상단부터 / 멀티페이지=1페이지**).
- **이미지 출처**:
  - **특정 콘텐츠를 가리키는 게 아니면** → 적합한 주제의 **템플릿 미리보기 영역**을 캡처. 템플릿 목록 = `https://www.cdbd.in/templates`.
  - **미리보기 영역** = 각 템플릿 상세(`.../templates/{slug}`) 페이지의 **우측 목업 프레임 내부 영역**. **개발자도구로 상단 `border-radius:0`·`border:none` 처리** 후 **내부 콘텐츠 영역만 정확히** 스크린샷.
  - 특정 콘텐츠(실제 브랜드 페이지)를 보여줄 땐 → 그 **공개 페이지를 직접 캡처**(이미 실데이터). 그 외에는 위 템플릿 미리보기.
- 슬롯 aspect(폰 ≈ **0.464**) 일치 → identity transform, 왜곡 0.

## 5. 캡션 → 빌드 플랜 (목적·템플릿·트랙) ⭐

> 🔑 **본문에는 이미지 자리마다 `*캡션*` 마커가 이미 박혀 있다.** (`*…*` 줄 = 이미지 위치 + 그 자리에 들어갈 이미지의 내용.) 그래서 "글을 분류해 몇 장 찍을지"를 추론하지 않는다 — **캡션 1개 = 이미지 1장**으로 확정하고, 각 캡션을 읽어 **목적·템플릿·트랙만** 정한다.
> - 절차: ① 본문에서 `*캡션*` 자리 추출(= 이미지 위치·개수 확정) → ② 캡션 메시지 1줄 해석 → ③ **목적 1개**([[1-2-1-1. 공통]] §1 라우팅) → ④ 템플릿·트랙 → ⑤ 빌드 플랜(출력 스키마).
> - **캡션이 없는 자리엔 이미지를 만들지 않는다.** 위치·개수·삽입 여부는 글쓴이가 캡션으로 이미 결정했다.
> - 🔴 **같은 목적 2장+ 쓰면 자산 차별화** — 3D 오브젝트는 다른 아이콘, 목업은 다른 페이지/카탈로그. ([[1-2-3. 검수 체크리스트]])

### 5.1. 캡션 메시지 → 목적 → 템플릿 (자동 결정)

| 캡션이 말하는 것 | 목적 | 대표 템플릿 노드 | 트랙 |
|---|---|---|---|
| 결과 페이지/사례를 그냥 보여줌 · 통계·응답 화면 담백히 | **① 기본** | 3단 `383:5912` · 모바일+데스크탑 `383:6634` | 합성 |
| 특정 버튼·기능·데이터를 콕 집어 설명 | **② 강조** | 버튼 강조 `383:5907` · 개인화 데이터 `383:5925` | 합성 |
| 기존 vs CdBd / 비용 대비 | **③ 비교** | 키워드 하단 `383:5699` · 비용 저울 `383:6415` | 합성 |
| 유형·조건·카테고리·카드구성 나열 | **④ 나열** | 카테고라이징 `383:6048` · 그리드 `383:6354` | 합성 |
| 사용법·플로우(1→2→3, 트리) | **⑤ 프로세스** | 사용법 `383:5752` · 개인화 URL 트리 `383:5786` | 합성 |
| 현장 실사진 | (실사진) | — | 소싱 |
| 경쟁사·외부툴·인스타 캡처 | (외부캡처) | — | 캡처 |

- **목업 화면 소싱**: **§2 목업 소싱** — 모바일=`cdbd.in/templates` 미리보기(주제 맞는 템플릿), 데스크탑=템플릿 상세/디자인 파일. 특정 브랜드 콘텐츠면 그 공개 페이지 직접 캡처.
- **에디터 컴포넌트 결정**: **§1 에디터 자산** 키워드표 → 없으면 §3.

### 5.2. 출력 스키마 (per 이미지)
```json
{
  "order": 1,
  "section": "도입부",
  "purpose": "기본",
  "size": "1920x1200",
  "templateNodeId": "383:5912",
  "captureSource": { "kind": "template-preview", "ref": "templates/{slug}", "pages": 3 },
  "replace": { "screens": ["page:1","page:2","page:3"], "texts": [], "icons": [] },
  "track": "composite"
}
```
→ 글 1편 = 이 객체의 배열(캡션 순서 = order). **합성(composite)**은 곧장 fill 파이프라인(§1~§4), **캡처/소싱**은 사람·스크래퍼 큐로 분기(§6).
