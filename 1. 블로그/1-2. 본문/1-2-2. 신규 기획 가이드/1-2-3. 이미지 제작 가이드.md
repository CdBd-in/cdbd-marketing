## 2. viewer 캡처 (`SCREEN_*`에 넣는 것) ⚡

> 본문이 특정 viewer 페이지(프로필 링크·예약·룩북·초대장·카탈로그 등)를 보여줄 때 → 폰 슬롯(`SCREEN_*`)에 채운다. **viewer는 공개 페이지라 로그인 불필요.**
> 슬러그 카탈로그(17개) → [[1-1-3. 이미지 규칙|1-3. 이미지 규칙]] §2.

### 2.1. 🔴 절대 원칙 — 사람처럼 분석 후 섹션 분할 (멀티 폰 A·C·F·G)

> **여러 폰 유형은 같은 캡처를 복붙하지 않는다.** viewer를 사람처럼 읽어 의미 섹션을 식별하고, **각 폰에 다른 섹션**을 넣는다.

- viewer는 자연스러운 사용자 여정(소개 → 정보 → 액션)을 가짐 → 그 흐름을 폰 시리즈로 시각화.
- **모범 `1:12129` (Heritage Summit)**: 폰1 인사말 / 폰2 RSVP 폼 / 폰3 문의처.
- 폰 개수만큼 의미 섹션 선정 (기본 3단=3 · 나열 그리드=4 · 프로세스 스텝=3~4) → 각 화면 비율(폰 ≈ **0.464**)로 crop → 업로드 → 화면 rect에 IMAGE fill.

### 2.2. 캡처 인프라 — Playwright (권장 1순위)

**스크립트**: `자동화 도구/cdbd-capture/capture-seminar-3sections.mjs`
```bash
cd "자동화 도구/cdbd-capture"
npm install && npx playwright install chromium     # 첫 1회
node capture-seminar-3sections.mjs <viewer-url> <prefix>   # 예: .../invitation/seminar/viewer seminar
```
- 진입 → **풀스크롤로 lazy-load 모두 트리거** → `SECTION_HINTS`로 의미 섹션 분기 → 슬롯 aspect(390×838=0.4654)로 3장 캡처.
- 🔴 **hero `forceY: 0` 룰**: hero는 **항상 페이지 진짜 상단(y=0)** 에서 캡처. (키워드 매칭은 본문 중간에 걸려 **로고·타이틀이 잘림** — Heritage Summit 사고). 새 viewer 스크립트도 `{ name:'1-hero', forceY:0 }` 동일 적용.
- Fallback 도구(인프라 불가 시): thum.io `fullpage` / Microlink — **lazy-load 누락 잦음**.

### 2.3. 업로드 전 체크 + Fallback

**업로드 전 필수 (같은 화면 3개 들어가는 사고 방지)**
- [ ] crop 3~4장을 **나란히 Read로 비교** — 정말 다른 내용인가.
- [ ] 각 crop **핵심 1줄 요약** — 같은 요약 나오면 ❌ (예: 폰1 로고+타이틀 / 폰2 RSVP폼 / 폰3 연락처).
- [ ] **콘텐츠 영역 밖 crop ❌** — 빈 BG만 나오는 y 범위 금지 (lazy-load 미스 인지).

**distinct 섹션이 안 잡힐 때 (순서대로)**
1. **다른 viewer 슬러그** 시도 — `personalized`↔`seminar`↔`rsvp` / `oak_table`↔`lookbook`↔`newarrival`.
2. thum.io `wait/30+` 로 더 대기.
3. 같은 viewer를 **다른 스크롤 위치**(상단/중간/하단)로 — 단, 간격을 충분히 벌려 시각이 다르게.
4. 1폰=full hero / 나머지=브랜드 컬러 BG 데코.

## 3. 에디터 화면 캡처 (EDITOR_CANVAS용 새 캡처) 🆕

> §1 컴포넌트로 안 되는 **새 에디터/관리/통계 화면**이 필요할 때. 에디터는 **로그인(admin)** 이 필요해 viewer 캡처와 절차가 다르다.

**언제**: D(화면설명)·E(인과)에서 §1 표에 없는 화면(특정 빌더·설정·CRM·통계 변형).

**방법 (우선순위)**
1. **컴포넌트 먼저** — §1 표에 있으면 캡처하지 말고 그 컴포넌트 instance 사용 (가장 안정적·일관).
2. **로그인 캡처** — Playwright로 CdBd 관리자(admin) 로그인 → 해당 빌더/통계 화면 이동 → 스크린샷.
   - 인프라는 viewer용(`자동화 도구/cdbd-capture/`)을 **로그인 스텝만 추가**해 재사용. (viewer=공개라 로그인 X / 에디터=로그인 필요)
3. **의미 영역만 크롭** 🔴 — 풀 에디터 화면 통째 ❌ → 보여줄 **패널·카드·통계 카드 1개**로 크롭 ([[1-2-3. 검수 체크리스트]]).
4. 업로드(`upload_assets`) → `imageHash` → 강조/프로세스 템플릿의 화면 영역에 fill. 통계면 핵심지표 확대 강조([[1-2-1-3. 강조]]).

> ⚠️ **에디터 로그인 자동 캡처 스크립트는 아직 없음** — 현재는 **수동 로그인 캡처 또는 §1 컴포넌트 재사용**이 기본. (→ TODO)
