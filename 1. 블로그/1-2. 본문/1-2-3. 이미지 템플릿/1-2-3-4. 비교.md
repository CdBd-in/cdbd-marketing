## 1. 대표 — 문제해결 (좌·우 50:50) `367:2459` ⭐

> 좌 = 기존 방식(부정·무채색) / 우 = CdBd(긍정·컬러). 좌우 대칭 3줄 특징.

**구조 (1920×1200, 좌 `367:2460` / 우 `367:2466` 각 960×1200)**

| 영역 | 위→아래 | 레이어 |
|---|---|---|
| **좌 (Before)** | sub-line → 라벨 pill(무채색) → **3D 부정 오브젝트** → 특징 3줄 | sub `367:2462` · `Problem` 인스턴스 `377:3957`(960×552 @0,292) · 특징 `367:2472` |
| **우 (After)** | sub-line → 라벨 pill(`#6C4CFF`) → **폰 2대(컬러)** → 특징 3줄 | sub `367:2468` · 폰 `367:2498`·`367:2503` · 특징 `367:2474` |

**🔴 원칙**
- **좌=비교대상(부정)·우=CdBd(긍정) 고정 배치.** 절대 좌우 바꾸지 않음.
- **좌측 자산 채도 다운(무채색)** — `Problem` 3D 오브젝트는 무채색 버전, 라벨 pill도 무채색. 우측은 원본 컬러 유지 → 시선이 CdBd로.
  - 방법: 이미지면 `fills[0].filters.saturation = -1`. 3D면 무채색 자산.
- **특징 3줄 = 본문에서 추출**, 좌(한계)·우(이점) **대칭**, 끝에 이모지. 예) 좌 "배포 후 수정 불가 ✍️ / 인쇄·폐기 비용 💰 / 고객 행동이 보이지 않음 🗒️" · 우 "즉시 수정 가능 🪄 / 저렴한 배포 비용 ✨ / 고객 행동 데이터 수집 📊".
- 라벨 = **병렬 골격** 통과 필수("종이 카탈로그 ↔ 모바일 카탈로그" ✅ / "1만 부 인쇄 ↔ 모바일 전환" ❌). → [[1-2-5. 카피 규칙 (라벨·캡션 텍스트)]].

**텍스트 위계 (Pretendard)**: sub-line SemiBold 36 / 라벨 pill Bold 50 / 특징 Bold 45(3줄).

## 2. 비용 비교 — 저울(시소) `371:2246` (#비용)

> 3D 저울 메타포 — 무거운 쪽 기존 비용, 가벼운 쪽 CdBd, 위로 "절감" 화살표.

| 레이어 | 처리 |
|---|---|
| `Expensive` 인스턴스 `377:4013` (446×310 @168,411) | 🔄 무거운 쪽 = 종이 더미+돈자루 3D (기존 비용) |
| 우측 배지 `Quick Menu` `371:2286` "수정 0원" + `371:2282`(앱 아이콘) | 🔄 가벼운 쪽 = CdBd 결과 + 절감 배지 |
| 곡선 화살표 `371:2302` + text-path `371:2301` "비용 00% 절감" | ✏️ 절감률 숫자 교체(본문 수치) |
| 하단 pill `371:2291` "CdBd 모바일 카탈로그" · 좌 pill `371:2295` "종이 카탈로그" | ✏️ 대상명 교체 |
| 저울대 vector `371:2253` · 받침 `371:2248` | 🔒 고정 |

- 🔴 **수치 = 본문 일치** ("00%"·"0원"을 실제 값으로). 정가/할인가 동시면 절감 강조.
- 좌측(무거운 쪽) 자산은 **무채색**, 우측은 컬러(공통 비교 원칙).

## 🔴 원칙 · 검수
