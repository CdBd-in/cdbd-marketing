# 피드백 기준 — 본문 이미지

> 🔴🔴 **이미지를 만들 때마다 — 시작 전 이 파일을 반드시 먼저 읽는다.** 여기 누적된 피드백 기준을 참고해 **같은 지적을 반복하지 않는 것**이 이 파일의 존재 이유다.


> 🎯 **목적**: 이미지별 **점수는 매기지 않는다**(일회성이라 남지 않음). 대신 **받은 피드백을 재사용되는 "기준"으로 축적**해, 다음 이미지부터 참고하며 퀄리티를 올린다.
> [[1-2-3. 검수 체크리스트]]가 *"사고 안 났나(binary)"* 를 본다면, 이 문서는 *"어떻게 하면 매번 더 잘 만드나(완성도·심미)"* 를 **원칙으로 굳혀** 둔다.
>
> 🔁 **사용법 (2단계 루프)**
> 1. **이미지 만들기 전** → §1 축별 기준 + §2 골든세트를 훑어 **같은 실수 반복 방지**.
> 2. **피드백 받으면** → §3 로그에 **원문 그대로** 기록 → 해당 축의 ✅기준/❌안티패턴으로 승격 → 필요 시 §2 예시·[[1-2-3. 검수 체크리스트]]에 반영.
>
> 🧭 **문서 관계**: 규범 = [[1-2-1-1. 공통]] / 사고방지(binary) = [[1-2-3. 검수 체크리스트]] / **완성도 기준(누적) = 이 문서**

## 1. 품질 축 — 축별 ✅기준 / ❌안티패턴 / 사례

> 기계적 규칙(폰트 px·노드 ID 매핑 등)은 여기 넣지 않는다 — 그건 규범·체크리스트 몫. 여기는 **"잘 만든다"의 판단 기준**만.

### 1-1. 본문 정합성 — 파트 메시지 ↔ 이미지 1:1 ⭐(본문 고유)
- ✅ 캡션이 말하는 **바로 그 기능·화면**이 이미지에 실제로 보인다.
- ❌ 파트와 느슨하게만 관련 / 아무 화면이나 캡처.

### 1-2. 시각 위계 — 한눈에 무엇을 볼지 명확한가
- ✅ 핵심 1개가 즉시 눈에 들어옴(크기·색·강조로 우선순위).
- ❌ 모든 요소가 같은 무게라 시선이 헤맴.

### 1-3. 가독성 — 화면·라벨·핵심이 즉시 읽히는가
- ✅ 라벨·화면 텍스트가 축소돼도 읽힘. 보여줄 영역만 확대 크롭.
- ❌ 화면 과다 축소로 뭉개짐 / 풀 화면 덤프.

### 1-4. 완성도(finish) — 정렬·여백·간격 일관, 군더더기 0
- ✅ 정렬·간격 일관, placeholder·예시 잔여물·빈 슬롯 0.
- ✅ **떠 있어야 할 요소(폰·링크칩·말풍선 등)엔 드롭섀도** — `blur 8~10 · 흑 25% · offset 0,0`. 평평하게 붙어 보이지 않게 살짝 띄워 깊이감. (예: `781:81` 스텝 요소들)
- ❌ 템플릿 예시 콘텐츠·점선 placeholder가 남음 / 카드가 그림자 없이 배경에 납작하게 붙음.
- ✅ **Wix 반영 = 정확히 2x PNG export** (1920×1200 → 3840×2400 / 1000² → 2000²) + 프레임·카드 **radius 유지**. 수정본으로 교체 시 **stale(구버전) 이미지 남지 않게** 확인.
- ❌ **1x·저해상 / radius 없는 raw 캡처 / 구버전 이미지**를 Wix에 넣음 → 흐리고 각지고 옛 버전으로 보임.

### 1-5. 자기설명성 — CdBd 몰라도 이해 + **상징(아이콘) 의미 정확** ⭐
- ✅ 개념 ↔ 오브젝트가 직관적으로 일치. `링크 = 🔗/카드/QR` · `파일 = 📁` · `사진 = 📷` · `수정 = ✏️` · `통계 = 📊`.
- ❌ **개념과 어긋난 상징**을 씀 → 독자가 다른 뜻으로 읽음.
- 📌 사례: ❌ body01 `761:1887` — "모바일 명함 링크"에 **지구본🌐**('글로벌/웹'으로 읽힘) / ✅ body05 `758:1887` — "URL"에 **체인🔗**(정확)

### 1-6. 브랜드 톤 + **템플릿·기존 에셋 준수**
- ✅ 신규 템플릿(`383:5681`) **clone 기반** + 색·폰트·목업이 CdBd답게 일관. 목적 분류(①~⑤)와 내용이 일치.
- ✅ 🔴 **기존 라이브러리 컴포넌트·에셋을 먼저 찾아 재사용** — 목업·인쇄물·3D 오브젝트는 **새로 만들거나 이미지 생성하기 전에 파일에 있는지 확인**. (멀티페이지 목업 `338:3238` · ③비교 인쇄물 `377:3936` Problem 라이브러리[Catalog·Paper·Namecard·Invitation] · 3D는 Thiings/자산 라이브러리)
- ❌ 템플릿 없이 **수작업 자유배치** / **있는 컴포넌트 두고 새로 생성**(멀티페이지에 단일 목업·세로합성, 비교 인쇄 쪽에 폰 목업·AI 생성 이미지).
- 📌 사례: ❌ body04 `763:1887`(수작업 조립) → ✅ `781:81`(템플릿 clone) · ❌ 브로셔 비교 좌측에 폰 목업+생성 이미지 → ✅ `377:3933`(Catalog 컴포넌트)
- 📌 멀티페이지 목업 채움(#ffffff Change-This 카드) · 비교 인쇄물 컴포넌트 상세 → [[1-2-2-2. 이미지 제작 가이드]] §2.0a-1

### 1-7. 심미·구도 — 점유율·여백·균형 ⭐
- ✅ 콘텐츠 점유율 **≥55%**, 요소가 캔버스를 충분히 채움. 상하 단일 여백 각 ≤25%.
- ✅ **스텝/카드 안 이미지(폰·칩·말풍선)는 스텝 라벨·화살표와 균형** — 서로 시각 무게가 비슷하게. 과하게 크면 답답·라벨과 불균형, 너무 작으면 휑함.
- ❌ 요소가 작아 상하·좌우 여백 과다 → **휑함** / 스텝 안 이미지가 과하게 커서 답답 (사례: `781:81` 스텝 이미지 축소 조정).
- 📌 사례: ❌ body05 `758:1887` — 원형 스텝이 1920×1200 대비 작아 상하 여백 과다 → 원 확대·세로 간격 축소 필요.

### 1-8. 세트 일관성 — 한 글의 이미지들이 하나의 시리즈로 ⭐(본문 고유)
- ✅ 같은 **상징 체계**(같은 개념=같은 아이콘) + 같은 **가상 데이터 세계관**(인물·회사·연락처가 서로 모순 없음).
- ❌ 같은 개념에 다른 아이콘 / 같은 이름이 다른 인물로 재등장.
- 📌 사례: 링크 상징 불일치(body01 🌐 ↔ body05 🔗) · 「김도현」이 hero(STech Energy)와 body03(GreenWave)에서 다른 인물로 중복.
