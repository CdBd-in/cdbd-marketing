## 5. 제작 & 검수 이력 (이터레이션)
1. **초안(축소판)**: A + 통계 2장만 제작 → 피드백 "비교 주제는 2장만? 통계가 왜?" → **풀세트로 확장**.
2. **B 비교 추가**(book vs 카탈로그) + **R 수치(0원)** + **통계에 "영업 데이터" 라벨** → 4장.
3. **파트별 매핑 적용**: 파트5(박람회 QR)가 비어있음을 발견 → **QR 배포 이미지 신설** → 5장.
4. **목업 비율 이슈**: 카탈로그를 원페이지 목업/짧은 슬롯에 넣어 **로고 잘림·세로 확대** 발생.
   - 사용자가 멀티페이지 목업 수정(새 컴포넌트 `98:2643`, 흰 화면 `Change-This`).
   - `98:2643` 직접 fill 첫 시도가 띠로 찌부러진 **근본 원인 규명**: 컴포넌트 안에 `Change-This`가 **2개** — **내부 화면(177×383, aspect 0.462)** + **외부 오버레이(177×286, aspect 0.619)**. 잘못된(외부·0.619) 노드에 채워서 깨졌던 것.
   - **해결(검증 완료)**: 인스턴스마다 `findAll('Change-This')` → **height 큰 쪽=내부 화면**에 풀페이지 캡처(aspect 0.453) **FILL identity**, **외부 오버레이는 `visible=false`**. 3개 모두 로고+'1/4' 네비게이터 정상.
5. **최종 통일 (사용자 정의 컴포넌트로 정타)**:
   - **A 히어로(`109:956`)**: `98:2643` 멀티페이지 목업 3개(BLUE NOTE·ELVE·ARTE) — 내부 화면 fill, 로고·네비게이터 보존.
   - **B 비교(`101:984`)**: 레퍼런스 `1:8211` clone + **특징 텍스트를 본문 내용으로 교체**(좌: 변경 시 재인쇄·재배포 / 인쇄·배송·재고·폐기 비용 / 영업 데이터 없음 · 우: 가격·구성 변경 0원 / 링크·QR 한 줄 배포 / 페이지뷰·CTR·순위 데이터, 52px). 이 이미지 기준으로 **비교(B) 디자인 가이드(1-2-1 §3.2) 갱신**.

## 7. 이번 글에서 얻은 교훈 (가이드 반영)
- **파트별 매핑**: 주제로 N장 찍지 말고 divider 파트마다 맞춤 ([[1-0. 주제]] §2.2, [[2. 검수 체크리스트]] A0).
- **목업↔콘텐츠 비율**: 카탈로그(가로 넓은 페이지)는 멀티페이지 폰, 로고 보존 위해 풀페이지(y=0~네비게이터) 캡처 ([[2. 검수 체크리스트]] B).
- **사용자 정의 컴포넌트 우선**: 임의 커스텀·레퍼런스 폰 대체 ❌ → 사용자가 정의한 멀티페이지 목업 `98:2643`을 써야 함. 단 **컴포넌트 내부 구조(이중 `Change-This`)를 정확히 파악**해야 정타 — 내부 화면 fill / 외부 오버레이 숨김 ([[2. 검수 체크리스트]] B).
- **정사각 이미지 = 슬롯 템플릿 사용**: 커스텀 레이아웃 ❌ → 1000×1000은 정의된 정사각 슬롯 템플릿(G~K, 예 H `15:325`) clone→fill. QR 전용 템플릿이 없으면 가장 가까운 템플릿(H)의 슬롯(SCREEN=폰, EDITOR_CARD=QR)에 매핑.
- **비교(B) 특징 = 본문 추출**: 레퍼런스 문구를 그대로 두지 말고 글의 실제 대비점으로 교체(좌 한계 3줄 / 우 이점 3줄, 52px). 이 결과를 디자인 가이드(1-2-1 §3.2)에 역반영.
- **캡처 한계**: 일부 카탈로그 viewer는 헤드리스 빈 렌더 → 기존 `.temp` 풀캡처 활용.

## 8. 후속 수정 — 세션 2 (2026-06-22) ⭐

> 5장 완성 후 사용자 피드백 기반 품질 개선 + 슬롯 템플릿 정합성 작업.

### 8.1. 통계(`81:774`) — 강조 영역 추가
- **사고**: 통계 대시보드를 단순 캡처만 하니 **어느 수치가 핵심인지 안 보임**.
- **해결**: 핵심 지표 카드(페이지뷰·클릭수)를 **확대·팝업**(클리핑 프레임 936×259에 통계 instance를 `scale≈1.44`로 확대 → 상단 2카드만 노출, 흰 카드+그림자로 떠 보임). 베이스 대시보드는 뒤로.
- **슬롯화**: 통계 단독 슬롯 템플릿 **`121:23` 신규** (`LABEL_PILL`·`STAT_SLOT`·`EMPHASIS_SLOT`) — 슬롯 페이지 `15:23`. 첫 버전은 실제 통계 instance를 넣는 실수 → **빈 점선 플레이스홀더로 정리**.
- 가이드: [[1-2-2. 강조 (Emphasis)]] (통계 = 핵심지표 확대 강조). *(2026-06-30 재편 전 구 "I-단독 통계" 정의)*

### 8.2. R 수치(`88:899`) — 빈 공간 보강
- **사고**: 1920×1200인데 "0원 + 코인"만 있어 상하 여백 ~33%씩 휑함.
- **해결**: **전후 대비** 추가 — "인쇄 재인쇄 비용 / 처음 비용 100%"(취소선, 회색) → ↓ → "0원"(히어로) + 코인 확대. 절감 스토리(100%→0원)로 0원의 의미 강화 + 공간 채움.
- 가이드: R 섹션에 "빈 공간 주의(전후대비/보조요소/1000×1000)" 룰 추가.

### 8.3. 슬롯 템플릿 명명·정합성 정리
- **C 슬롯(`15:84`) 이름 중복**: `MOCKUP_PHONE_1/2`·`SCREEN_1/2`가 2×2인데 2번씩 중복 → `findOne`이 첫 개만 잡음 → **`_1~_4` 위치순 유일화**(상좌·상우·하좌·하우).
- **F 슬롯(`15:224`)**: `Group 3` 래퍼 → `STEP_GROUP_3` (내부 STEP_PHONE_3/SCREEN_3 유지).
- **가이드 ↔ 실제 불일치 정정**: 1-2-2가 "N·R 신규 슬롯 필요"라 했으나 **실제 L~R 슬롯 모두 `15:23`에 존재** → 가이드 "존재함"으로 정정.
