## 0. 대전제 — "이미지가 말하고, 텍스트는 거든다"

본문 이미지는 **타이틀을 박지 않는다.** 텍스트는 시각(목업·에디터·통계)을 **보조**하는 라벨·캡션뿐. 긴 설명문은 본문이 처리한다.

1. **시각 우선** — 이미지만으로 이해되면 텍스트 0개도 정답. 텍스트는 "이게 뭔지" 헷갈릴 때만 최소로.
2. **한 이미지 한 메시지** — 라벨은 그 파트의 **핵심 1개**만. 두 개념을 한 라벨에 담지 않는다.
3. **CdBd 모르는 독자 기준** — 내부 명칭·전문용어 대신 **일반 독자가 즉시 아는 말**로. (예: `viewer` ❌ → "모바일 카탈로그" ✅)
4. **광고체 금지** — 라벨/캡션은 **컨텍스트(무엇을 보여주는지)**. 가치제안·CTA·과장(최고/혁신/완벽)은 ❌.

## 2. 단어 선택 — 함축적으로 전달하기

### 2.1. 명사형 압축 (조사·서술어를 덜어낸다)
문장을 **체언(명사) 중심**으로 줄인다. "~을 ~합니다"를 통째로 명사구로.

| 풀어 쓰면 (❌ 장황) | 함축 (✅ 라벨) |
|---|---|
| 행사 참여 통계를 한눈에 볼 수 있어요 | **행사 참여 통계 한눈에** |
| 가격을 실시간으로 수정할 수 있습니다 | **가격 실시간 수정** |
| 질문과 답변 카드를 만드는 화면 | **질문·답변 카드 빌더** |
| 페이지 성과를 추적합니다 | **페이지 성과 추적** |

### 2.2. 구체어 > 추상어
막연한 말 대신 **셀 수 있고 눈에 띄는 단어**. 독자가 "오 이런 게 되네"를 느끼게.

- "데이터" ❌ → **"조회수·클릭률·순위 데이터"** ✅
- "편하게 배포" ❌ → **"링크·QR 한 줄 배포"** ✅
- "비용 절감" ❌ → **"인쇄·배송·재고·폐기 비용"** (제거 대상 구체화) ✅

### 2.3. 숫자·기호로 줄이기
| 기호 | 용도 | 예 |
|------|------|----|
| **숫자+단위** | 수치는 아라비아 숫자 | `0원` · `5분` · `100%` · `430명` · `Best 18` · `N가지` |
| **·** 가운뎃점 | **동급 나열**(같은 층위 묶기) | "한과·정육·과일" · "페이지뷰·CTR" · "출시·업데이트" |
| **/** 슬래시 | **선택지·구분** | "무료 / 유료" · "현장/사례" |
| **→** 화살표 | **인과·전환·단계** | "재인쇄 100% → 0원" · "정보 등록 → 카드 조립" |
| **vs** | **대비**(비교 주제) | "종이 vs 모바일" · "기존 vs 신규" |

### 2.4. 대비쌍 어휘 (Before ↔ After) — 비교형의 핵심
좌/우는 **같은 축, 반대 값**으로 대칭. 한쪽이 명사면 반대쪽도 명사.

> 🔴 **병렬 골격 테스트 (2026-06-23 추가 — "1만 부 인쇄 ↔ 모바일 전환" 사고 방지)**
> "같은 축"이 추상적이라 빠져나가는 걸 막는 **검증 가능한 테스트.** 비교 좌/우 라벨은 **`[수식어] + 공통 핵심명사`** 형식으로, **핵심 명사를 공유하고 수식어(값)만 반대**로 둔다.
> - **테스트**: 좌·우에서 공통 명사를 빼면 **같은 틀**이 남는가?
>   - ✅ 종이 **[카탈로그]** ↔ 모바일 **[카탈로그]** → 틀 `◯◯ 카탈로그` 공유
>   - ❌ 1만 부 **[인쇄]** ↔ 모바일 **[전환]** → 인쇄 ≠ 전환, 공유 틀 없음 (둘 다 명사여도 탈락)
> - **작성 절차**: ① 비교 축 = **공통 명사 먼저 고정**(카탈로그 / 명함 / 배포 / 페이지…) → ② 그 앞 **수식어만** `종이↔모바일`·`기존↔신규`·`인쇄↔디지털`로 교체.
> - ⚠️ "둘 다 명사로 끝나는가"만으론 부족 — **핵심 명사 일치**까지 확인해야 진짜 대비.

| 축 | Before (한계) | After (이점) |
|---|---|---|
| 매체 | 종이 카탈로그·PDF | 모바일 카탈로그 |
| 수정 | 변경 시 재인쇄·재배포 | 내용 바꿔도 0원 |
| 배포 | 부수 한정 | 링크·QR 한 줄 배포 |
| 데이터 | 영업 데이터 없음 | 조회수·클릭률·순위 데이터 |
| 비용 | 재인쇄 100% | 0원 |

### 2.5. 주제별 빈출 어휘 사전 (블로그 실제 사용어)
라벨·캡션을 쓸 때 **그 주제가 실제로 쓰는 단어**를 빌려 쓴다. ([[1-0. 주제]] 분류 신호어와 동일 — 일관성 유지)

| 주제 | 자주 쓰는 단어 |
|------|---------------|
| **사례** | 후기 · 인터뷰 · 비하인드 · 「브랜드」의 「행사/제품」 |
| **가이드** | 만들기 · N분 · 방법 · ~하는 법 · 셀프 제작 |
| **비교** | vs · 대안 · 한계 · 차이 · 왜 안 되나 |
| **비용/ROI** | ROI · 절감 · 단가 · 0원 · 무료 vs 유료 · N% |
| **소트리더십** | 전략 · 인사이트 · 알고리즘 · GEO |
| **기능 출시** | 출시 · 업데이트 · NEW · 소개 · 기능 |
| **프로필링크** | 프로필 링크 · 링크인바이오 · 멀티링크 · 미니 홈페이지 |
| **라운드업** | 추천 N가지 · Best N · 툴 N가지 · N곳 · 비교 N |

### 2.6. 🔴 과압축 금지 — "의미 복원 테스트" (함축의 한계선)
함축은 **의미가 복원될 때만** 함축이다. 압축이 과해 뜻이 사라지면 그건 암호다. 라벨을 쓴 뒤 반드시 자문:

> **"이 글을 모르는 사람이 이 라벨만 보고 무슨 뜻인지 한 번에 복원되는가?"** → 안 되면 **압축을 한 단계 풀어** 명확성을 우선한다. **(명료성 > 짧음)**

**모호 신호 (이게 보이면 다시 쓴다)**
- **지시 대상 생략**: "받는 사람" "그것" — 누구/무엇인지 안 나옴.
- **단위·기준 미상**: "1장" "0원" "N개" — *무엇*이 1장인지, *무슨* 비용이 0원인지 빠짐.
- **동사+숫자 결합 모호**: "변경 0원" → "변경하는 데 0원"인지 "0원으로 변경"인지 갈림.
- **주어/목적어 증발**: 무엇이 무엇을 하는지 복원 불가.

| ❌ 과압축 (의도 증발) | 의도 | ✅ 복원되게 |
|---|---|---|
| 받는 사람만 1장 | 종이는 직접 만난 사람에게만 줌 | **대면 전달만 가능** |
| 가격·구성 변경 0원 | 내용을 바꿔도 비용 0원 | **내용 바꿔도 비용 0원** |
| 데이터 수집까지 | 누가 봤는지 데이터가 남음 | **열람·클릭 데이터 수집** |

> 💡 **대비형(B)은 "~면 ↔ ~도"로 복원력↑**: "바꾸면 재인쇄 ↔ 바꿔도 0원"처럼 좌/우 어미까지 대칭시키면 0원이 "수정 비용"임이 자동으로 읽힌다.

### 2.7. 🔴 쉬운 단어 우선 (어려운 말 → 쉬운 말)

> 기준 = **이 서비스를 처음 보는 사람.** 비즈니스 용어·한자어·업계 약어보다 **일상에서 쓰는 쉬운 말**을 고른다. 짧게 줄이려다 딱딱한 한자어를 쓰면 오히려 안 읽힌다 — **쉬움 > 멋짐**.

**대표 예**: ❌ "가격·구성 변경 0원" (무엇을 변경?·딱딱) → ✅ **"내용을 바꿔도 0원"** (처음 보는 사람도 바로 이해)

| 어려운 말 (❌) | 쉬운 말 (✅) |
|---|---|
| 가격·구성 변경 | 내용 바꾸기 |
| 변경 · 수정 · 갱신 | 바꾸기 · 고치기 |
| 열람 | 보기 |
| 도입 | 시작 · 쓰기 |
| 구축 · 제작 | 만들기 |
| 페이지뷰 / CTR | 조회수 / 클릭률 |

> **단, 독자가 이미 아는 말은 유지** — "모바일 카탈로그 · QR · 링크 · 데이터"처럼 일상화된 용어는 굳이 안 바꾼다. **쉬운 말 ≠ 유치한 말** — 정확성은 지키되 표현만 쉽게.

## 3. 어미·문체 규칙 ⭐

### 3.1. 라벨·비교 라벨 → **명사형 종결** (체언 마침)
- ✅ "~ 빌더" · "~ 추적" · "~ 배포" · "~ 한눈에" · "~ 카탈로그"
- ❌ 문장체 종결어미: `~합니다 / ~해요 / ~하세요 / ~할 수 있어요` (설명·명령문은 본문 몫)
- ❌ **마침표(.) 금지**, 느낌표(!) 금지. (라벨은 부호 없이 끝낸다)

### 3.2. 특징 리스트 → 명사형 또는 **동사의 명사화**
동사가 필요하면 "~합니다"가 아니라 **명사화**로 끊는다.
- ✅ "즉시 수정 가능" · "데이터 수집" · "비용 제거" · "한 줄 배포" · "내용 바꿔도 0원"
- ❌ "즉시 수정할 수 있습니다" · "데이터를 수집해요"
- 줄 끝 **이모지 1개**로 의미 보조 (🪄 마법/간편 · ✨ 효율 · 📊 데이터 · 💸 비용 · 🚫 부재). 라벨 pill엔 이모지 ❌.

### 3.3. 서브라인 → 관형형·부사형으로 **여운 있게 끊기**
라벨을 꾸미는 한 톤. 명사로 끝나도, "~한"/"~까지"/"~한눈에"로 끝나도 OK.
- ✅ "비용은 높고 수정은 어려운" (관형형) · "낮은 비용으로 데이터 수집까지" (부사격 조사 종결)

### 3.4. 캡션 → **동사 명사형**(음슴체 느낌)
- ✅ "현장에서 QR 스캔" · "→ 모바일 카탈로그 바로 보기"

### 3.5. 물음표·em dash — 제한적 사용
- **물음표(?)**: 문제제기 유형(O 문제신)에서만. 라벨엔 기본 ❌.
- **em dash(—)**: 본문 이미지 라벨엔 쓰지 않는다. (시리즈 마커·타이틀 분리는 썸네일 규칙)

## 4. 길이·표기 빠른 기준

- 라벨 pill **5~12자** / 서브라인 **~15자** / 특징 1줄 **8~14자(+이모지)** / 캡션 **~12자**.
- 숫자는 **아라비아 숫자 + 단위**: `0원` `5분` `100%` `430명` `34.88%` `Best 18` `N가지`.
- 영문 제품/브랜드명은 원표기 유지(더미). 한글 조사와 붙을 때 자연스럽게.
- **더미 데이터** — 실명·실제 고객 로고·실제 수치 노출 ❌ ([[2. 검수 체크리스트]]).

## 5. 카피 검수 (이미지 검수에 포함)

- [ ] 라벨/비교라벨이 **명사형 종결** + **마침표 없음**인가
- [ ] 문장체(`~합니다/~해요`)·광고체(최고/완벽/혁신)·CTA가 섞이지 않았나
- [ ] **추상어 → 구체어**로 바꿨나 (데이터 → 페이지뷰·CTR 등)
- [ ] 비교 좌/우가 **같은 축·반대 값**으로 대칭인가 + 🔴 **병렬 골격 테스트**(공통 핵심명사 공유 + 수식어만 반대 — §2.4) 통과인가 (예: "종이 카탈로그 ↔ 모바일 카탈로그" ✅ / "1만 부 인쇄 ↔ 모바일 전환" ❌)
