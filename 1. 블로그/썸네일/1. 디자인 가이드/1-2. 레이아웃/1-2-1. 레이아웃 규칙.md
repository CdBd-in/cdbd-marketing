## 1. 레이아웃 적용 절차 (2026-06-12 갱신)

> 타이틀을 받으면 **이미지 유형 2-3개를 파악**하고, **각 유형별 2안 = 총 4-6안 자동 생성** → 사용자가 유형 자체부터 비교 선택.

1. **이미지 유형 2-3개 결정** (§1.1) — 신호어 매칭 점수로 **1·2순위 유형 필수 + 3순위 선택** (신호어 폭 좁으면 2개·넓으면 3개). 단일 유형 결정 ❌.
2. **각 유형별 자산 추출** — [[1-3. 이미지 규칙]] §1 Step 2 다층 분석으로 유형별 1순위 자산. 서브타이틀은 입력으로 결정(±서브 직교) / 강조색 자동(서브→그린·무서브→퍼플 → [[1. 블로그/썸네일/1. 디자인 가이드/1-1. 스타일]])
3. **각 유형별 2안 자동 제작 = 총 4-6안** (§2):
   - **A·B·D 유형 (위치 변형 가능)**: 상단·서브 + 하단·서브 = 2안
   - **C 유형 (상단 고정)**: 다른 자산 조합 2안
   - **E 유형 (중앙 고정)**: 다른 자산 2안
   - 각 안: 슬롯 clone → 타이틀·이미지·보조 fill
4. **검수·선택** — 사용자가 4-6안 중 1개 선택. **유형 자체부터 비교 가능**.

### 1.1. ① 이미지 유형 결정 (타이틀 → 유형 / 본문 있으면 본문이 1차 근거)

> 핵심 질문: **"이 타이틀이 보여줄 CdBd 화면이 있는가? 하나인가 여럿인가? 없는가?"**(기존 썸네일 이미지 분석)

#### A. 목업 — **발행 페이지(viewer)에 보이는 기능** 하나를 시연
- **기준**: 그 기능이 방문자가 보는 *완성된 페이지*에 나타남 → 목업 1개로 시연
- **신호**: viewer 기능명 (RSVP·예약 관리·프로필 링크·프로모션·상담 신청·룩북·서명), "X 활용법/제작/소개/**업데이트**", "X로 **끝내기/해결**"
- **실제 예시**:
  - "행사 **RSVP**, 엑셀 입력 말고 모바일 초대장으로 끝내세요"
  - "레이어 추가하기 **기능 업데이트**"
  - "**VIP 1:1 예약 관리**, 전화 핑퐁 모바일 초대장으로 끝내기"

#### B. 목업 + 에디터 기능 — **편집·관리 화면에서 하는 기능**
- **기준**: 그 기능이 발행 페이지엔 안 보이고 *에디터/관리 화면*에서 일어남 → "기능 UI(표·카드·패널) + 결과 목업" 결합
- **신호**: 에디터 기능명 (레이어·카드 추가 / 팀 공유 / 데이터·CRM 업로드 / 통계 / QR / AI 디자인)
- **실제 예시**:
  - "엑셀 업로드 → CRM 마케팅 자동화" = **데이터 표 + 목업**
  - "레이어 추가하기 **기능 업데이트**" = **카드 빌더 UI + 목업**

#### C. 멀티 목업 — 화면이 **둘 이상** 등장·암시 (타이틀 **상단 고정**)

**🆕 C 유형 전용 룰 (2026-06-12 추가)**
- **서브 입력 시 `338:3150` 슬롯 자동 분기** ⭐ — 입력에서 서브타이틀(또는 em dash 마커 분리)을 발견하면 **반드시 `338:3150` (멀티·상단·서브) 사용**. 서브 없으면 `338:3118`. 2026-06-12 AIC 카탈로그 시안에서 슬롯 누락 사고 발생 → 룰 정착.
- **TITLE 한 행(1줄), hug(자동 폭)** — 폭은 텍스트 콘텐츠에 맞춰 자동(hug). 1줄 안 들어가면 의미 단위 분리.
- **DECO 미사용** — 멀티 mockup 3개 자체가 이미 시선 끄는 시각 임팩트 → 추가 sparkle/데코는 노이즈. C 유형 슬롯에 DECO placeholder 박지 않음.
- **상품/콘텐츠 페이지 캡처** — 멀티 mockup은 카탈로그·룩북 페이지 시리즈 시연용. cdbd viewer **URL parameter `?page=N`** 활용해 표지(p1) 대신 **실제 상품/콘텐츠 페이지** 캡처 권장. (예: lookbook 4페이지 → p3=상품 / newarrival 4페이지 → p2=상품 / online_lookbook 4페이지 → p3=상품 큐레이션). 페이지네이션 PIL 후처리 → [[1-3. 이미지 규칙]] §2.

- **위치**: 목업들이 하단 밴드를 차지 → 타이틀은 상단만 (하단 변형 없음)
- **신호**: 복수 명시("A와 B", "명함과 브로셔"), "결합/여러 개", **카탈로그·룩북**(다중 페이지 속성), "페이지 빌더"(여러 종류 제작), 컬렉션·여정형
- **실제 예시**:
  - "모바일 명함**과** 브로셔 만들고 팀 전체에 공유하는 방법"
  - "코딩 없이 10분 완성! 모바일 **페이지 빌더** CdBd"
  - "한화 ANTO 모바일 브로셔 **+** 영업 명함 **결합** 운영"

#### D. 3D 아이콘 — 메시지의 **개념을 상징하는 오브젝트**로 표현
- **기준**: 시연할 UI 화면보다 *개념·주장 자체*가 핵심 → 그 개념을 상징하는 3D 오브젝트(집·방패·차트·말풍선 등) 사용
- **신호**: "**왜 / 이유 / 진짜 이유**", 질문·주장형, 추상 개념(ESG·전환·신뢰), 비교("**대신 / vs / 갈아타는**"), "고집·주목"
- **실제 예시**:
  - "홈페이지 **대신** 프로필 링크로 갈아타야 하는 **이유**"
  - "기업이 비공개 초대장을 **고집해하는** 7가지 **이유**"
  - "상담 문의, 아직도 카톡으로 받으세요?" (문제 제기)

#### E. 배경 — CdBd 화면이 주인공이 **아닌** 외부 주제·리스티클 (특수, 매트릭스 밖 → §1.2)
- **신호**: "**Best N / N가지 / 추천**", 외부 툴·팁·일반 노하우, CdBd와 직접 무관한 마케팅 주제
- **실제 예시**:
  - "업무 효율 200% 높여줄, 직접 써보고 추천하는 **AI 툴 5가지**"
  - "일잘러를 위한 무료 이미지 사이트 **추천 Best 18**"

#### F. 글로우 (이점·비교 나열) ⭐ NEW (2026-06-22)
- **기준**: 여러 이점·축을 **나열·비교**하는 콘텐츠 → 각 축을 3D 아이콘 + 보라 태그로 한 화면에 나열
- **신호**: "**N가지 이점**", "**vs**", "**N축 비교/종합**", 본문에 **인쇄 vs 모바일 같은 대비 구조**·비교표, "비용·환경·재고" 같은 다축 분석
- **구성**: `TEXT_BLOCK`(SUBTITLE 그린 + TITLE 흰색·강조 그린) + 글로우 아이콘 2~3개(상단 `338:3202` / 상단·서브 `338:3183` / 2아이콘 `1:1127`) + 태그(정량 수치) — 상세 §3.6
- **실제 예시**:
  - "추석 모바일 카탈로그 **6가지 이점**" → 글로우 (영업데이터·비용·ESG…)
  - "추석 모바일 카탈로그 **vs** 인쇄 — 3년 **비용·환경·재고** 종합 분석" → 3글로우 (piggy·leaf·box)
- **D vs F**: 단일 개념·주장 = D(3D 1개) / **여러 이점·축 나열·비교 = F(글로우 N개)**

> **A vs B 핵심**: 그 기능이 **발행 페이지(viewer)에 보이면 A** / **에디터·관리 화면에서 하는 일이면 B**. (viewer 기능 목록 → [[1-3. 이미지 규칙]] §3.1 · 에디터 기능 → §3.2)
> **애매하면**: 복수 화면이면 C(멀티) / 화면 없으면 D·E / **여러 이점·비교면 F(글로우)**. 끝까지 모호하면 사용자에게 확인.

### 1.2. 특수 레이아웃 — 배경 (위치 변형 없음)

#### 베리에이션 규칙 (자동화)
서브타이틀 유무에 따라 슬롯이 결정되며, **둘을 섞지 않는다**:
