> **목적**: "무엇을 담을지"(콘텐츠·카피·보이스)를 기획·검수하는 가이드.
> "어떻게 보일지"(포맷·레이아웃·비주얼)는 [[05. 제작 디자인 규칙|제작 디자인 규칙]] 및 [[00. 페이지 유형 가이드|페이지 유형 가이드]]를 따른다.

## 1. 콘텐츠 서사 구조 (8비트 프레임워크) ⭐ 핵심

사례(레퍼런스) 콘텐츠 한 편의 **이야기 흐름**. 이 8단계를 우리 표지/본문/뒷표지에 매핑한다.

| # | 비트 | 역할 | 매핑(우리 유형) |
|---|------|------|----------------|
| 1 | **HOOK** | 스크롤을 멈추는 한 문장 | **표지** |
| 2 | **누가** | 주체(브랜드/기관) 소개 + 흥미 유발 | **본문** (또는 표지와 함께 듀얼 후킹) |
| 3 | **문제(통증)** | 기존 방식의 구체적 불편 2~3개 | 본문 |
| 4 | **사례 데이터** | 무엇을 했는지 / 핵심 수치 | 본문 |
| 5 | **사례 결과** | 그래서 어떻게 됐는지 | 본문 |
| 6 | **해법(기능)** | CdBd가 한 일 (기능 3개) | 본문 |
| 7 | **일반화(당신도)** | "이런 경우라면 당신도" 확장 | 본문 |
| 8 | **CTA** | 프로필 링크로 전체 사례 유도 | **뒷표지** |

> 매핑은 고정이 아니라 **출발점**. 표지=HOOK, 뒷표지=CTA는 고정, 중간 2~7번은 본문 유형을 콘텐츠 성격에 맞게 고른다(수치 강조→`Body-Full Bleed`/하이라이트, 여러 컷→`Body-Collage`, 개념·프로세스→`Body-Illust` 등).

### 듀얼 후킹 (HOOK을 표지에 다 몰지 말 것)
- **근거**: 인스타 알고리즘은 첫 장에서 안 넘기면 **둘째 장을 독립 노출**해 한 번 더 기회를 준다(Mosseri, 2024.10).
- **적용**: **표지(HOOK)와 첫 본문("누가")을 둘 다 단독으로 봐도 후킹**이 되게 쓴다.
  - 표지: 메인 HOOK (짧고 강하게)
  - 첫 본문: 서브 HOOK + 주체 소개 (한 문장만 봐도 흥미)

## 2. 분량 · 깊이 전략

### 한 장 한 메시지
- **슬라이드 1장 = 메시지 1개**. 한 장에 약 **100자 이내** 권장.
- HOOK(표지)은 특히 **짧고 임팩트** 있게.

### 깊이에 따른 장수
콘텐츠의 깊이에 맞춰 본문 비트를 가감한다.

| 깊이 | 총 장수(예) | 구성 |
|------|------------|------|
| **짧고 빠른 발견** | 6~7장 | HOOK·문제·결과·해법 핵심만 (일부 비트 통합/생략) |
| **표준 풀 스토리** | 8장 | 8비트 전부 |
| **깊은 사례** | 9~10장 | 데이터/통증을 분할, 중간 CTA 가능 |

> 시리즈로 발행 시 **편마다 장수를 달리해** 깊이를 조절할 수 있다(원문 실험 설계). 단, 표본이 작으면 인과 단정은 금물 — 방향성 신호로만.

### 중간 CTA (선택)
- 긴 편(9~10장)에서는 **중간에 CTA 슬라이드 1장**을 끼울 수 있다(알고리즘이 중간 장도 노출하므로 끝까지 안 보는 사용자도 도달).
- 문구 예: *"여기까지 보셨다면, 프로필 링크에서 전체 사례."* + (작게) `home.cdbd.in`

## 3. CTA 전략 (뒷표지)
- CTA는 **"프로필 링크에서 전체 사례 보기"** 로 유도한다.
- 본문에 **URL을 직접 노출하지 않는다** — 인스타 프로필 링크가 자동 전달되는 구조.
- 보조 표기로 `home.cdbd.in`을 작게.

## 4. 에디토리얼 규칙 (콘텐츠 검수)

콘텐츠 작성·검수 시 반드시 지킨다. (레이아웃 검수는 [[00. 페이지 유형 가이드]] 규칙으로)

- [ ] **CdBd 표기 정확** — `CdBd` 고정 (`cdbd`/`CDBD`/`Cdbd` 금지)
- [ ] **한자 0건** (한글/필요 영문만)
- [ ] **CdBd 미제공 기능 0건** — 실제로 없는 기능(예: 잠금·다국어 자동 변환 등) 언급 금지
- [ ] **CdBd 카드명·기능 정확** — 기능을 설명할 땐 디자인 시스템 **「4. 카드 기능 정의」**(`cdbd-design-system/디자인 시스템/4. 카드 기능 정의`) 기준의 **정확한 카드명**만 사용. 없는 카드명 금지 (예: "응답 카드" ❌ → "질문과 답변 카드" ✅)
  - RSVP·참석여부 수집 → **질문과 답변 카드** (사전 참석 신청서 프리셋 등)
  - 시간대 예약·방문 체크(QR) → **예약 카드**
  - 상품/룩북 → **상품 카드 · 갤러리 카드 · 이미지 카드**
  - 그 외: 프로필·텍스트·버튼·위치 안내·메뉴·SNS·유튜브·구분선·코드·2단 카드
- [ ] **검증된 사실만 인용** — 확인된 사실풀(레퍼런스 근거)과 일치
- [ ] **금지 통계 0건** — 출처 불명/과장 통계 금지
- [ ] **출처가 있으면 반드시 표기** ([[00. 페이지 유형 가이드#-공통-작업-규칙-자동화-기본값|출처 필수 규칙]])
- [ ] **시리즈 톤 일관성** — 여러 편 발행 시 HOOK 임팩트·해법 패턴·포인트 컬러를 통일해 한 시리즈로 인식되게

### 카피 톤 규칙
- **친근한 구어체**: 딱딱한 개조식 대신 `~요 / ~죠 / ~고요` 같은 말맛. (CdBd mag 뉴스레터 톤)
- **줄바꿈**: 본문은 **절 단위로 줄바꿈**(한 줄에 한 메시지). 자동 줄바꿈에만 의존하지 않음.
- **시제**: 사례의 **실제 시점에 맞춘다**. 이미 지난 일(매장 오픈 완료 등)은 **과거형**, 예정 이벤트는 미래형.

### 1순위 — 인스타 @cdbdmag 발행본 보이스 ⭐⭐ (매거진 기본)
> 근거: Figma 파일 내 실제 발행본 다수(`20250425`~`20251031_인스타그램 콘텐츠`) 텍스트 분석. **모든 매거진 카피는 이 톤·구조를 우선으로 따른다.**

**게시물 골격 (고정)**: `#카테고리 태그` → `제목 1~2줄(후킹)` → `설명 2~3줄(핵심 요약 + CTA 마무리)`

**분량 (4:5 카드 기준)**
| 슬롯 | 권장 글자 수 | 형태 |
|------|-------------|------|
| 카테고리 태그 | `#마케팅 인사이트` 형식, **1개** | 해시태그 한 줄 (있을 때만) |
| 제목 (HOOK/타이틀) | **20~35자**, 한 문장 | 질문형·반전형·수치형 후킹 |
| 설명 (서브) | **55~100자** (표준 ~85자), 1~2문장 | 핵심 요약 + **CTA 마무리** |
| 본문 캡션 (해설·트렌드형) | 최대 **~145자** | 단, **한 장 한 메시지** 유지 |

**카테고리 태그** (성격에 맞게 1개, 시리즈는 같은 체계 유지): `#마케팅 인사이트` · `#팩트체크` · `#실무자와의 인터뷰` · `#에디터활용` · `#CdBd 에디터 픽` · `#프로필 링크 시리즈 N` · `#업데이트 소식` 등.

**제목 후킹 6종** (하나 이상 적용)
- **질문형**: "혹시, …하고 있진 않나요?" · "…아끼고 싶지 않으신가요?"
- **대비·반전**: "링크트리 유료 기능, CdBd에선 '평생 무료'" · "'페이지 수정'에서 '기획'으로"
- **권위·직접**: "CEO가 직접 알려줌" · "직접 써보고 추천하는 AI 툴 5"
- **가정형**: "라부부 작가가 CdBd로 포트폴리오를 만든다면?"
- **단언·말맛**: "폰트 하나만 잘 써도 브랜딩을 완성시켜"
- **수치형**: "AI 툴 5" · "최고의 폰트 50"

**톤 (필수 패턴)**
- **설명(본문)은 친근 존댓말 구어체**: `~죠? / ~아깝죠? / ~않나요? / ~있어요 / ~드릴게요 / ~보세요`.
- **제목은 임팩트 우선** — **반말·명사형 종결 허용**("…알려줌", "…완성시켜"). 단 설명 문장은 존댓말 유지.
- **키워드 작은따옴표 강조**: '평생 무료' · '트래픽 맛집' · '진짜 실무용' · '일잘러' · '새로운 기준'.
- **영문 강조어**: "단순 링크 나열 NO!" · "A to Z 가이드".
- **구체 수치**: "월 9달러·1년 10만 원" · "조회수 138만회" · "월 0원".
- **CTA로 마무리**: "확인하세요!" · "비교해 드립니다" · "구독해 보세요" · "만나보세요".
- **밈·시의성 인용 OK** (인사이트형): 최신 사례·밈을 친근하게 엮는다.

**발행본 예시 (발췌)**
- 제목: "혹시, 당신의 프로필 링크가 고객을 떠나게 하고 있진 않나요?" / "링크트리 유료 기능, CdBd에선 '평생 무료'" / "인스타그램 알고리즘 타는 법 — CEO가 직접 알려줌"
- 설명: "매월 9달러, 1년이면 10만 원이 넘는 링크트리 구독료, 너무 아깝죠? 월 0원으로 프로필 링크를 업그레이드하는 방법을 조목조목 비교해 드립니다."
- **매거진 사인오프** (뒷표지 고정 문구): "인사이트가 필요할 때, CdBd 매거진"

### 2순위(보조) — 공식 랜딩 home.cdbd.in 보이스 (제품·기능 설명 시) ⭐
> 근거: 공식 마케팅 랜딩 `home.cdbd.in` + 세부 페이지(`/invitation`·`/businesscard`·`/profilelink`·`/catalog`) 카피 분석(2026-06-24). **CdBd의 제품·기능을 소개·설명할 때만** 아래 표기·용어·패턴을 따른다. 매거진 기본 톤·후킹은 위 **1순위(@cdbdmag)** 가 우선한다.

**보이스 4대 패턴**
1. **명령형 권유로 닫기** — 혜택 문장은 `~하세요 / ~해 보세요 / ~담으세요 / ~연결하세요`로 행동을 유도. (예: "방문객이 필요한 모든 걸 담으세요", "QR로 빠르게 입장시키세요")
2. **문제→해결 대비(before/after)** — 기존 방식의 통증을 먼저, CdBd를 그 해소로. (예: "홈페이지는 과하고 / 프로필 링크로는 부족할 때", "버튼만 나열된 프로필링크 대신", "이미지 약도 한 장만 보내실 건가요?")
3. **혜택을 수식 동사구로** — `[지표/대상]을 [동사]하는 CdBd [제품]` 골격. (예: "참석률을 극대화하는", "고객 이탈률을 최소화하는", "성과로 이어지는", "고객의 신뢰를 얻는")
4. **구체 상황·업종 호출** — 막연한 "행사" 대신 정확한 사용처를 부른다. (예: "신제품 런칭·쇼케이스", "매장·팝업 오픈", "VIP 초청·파티", "세미나·컨퍼런스")

- 막연한 "초대장 페이지" → **예약형 초대장 / 고객 맞춤형 초대장**
- "응답 카드 / 참석 신청 카드"(없는 명칭) → **질문과 답변 카드** (§4 카드명 규칙과 동일)
- 맥락 없는 "통계" → **실시간 통계(페이지뷰·클릭수·제출 답변)**
- "QR 명함 / 전자 명함" → **모바일 명함**(NFC 공유)
- 과장·미검증 수치(예: "5분 제작") → 검증된 표현("빠르게, 직접 제작")

**표기 규칙**
- **제목·타이틀 끝에 마침표(온점 `.`) 금지** — 제목은 온점 없이 끝낸다. (느낌표 `!`·물음표 `?`는 허용 / 설명·본문 문장은 온점 OK)
- **HOOK(표지 제목)은 강하게 후킹** — 단순 사실 나열보다 호기심 갭("…이렇게 열었어요"), 질문, 반전을 넣는다. (예: `BTS V가 산 그 모자, 첫 매장이 문을 연 날` → `…첫 매장을 이렇게 열었어요`)
- **템플릿 플레이스홀더는 반드시 콘텐츠로 교체** — `잘 정리된 마케팅과 디자인 인사이트를…`, `0. 소제목을 입력하세요`, `텍스트를 입력하세요`, `이 곳에 내용을 입력하세요` 등 기본 문구를 그대로 남기지 않는다.
