# CdBd 매거진 발행·내보내기 규칙

> 완성한 카드뉴스 세트를 **발행용 PNG로 내보낼 때**의 폴더 위치·파일명·규격 규칙.

## 1. 내보내기 위치 (데스크탑)

~~~
~/Desktop/{카드뉴스명}/
~~~

- 데스크탑에 **카드뉴스명으로 폴더 1개**만 만든다. (별도 부모 폴더 ❌, `#번호` 접두어 ❌)
- 예: `~/Desktop/올인컴플리트/`

## 2. 파일명 규칙

- **`01.png` ~ `NN.png`** — **카드 표시 순서**대로(표지 = `01` → 본문 → 뒷표지 = 마지막), **2자리 zero-pad**.
- 예(8장 세트): `01.png`(표지) · `02`~`07`(본문) · `08.png`(뒷표지).

## 3. 규격

| 항목 | 값 |
|------|-----|
| 크기 | **1080 × 1350 px** (4:5) |
| 포맷 | PNG |
| 해상도 | 네이티브 1x (프레임 원본 그대로) |

> Figma 프레임을 풀해상도로 내보낸다 (예: `get_screenshot maxDimension=1350` = 1x 네이티브, 또는 Figma export 1x PNG). 업스케일·축소 ❌.
