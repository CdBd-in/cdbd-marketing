# CdBd 매거진 페이지 유형 가이드

> **목적**: SNS 카드뉴스 콘텐츠 디자인 자동화.
> 사용자가 **내용(텍스트·이미지)** 을 전달하면 → Claudian이 아래 유형 중 적절한 **페이지 유형을 선택** → **슬롯에 내용을 채워** 카드뉴스 한 세트를 완성한다.

| 항목 | 값 |

| 비율 | 4:5 (세로형 카드뉴스) |

## 페이지 유형 = 3개 카테고리

카드뉴스 한 세트는 **표지 1장 → 본문 N장 → 뒷표지 1장** 순서로 구성한다.

| 순서 | 카테고리 | 역할 | 유형 수 | 문서 |
|------|----------|------|---------|------|
| 1 | **표지 (Cover)** | 첫 장. 후킹·주제 제시 | 3종 | [[CdBd 매거진/01. 표지(Cover).md\|01. 표지]] |
| 2~ | **본문 (Body)** | 내용 전달. 슬라이드마다 1개 메시지 | 6종 | [[CdBd 매거진/02. 본문(Body).md\|02. 본문]] |
| 마지막 | **뒷표지 (BackCover)** | 마무리·구독 유도·로고 | 3종 | [[CdBd 매거진/03. 뒷표지(BackCover).md\|03. 뒷표지]] |

## 자동화: 유형 선택 의사결정 가이드

전달받은 콘텐츠를 보고 아래 순서로 판단한다.

**1단계 — 카테고리 정하기 (슬라이드 위치)**
- 세트의 첫 장 → **표지**
- 중간 내용 장 → **본문**
- 마지막 장 → **뒷표지**
- 표지/뒷표지는 **배경 톤(BG)을 통일**한다. (예: 표지 `Cover-IMG BG` ↔ 뒷표지 `BackCover-IMG BG`)

**2단계 — 표지 유형**
- 분위기 좋은 **대표 사진**이 있다 → `Cover-IMG BG`
- 앱/서비스/제품 **아이콘·스크린샷** 중심 → `Cover-Icon`
- 사진 없이 **텍스트 중심·잔잔한 톤** → `Cover-Texture BG`

**3단계 — 본문 유형 (콘텐츠 형태 기준)**
- 임팩트 있는 **사진 1장 + 짧은 메시지** → `Body-Full Bleed`
- **여러 컷**을 한 장에 보여줌 → `Body-Collage`
- **사진 1장 + 설명 문단**을 균형있게 → `Body-Half`
- **두 이미지 비교/전후/A·B** → `Body-Half-IMG`
- **글(설명·인사이트)이 주인공**, 사진 비중 작음 → `Body-Texture BG-Article`
- **개념·프로세스를 일러스트/도식**으로 설명 → `Body-Texture BG-Illust`

**4단계 — 뒷표지 유형**
- 표지가 사진형 → `BackCover-IMG BG`
- 깔끔하게 마무리 → `BackCover-Solid BG` (기본값)
- 표지가 텍스처형 → `BackCover-Texture BG`

## 공통 슬롯 규칙

| 슬롯 종류 | 설명 |
|-----------|------|
| 🖼 이미지 슬롯 | `이 이미지를 교체하세요` 라고 표시된 프레임. 사진/그래픽으로 교체 |
| 📝 제목 / 소제목 | 한 장의 핵심 메시지. 짧고 강하게 |
| 📄 본문 | 부연 설명. 2~4줄 권장 |
| 🔖 출처 | `*출처: OOOOOO` — 데이터·인용 출처 (없으면 삭제) |
| 🔢 페이지 번호 | `1/5` 형태 (일부 본문 유형). 세트 총 장수에 맞춰 표기 |

> 글자 수는 4:5 카드뉴스 가독성 기준의 권장값이며, 각 유형 문서에 슬롯별 가이드가 정리되어 있다.

## 🧷 공통 작업 규칙 (자동화 기본값)

콘텐츠를 채울 때 항상 적용하는 기본 규칙. (별도 지시가 있으면 그것을 우선)

### 1. 표지 기본값
- **별도 요청이 없으면 표지는 `Cover-IMG BG` 유형을 사용**한다. (짝 뒷표지 = `BackCover-IMG BG`)
- 표지의 **설명 텍스트는 없을 수 있다** → 없으면 설명 슬롯을 **삭제**(빈 줄로 남기지 않음).

### 2. 포인트 컬러 일관성
- 본문에서 **포인트 컬러**(제목 하이라이트 박스, 강조 텍스트 등)를 쓰는 경우,
  **같은 콘텐츠(=같은 카드뉴스 세트) 안에서는 동일한 포인트 컬러**를 유지한다.
- 세트별로 포인트 컬러는 달라질 수 있지만, **한 세트 내에서는 통일**.

### 3. 출처 표기 (필수)
- 데이터·인용 등 **출처가 있으면 반드시 `*출처: …`로 표기**한다.
- 출처가 없을 때만 출처 슬롯을 삭제한다.

### 4. 이미지: 여백 없이 프레임 가득
- **모든 이미지는 여백 없이 프레임을 가득 채운다.**
- 원본 비율을 유지한 채 **프레임보다 크게 두고 clip으로 오버플로를 잘라낸다** (이미지를 줄여 맞추는 scale-to-fit 크롭 ❌, 이미지 RECT < 프레임 = anti-pattern).
- 위치를 정할 때 **중요한 부분(피사체·텍스트 영역)이 잘리지 않도록** 사이즈/위치를 조정한다.

### 5. 이미지는 별도 레이어로 (부모 프레임 fill ❌)
- 이미지를 **부모 프레임의 fill로 넣지 않는다.**
- 프레임 **내부에 별도의 이미지 레이어(RECTANGLE)** 를 추가한다.
- 부모 프레임은 **clip content가 켜져 있으므로**, 이미지 레이어가 프레임을 완전히 덮도록 **사이즈/위치만 조정**하면 된다.

### 6. 인물 사진 배치 규칙
인물 사진은 위 4·5번에 더해 **룩북 화보 배치 규칙**을 따른다.
> 📎 절차 문서: `cdbd-design-service/룩북/2. 디자인 가이드/2-4. 화보·상품.md` (및 「위치·사이즈 결정 트리」가 있는 `2-1. 공통.md`)

- **축소 크롭 금지 · 원본 비율 유지** — 프레임 clip으로만 잘라냄.
- **얼굴 등 중요한 부분이 잘리지 않게** 배치.
- 샷 타입별 배치 (결정 트리 요약):

| 샷 타입 | 배치 규칙 |
|---------|-----------|
| **풀샷** (머리~발끝) | 머리·발 모두 보이게 + **상단:하단 ≈ 3:2** 마진 + 모델 좌우 정중앙 (규칙 A) |
| 풀샷·한쪽 치우침 | 사이즈 키워 몸을 좌우 중앙으로 (크롭은 다리쪽만) (규칙 B) |
| **웨이스트~니샷** | 모델 정중앙 + 머리 상단 여백 ≈ 36~40 (규칙 C) |
| **바스트샷** (상하 여백 X) | 사이즈 키워 머리 보호 + 좌우 중앙 (규칙 D) |

- **비율이 안 맞아 여백이 생기면** 임의 크롭하지 말고 **Figma AI 배경 늘림**으로 채우거나 사용자에게 요청한다.

## 🖼 이미지 소싱 규칙

| 상황 | 소싱 방식 |
|------|-----------|
| **`Body-Texture BG-Illust`의 3D 아이콘** | **Thiings** 활용 방식 그대로 따름 → 가이드 문서: `cdbd-templates/1. 작업 가이드/1-3. 이미지.md` 「📦 소스 ①: Thiings」 |
| **그 외 모든 이미지 슬롯** (표지·본문·뒷표지의 사진/그래픽) | **이미 보유한 이미지를 가공해서 사용** (신규 생성 X) |

> 즉, 새로 만드는 이미지는 Illust 유형의 Thiings 3D 아이콘뿐. 나머지는 기존 이미지를 크롭·보정·누끼 등으로 가공해 슬롯에 맞춘다.
> Thiings 추출·파일 관리(`~/Downloads/{slug}.png`, 1:1 기본 등) 세부 규칙은 위 `1-3. 이미지.md` 참조.

### 누끼(배경 제거) 가공이 필요할 때
콜라주 컷처럼 **배경을 제거(투명 PNG)** 해서 슬롯/셀에 얹어야 하는 경우, 별도 가공 규칙을 따른다.
> 📎 절차 문서: `cdbd-templates/1. 작업 가이드/1-3. 이미지.md` → 「✂️ 누끼(배경 제거) 이미지 처리 요청」

- **두 가지 모드**
  - 🅰️ **로컬 누끼** → `~/Downloads/{keyword}-cutout.png` (투명 PNG). Obsidian 임베드·임시 자산용
  - 🅱️ **Figma 누끼 + 프레임** → Figma 안에서 누끼 RECT + 배경색 프레임 분리. **CdBd 페이지에 들어가는 디자인 자산은 이 모드 필수** (배경색을 이미지에 굽지 말고 프레임에 분리 → 재사용·수정 용이)
- **핵심 단계**: 배경 제거(Figma AI Remove background 등) → **PIL `getbbox()` + `crop()`** 로 alpha 여백 제거 → 크롭본을 슬롯에 fill
- **검증**: PNG `RGBA` 모드 + 네 모서리 alpha=0 (투명) 확인
