# 표지 (Cover) 페이지 유형

카드뉴스 세트의 **첫 장**. 스크롤을 멈추게 하는 후킹 + 주제를 한눈에 전달한다.
공통 요소: 하단 `CdBd mag.` 로고.

> ⭐ **기본값**: 별도 요청이 없으면 표지는 **`Cover-IMG BG`** 를 사용한다. (짝 뒷표지 = `BackCover-IMG BG`)
> 표지에서 고른 배경 톤은 **뒷표지와 짝을 맞춘다** (IMG ↔ IMG, Texture ↔ Texture).
> 📌 **설명 텍스트는 없을 수 있다** — 없으면 설명 슬롯을 삭제(빈 줄로 남기지 않음).

---

## 1. Cover-IMG BG `2451-47` ⭐ 기본값

사진을 카드 전체에 꽉 채우고(full-bleed) 그 위에 제목을 올리는 가장 강한 표지.

- **분위기**: 임팩트, 감성, 비주얼 강조
- **언제**: **별도 요청이 없으면 기본으로 사용**. 분위기 좋은 대표 사진/제품컷이 있을 때
- **이미지**: 부모 프레임 fill ❌ → 내부 이미지 레이어로 추가, 여백 없이 가득 채움 (인물이면 룩북 배치 규칙). → [[CdBd 매거진/00. 페이지 유형 가이드.md#-공통-작업-규칙-자동화-기본값|공통 작업 규칙]]

### 슬롯
| 슬롯 | 내용 | 가이드 |
|------|------|--------|
| 🖼 배경 이미지 | 풀블리드 사진 | 1080×1350, 인물·제품·분위기컷. 어두운 오버레이가 깔려 흰 글씨 가독성 확보 |
| 📝 제목 | `커버 페이지 제목을 입력하세요` | 핵심 카피. 1~2줄, 8~20자 |
| 📄 설명 | `설명 텍스트가 있다면 입력하세요` | 보조 문구 1줄(선택, 없으면 삭제) |

### 변형
- **제목 하단형** (`504-351`): 제목을 카드 아래쪽에 배치 (기본)
- **제목 상단형** (`2008-428`): 제목을 카드 위쪽에 배치 — 이미지의 주요 피사체가 아래에 있을 때

## 2. Cover-Icon `2451-377`

흰 배경 위에 **아이콘/스크린샷**을 크게 두고 제목을 붙이는 깔끔한 표지.

- **분위기**: 정보형, 깔끔함, 신뢰감
- **언제**: 앱·서비스·제품의 아이콘이나 화면 캡처가 주인공일 때

### 슬롯
| 슬롯 | 내용 | 가이드 |
|------|------|--------|
| 🖼 아이콘/이미지 | 상단 사각 영역 | 앱 아이콘, 로고, 스크린샷 등. 여백 있는 단일 그래픽 권장 |
| 📝 제목 | `커버 페이지 제목을 입력하세요` | 1~2줄, 8~20자 (검정 글씨) |
| 📄 설명 | `설명 텍스트가 있다면 입력하세요` | 보조 문구 1줄(선택) |

### 변형
- **아이콘 + 제목형** (`2451-414`): 아이콘 + 제목 + 설명 모두 표기
- **이미지 크게형** (`2451-430`): 이미지를 더 크게, 제목 없이 비주얼만 — 스크린샷 강조용

## 3. Cover-Texture BG `2451-533`

종이/구김 등 **텍스처 배경** 위에 제목을 얹는 잔잔한 표지.

- **분위기**: 따뜻함, 에디토리얼, 아날로그 감성
- **언제**: 사진 없이 텍스트 중심으로, 톤을 차분하게 가져갈 때

### 슬롯
| 슬롯 | 내용 | 가이드 |
|------|------|--------|
| 🖼 배경 텍스처 | 종이/구김 텍스처 | 템플릿 기본 텍스처 유지 권장 |
| 📝 제목 | 제목 | 1~2줄, 8~20자 |
| 📄 설명 | 설명(선택) | 1줄 |

> 이 표지를 쓰면 뒷표지는 `BackCover-Texture BG`로 맞춘다.
