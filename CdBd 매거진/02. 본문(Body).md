# 본문 (Body) 페이지 유형

표지와 뒷표지 **사이의 내용 슬라이드**. 한 장 = 하나의 메시지가 원칙.
공통 슬롯: `소제목/제목`, `본문`, `*출처: OOOOOO`, 일부 유형의 `1/5` 페이지 번호.

> **본문 공통 규칙** (자동화 기본값 — 전체는 [[CdBd 매거진/00. 페이지 유형 가이드.md#-공통-작업-규칙-자동화-기본값|공통 작업 규칙]])
> - 🎨 **포인트 컬러 일관성**: 제목 하이라이트 등 포인트 컬러는 **같은 콘텐츠(세트) 안에서 동일하게** 유지.
> - 🔖 **출처 필수**: 출처가 있으면 **반드시 `*출처: …` 표기**. 없을 때만 슬롯 삭제.
> - 🖼 **이미지**: 부모 프레임 fill ❌ → **내부 이미지 레이어(RECTANGLE)** 로 추가, clip 전제로 **여백 없이 가득** 채우고 사이즈/위치만 조정. 인물 사진은 **룩북 화보 배치 규칙**(`cdbd-design-service/룩북/2-4. 화보·상품.md`) 적용.
> - 🟰 **배경 타입 통일**: 한 세트의 본문은 img/solid/texture 중 **하나의 배경 타입**으로 통일 ([[CdBd 매거진/00. 페이지 유형 가이드.md#1-1-본문-배경-타입-통일|규칙]]).
> - 🌗 **dim 그라데이션 표준**: 이미지/목업 위에 텍스트를 올릴 때 쓰는 dim 그라데이션은 **세로(투명 상단 → 검정 하단) + paint opacity 0.5**(부드럽게)로 통일. 스톱 예시: 0%·45% 투명 / 72% 검정 0.85 / 100% 검정.
> - ✏️ **제목 하이라이트**: **색**은 템플릿 원본 색(`#FFB700` 앰버 / `#CCFF00` 라임 / `#FFCD4E` 골드) 중 택1(세트 내 통일). **디자인**은 템플릿 **형광펜 스타일** — 모서리 **각짐(radius 0)** · 글자 폭에 딱(패딩 X) · 높이 ≈ 폰트 × 1.1 · **어두운 글자(`#141414`)가 위에**. (Illust 페이지 기본 #FFCD4E)
> - 🔢 **페이지 번호 미사용**: 템플릿 원본에서 제거됨 → 본문에 `N/N` 페이지 번호 넣지 않는다.

### 본문 유형 호환성 규칙 ⭐
한 세트의 본문에 **어떤 유형을 함께 쓸 수 있는지**.
- **Half 유형은 Collage·Article과 섞어 쓰지 않는다.** (Half ✗ Collage / Half ✗ Article)
- Half는 그 외 유형(Full Bleed·Half-IMG·Illust 등)과는 **배경 타입만 같으면** 함께 사용 가능.
- **Collage와 Article은 서로 섞어 써도 된다** — 단 **배경 타입은 동일**해야 함.
- 정리: `{Collage, Article}`는 한 묶음(서로 호환) · `Half`는 이 묶음과 배타적.

### 🚫 누끼(배경 제거)는 사용자 요청 사항
- **이미지 배경 제거(누끼)는 절대 직접 처리하지 않는다.** 반드시 **사용자에게 요청**한다(Figma AI Remove background).
- 절차: 원본(흰 배경) 이미지를 Figma 보드에 업로드 → 노드 ID와 함께 **누끼 요청 메시지** 전달 → 사용자 완료 신호 후 가공본 hash로 교체.
- 상세: `cdbd-templates/1. 작업 가이드/1-3. 이미지.md` 「✂️ 누끼 처리」 / [[CdBd 매거진/00. 페이지 유형 가이드.md#누끼배경-제거-가공이-필요할-때|00. 가이드]]

## 1. Body-Full Bleed `2451-48`

사진을 카드 전체에 꽉 채우고 제목·본문을 그 위에 올림. 표지의 본문 버전.

- **언제**: 임팩트 있는 **사진 1장 + 짧은 메시지**
- **분위기**: 강한 비주얼, 몰입감

### 슬롯
| 슬롯 | 내용 | 가이드 |
|------|------|--------|
| 🖼 배경 이미지 | 풀블리드 사진 | 1080×1350. 글씨 영역에 어두운 그라데이션 |
| 📝 제목 | `세련미와·소박함의 조화, 2025 올해의 컬러…` | 1~2줄 |
| 📄 본문 | `이 곳에 내용을 입력하세요…` | 2~3줄 |
| 🔖 출처 | `*출처: OOOOOO` | 선택 |
| 🔢 페이지 번호 | `1/5` | 일부 변형에만 |

### 변형
- **제목 오버레이형** (`2008-688`, `2204-70`): 제목+본문만 깔끔하게
- **하이라이트 박스 + 페이지번호형** (`2009-43`, `2009-81`): 제목에 형광 하이라이트 박스(노랑·초록 등) + 상단 `1/5` — 연속 시리즈에 적합

## 2. Body-Collage `2451-51`

여러 컷(1~3장)을 한 장에 콜라주로 배치 + 하단 소제목·본문.

- **언제**: 한 주제에 대한 **여러 장면/예시 사진**을 함께 보여줄 때
- **분위기**: 풍부함, 큐레이션

### 슬롯
| 슬롯 | 내용 | 가이드 |
|------|------|--------|
| 🖼 이미지 | 1~3개 (배경 컬러 위 카드형 배치) | 레이아웃별로 컷 수 다름 |
| 📝 소제목 | `0. 소제목을 입력하세요.` | `숫자. 제목` 형식 권장 |
| 📄 본문 | 본문 | 2~3줄 |
| 🔖 출처 | `*출처: OOOOOO` | 선택 |

### 변형 (이미지 배치)
- 큰 1컷 (`2010-183`, `2016-125`, `2010-221`)
- 좌우 2컷 (`2010-173`, `2010-195`, `2010-229`)
- 1+2 조합 콜라주 (`2009-50`)
- **누끼 멀티 콜라주** (`2541-96`): 배경 제거한 여러 제품 컷을 다크 배경에 흩뿌려 배치 — 적용 예시
- **단일 목업 + scrim 오버레이** (`2541-127`): 세로 페이지 목업 위 dim 그라데이션 + 제목·본문 오버레이 — 적용 예시
> 컷 수에 맞는 변형을 고른다: 1장→1컷형, 2장→2컷형, 3장→조합형.

### 🖼 이미지 가공 메모
- 컷들은 **보유 이미지를 가공**해서 사용 (크롭·보정). 신규 생성 X.
- 컷 배경을 제거해 셀 위에 띄워야 하는 경우 → **누끼 가공 규칙** 적용.
  > 📎 `cdbd-templates/1. 작업 가이드/1-3. 이미지.md` 「✂️ 누끼(배경 제거) 이미지 처리 요청」 / 요약은 [[CdBd 매거진/00. 페이지 유형 가이드.md#누끼배경-제거-가공이-필요할-때|00. 가이드 — 누끼 가공]]

## 3. Body-Half `2451-725`

카드를 **상/하 절반으로 분할** — 한쪽 이미지, 한쪽 텍스트.

- **언제**: **사진 1장 + 설명 문단**을 균형 있게 전달
- **분위기**: 정보 + 비주얼 균형, 안정적
- 📐 **가로 비율 이미지 전용**: Half는 **이미지 원본이 가로(landscape) 비율일 때만** 사용한다. 세로(portrait) 원본은 Half에서 과도하게 잘리므로 다른 유형(Full Bleed·Article 등)을 쓴다.
- 📏 **이미지 영역 세로 길이 가변**: 원본 비율에 맞춰 이미지 영역(상/하 분할 비율)을 조정해도 된다. **제품·피사체가 과하게 잘리지 않도록** 세로 길이를 늘리거나 줄인다. (절반 고정 ❌)
- ⚠️ **Collage·Article 유형과 같은 세트에 함께 쓰지 않는다** (위 호환성 규칙).

### 슬롯
| 슬롯 | 내용 | 가이드 |
|------|------|--------|
| 🖼 이미지 | 절반 영역 | 가로로 넓은 컷 적합 |
| 📝 소제목 | `0. 소제목을 입력하세요.` | `숫자. 제목` |
| 📄 본문 | 본문 | 3~4줄 (텍스트 영역 넉넉) |
| 🔖 출처 | `*출처: OOOOOO` | 선택 |

### 변형
- **이미지 上 / 텍스트 下** (`2059-12`, `2059-20`, `2059-28`)
- **텍스트 上 / 이미지 下** (`2059-36`)
- **다크 톤 변형** (`2451-55`, `2451-66`, `2451-760`, `2451-782`): 어두운 배경 + 이미지/텍스트 분할 — 적용 예시

## 4. Body-Half-IMG `2451-176`

이미지를 **2분할 그리드**로 나란히 배치. 비교/전후/A·B 대조에 사용.

- **언제**: 두 이미지를 **비교·대조**, 또는 한 장면을 분할 연출
- **분위기**: 대비, 직관적 비교

### 슬롯
| 슬롯 | 내용 | 가이드 |
|------|------|--------|
| 🖼 이미지 | 2분할(상/하 또는 좌/우) | 두 컷 톤 맞추기 |
| 📝 캡션 | `텍스트를 입력하세요` | 하단 작은 라벨(선택) |

### 변형
- **이미지만** (`2306-16`)
- **이미지 + 하단 캡션 라벨** (`2306-33`)

## 5. Body-Article `2451-49`

텍스처 배경 위 **글 위주 아티클**. 제목 + 비교적 긴 본문.

- **언제**: **글(설명·인사이트)이 주인공**, 사진은 보조이거나 없음
- **분위기**: 에디토리얼, 읽는 콘텐츠
- 🎨 **배경**: 종이 텍스처 (세트가 텍스처 배경 타입일 때 사용)

### 슬롯
| 슬롯 | 내용 | 가이드 |
|------|------|--------|
| 🖼 배경/포인트 이미지 | 상단 작은 이미지 또는 텍스처 | 선택 |
| 📝 제목 | 제목 (하이라이트 가능) | 1~2줄 |
| 📄 본문 | 긴 본문 | 4~6줄까지 |
| 🔖 출처 | `*출처: OOOOOO` | 선택 |

### 변형
- 3종 베리에이션 (`2008-703`, `2008-730`, `2008-760`)

## 6. Body-Texture BG-Illust `2451-611`

종이 텍스처 배경 + **일러스트/그래픽**으로 개념·프로세스를 설명.

- **언제**: 추상 개념, 단계/프로세스, 비교 구조를 **도식·일러스트**로 풀어낼 때
- **분위기**: 친근함, 설명형(사용 설명서 톤)

### 슬롯
| 슬롯 | 내용 | 가이드 |
|------|------|--------|
| 📝 소제목 | 상단 소제목 | 1~2줄 |
| 🖼 일러스트/그래픽 | 중앙 영역 | **3D 아이콘 → Thiings 소싱**(아래) · 다이어그램·캡처 등 |
| 📄 캡션 | 하단 설명 | 1~2줄 |

### 🖼 이미지 소싱 규칙 (중요)
이 유형의 **3D 아이콘**은 `cdbd-templates` 작업 가이드의 **Thiings 활용 방식을 그대로 따른다**.
> 📎 출처 문서: `cdbd-templates/1. 작업 가이드/1-3. 이미지.md` → 「📦 소스 ①: Thiings」

- **소스**: [Thiings](https://www.thiings.co/things) (무료 3D 렌더 아이콘, `/things/{slug}` 구조)
- **선정 기준**: 1~2초 안에 의미 파악되는 보편적 모티프 / 너무 구체적·문화 종속적 아이콘 ❌
- **판단 질문**: "처음 본 사람도 이 아이콘의 의미를 즉시 이해하는가?"
- **일관성**: Thiings는 입체감·재질 톤이 통일돼 한 페이지에 여러 개 써도 흐트러지지 않음
- **추출/저장**: `https://www.thiings.co/things/{slug}`의 `og:image` URL → `~/Downloads/{slug}.png` (볼트 외부, 1:1 기본)

### 변형
- 3종 베리에이션 (`2451-344`, `2451-353`, `2451-369`)
