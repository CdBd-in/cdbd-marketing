# CdBd 매거진 제작 디자인·포맷 규칙

> **목적**: 콘텐츠를 4:5 카드로 제작할 때의 **포맷·레이아웃·비주얼 규칙** 요약.
> "무엇을 담을지"(카피·서사·보이스)는 [[CdBd 매거진/04. 콘텐츠 기획 가이드.md|콘텐츠 기획 가이드]]를 따른다.
> 상세 레이아웃·유형은 [[CdBd 매거진/00. 페이지 유형 가이드.md|페이지 유형 가이드]] 및 01~03을 따른다.
>
> ※ 원문 기획서(카드뉴스 MVP)는 1:1 정사각·고정 8슬라이드 마스터 전제였으나 **전부 우리 규칙으로 대체**했다. 아래는 우리 규칙만 남긴 것.

## 1. 포맷·레이아웃 규칙

| 항목 | 우리 규칙 |
|------|-----------|
| 캔버스 비율·크기 | **4:5 (1080×1350)** |
| 페이지 유형 | **표지·본문·뒷표지 12유형** ([[CdBd 매거진/00. 페이지 유형 가이드.md]]) |
| 배경 | 유형별 배경(사진·텍스처·solid 등). **배경 타입 3종**(`① img+dim/blur · ② solid · ③ texture`) 중 택1. 표지 기본 `Cover-IMG BG` |
| 폰트·크기 | 4:5 템플릿에 내장된 스타일 사용 (임의 크기 지정 ❌) |
| 로고 | 템플릿에 내장된 `CdBd mag.` 로고 위치 사용 |
| 페이지 번호 | 템플릿 본문의 표기 방식 따름 (현행 제작 세트는 번호 미표기) |
| 색상·포인트 컬러 | 템플릿·콘텐츠에 따라 결정. **세트 내 1색 일관성**만 적용 ([[CdBd 매거진/00. 페이지 유형 가이드.md#-공통-작업-규칙-자동화-기본값|일관성 규칙]]) |
