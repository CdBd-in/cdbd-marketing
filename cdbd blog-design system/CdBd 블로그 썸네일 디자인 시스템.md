# CdBd 블로그 썸네일 디자인 시스템

> 피그마 파일 분석 기반으로 자동 추출된 디자인 시스템 문서.
> 총 **94개의 Cover 썸네일** (600×450px) 패턴에서 도출.

---

## 1. 캔버스 스펙

| 항목 | 값 |
|------|-----|
| **크기** | 600 × 450 px |
| **비율** | 4 : 3 |
| **포맷** | PNG |
| **해상도** | 72 dpi (웹 전용) |

---

## 2. 컬러 시스템

### 배경색
| 역할 | HEX | 설명 |
|------|-----|------|
| **Primary BG** | `#0D0D0D` ~ `#111111` | 모든 썸네일의 기본 배경. 완전한 검정보다 약간 밝은 다크톤 |

### 텍스트 색상
| 역할 | HEX | 사용 위치 |
|------|-----|-----------|
| **헤드라인** | `#FFFFFF` | 메인 제목 텍스트 전체 |
| **강조어 (Green)** | `#4ADE80` 계열 | 핵심 키워드 강조 — 가장 빈도 높음 |
| **강조어 (Purple)** | `#8B5CF6` ~ `#7C3AED` 계열 | 브랜드/기능명 강조 — 두 번째로 빈도 높음 |
| **강조어 (Yellow)** | `#FBBF24` 계열 | 따옴표 강조, 인용 표현 — 간헐적 사용 |

### 강조색 사용 원칙
- 한 썸네일에 **1~2가지** 강조색만 사용 (혼잡 방지)
- 강조는 반드시 **핵심 키워드 1~2 단어**에만 적용
- Green + Purple 조합이 가장 많음
- 제품명("프로필 링크", "CdBd")은 Yellow 또는 Purple 처리

---

## 3. 타이포그래피

### 폰트 사양
| 항목 | 값 |
|------|-----|
| **폰트** | Pretendard (추정) |
| **언어** | 한국어 |
| **웨이트** | Bold / ExtraBold (700~800) |
| **크기** | 약 34~46px (600px 캔버스 기준) |
| **행간 (Line Height)** | 1.3~1.4 (tight, 임팩트 있게) |
| **자간** | 기본 또는 약간 타이트 |

### 헤드라인 작성 규칙
- **2~4줄** 구성 (한 줄 최대 약 13~16자)
- 마지막 줄이나 핵심 구문에 강조색 적용
- 따옴표 `'키워드'`로 특정 기능/서비스명 강조하는 패턴 자주 사용
- 의문형(`?`) 또는 명사형 종결로 궁금증 유발
- 브랜드명("CdBd", "프로필 링크")은 반드시 헤드라인에 포함

### 헤드라인 패턴 예시
```
[문제 상황 제시]
[해결책/방법]
[핵심 키워드] ← 강조색
```
```
[타겟 독자 호명]
[핵심 기능/혜택]
[브랜드 언급] ← 강조색
```

## 4. 레이아웃 패턴

### 표준 레이아웃 (전체 썸네일의 ~85%)

```
┌────────────────────────────────────────┐
│                                        │
│  [헤드라인       ]   [  비주얼 요소  ] │
│  [텍스트         ]   [  (모바일     ] │
│  [블록           ]   [   목업)      ] │
│                       [              ] │
└────────────────────────────────────────┘
   ← 약 42% →          ← 약 58% →
```

- 텍스트 블록: **좌상단 정렬**
- 비주얼 요소: **우측 전체** 또는 **우하단**
- 텍스트 시작 여백: 상단 약 30~40px, 좌측 약 30~40px

### 변형 레이아웃 (일러스트/3D 중심)

```
┌────────────────────────────────────────┐
│  [헤드라인              ]              │
│  [텍스트                ]              │
│                                        │
│           [3D 오브젝트 / 이모지]       │
└────────────────────────────────────────┘
```

- 텍스트: 상단 전폭
- 비주얼: 하단 우측 배치
- 3D 아이콘이나 이모지 캐릭터 활용

---

## 5. 비주얼 요소 유형

### Type A — 모바일 목업 (가장 많이 사용)
- **다크 프레임 iPhone** 목업 (2~3개)
- 목업 내부에 실제 CdBd 페이지 스크린샷 삽입
- 목업들을 **비스듬히 겹쳐** 배치 (깊이감 연출)
- 색상: 다크 모드 iPhone 프레임

### Type B — 3D 오브젝트
- 특정 개념을 상징하는 3D 렌더링 아이콘
- 예: 집 아이콘 (홈페이지), 채팅 말풍선 (상담), 손/스마트폰
- 배경색과 자연스럽게 어울리는 색상 사용

### Type C — 이모지/캐릭터
- 애플 memoji 스타일 사람 캐릭터
- 감정 표현용 (생각하는 포즈, 놀라는 표정 등)
- 텍스트의 정서를 시각적으로 강화

### Type D — 데코 요소
- 별/스파클 아이콘 (`✦` `✧` `★`)
- 마법 지팡이, 브러시 등 아이콘
- 강조 포인트로 소량 사용

### CdBd 브랜드 로고
- 일부 썸네일 우상단에 배치
- `## CdBd` 형태 (해시(‡) 심볼 + "CdBd" 텍스트)
- 색상: Purple/Blue 계열

---

## 6. 합성 원칙 (Composition Rules)

1. **단순하게** — 텍스트 + 비주얼 딱 2가지 요소만
2. **어둡게** — 밝은 배경 절대 사용 안 함 (브랜드 일관성)
3. **크게** — 헤드라인은 캔버스의 40% 이상을 차지하도록
4. **강조 1~2개** — 색 강조는 최대 2개 단어/구문
5. **모바일 우선** — 비주얼 요소는 항상 iPhone 목업이나 모바일 UI
6. **여백 확보** — 텍스트와 비주얼 사이 충분한 여백 유지

## 8. Claude에게 이미지 제작 요청하는 프롬프트 템플릿

### 기본 프롬프트 템플릿

```
CdBd 블로그 썸네일 이미지를 만들어줘.

[디자인 시스템 규칙]
- 크기: 600 × 450px
- 배경: #111111 (다크 네이비 블랙)
- 레이아웃: 좌측 40%에 텍스트 블록, 우측 60%에 비주얼 요소
- 텍스트: Pretendard Bold, 흰색 (#FFFFFF), 34~44px
- 강조색: [GREEN #4ADE80 / PURPLE #8B5CF6 / YELLOW #FBBF24] 중 선택
- 비주얼: 다크 프레임 iPhone 목업 2~3개 (비스듬히 겹침), 또는 3D 아이콘

[이번 썸네일 내용]
- 제목: [제목 입력]
- 강조할 키워드: [키워드]
- 강조색: [그린 / 퍼플 / 옐로 선택]
- 비주얼 요소: [모바일 목업 / 3D 아이콘 / 이모지 중 선택]
- 목업 내용 (선택): [어떤 화면을 보여줄지]
```

### 변형 프롬프트 — 3D 오브젝트 버전

```
CdBd 블로그 썸네일 (600×450px, 다크 배경 #111111) 디자인

헤드라인: "[제목]"
- [키워드] 부분을 #4ADE80 그린으로 강조

비주얼: 우하단에 3D 스타일 [오브젝트 설명] 아이콘 배치
         (밝고 입체적인 3D 렌더링 스타일)

텍스트는 좌상단에 Bold 한국어로, 강조 없는 부분은 흰색.
전체적으로 심플하고 임팩트 있게.
```
