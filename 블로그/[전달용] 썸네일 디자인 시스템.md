# CdBd 블로그 썸네일 디자인 시스템

> 이 문서는 **CdBd 블로그 썸네일(600×450)**을 일관된 룩앤필로 제작하기 위한 가이드입니다.
> 컬러·타이포그래피·5가지 템플릿·비주얼 요소 규칙이 정의되어 있어요.

---

## 📋 한눈에 보기

| 항목 | 값 |
|------|-----|
| 캔버스 | 600 × 450 px (4:3) |
| 배경 | `#141414` |
| 폰트 | Noto Sans KR |
| 타이틀 | Bold 36px / 흰색 `#FFFFFF` |
| 서브타이틀 | Medium 24px / `#4DE98B` 또는 `#8F80FF` |
| 강조색 | 그린 `#4DE98B` · 퍼플 `#8F80FF` (한 썸네일에 1가지만) |
| 좌측 여백 | 40px (고정) |
| 우측 여백 (목업) | 40px (고정) |

| 항목 | 값 |
|------|-----|

| 비율 | 4 : 3 |
| 포맷 | PNG |

## 2. 컬러

### 배경
| 역할 | HEX |
|------|-----|
| 기본 배경 | `#141414` |

### 텍스트
| 역할 | HEX | 사용 위치 |
|------|-----|-----------|
| 타이틀 | `#FFFFFF` | 메인 제목 전체 |
| 강조 — Green | `#4DE98B` | 타이틀 키워드 인라인 강조 |
| 강조 — Purple | `#8F80FF` | 서브타이틀 전체 또는 타이틀 첫 줄 강조 |

### 강조색 사용 규칙
- 한 썸네일에는 **딱 1가지 강조색**만 사용
- **타이틀만 있을 때**: 핵심 단어/줄에 인라인으로 강조색 적용
- **서브타이틀이 있을 때**: 서브타이틀 줄 전체를 강조색으로, 타이틀은 흰색 유지

---

## 3. 타이포그래피

| 역할 | 폰트 | 웨이트 | 크기 | 행간 | 색상 |
|------|------|--------|------|------|------|
| **타이틀** | Noto Sans KR | Bold | 36px | 1.3 | `#FFFFFF` (+ 인라인 강조) |
| **서브타이틀** | Noto Sans KR | Medium | 24px | 1.3 | `#4DE98B` 또는 `#8F80FF` |

### 텍스트 작성 규칙
- 타이틀은 **2~4줄**로 구성
- 따옴표 `'키워드'`로 특정 기능명·서비스명 강조하는 패턴 자주 사용
- **줄바꿈은 직접 끊을 것** — 자동 줄바꿈에 강조 단어가 분리되지 않게

## 4. 템플릿 5종

> 좌측 여백 `40px`, 배경 `#141414`, 캔버스 600×450 — 공통

### Template 1 — 타이틀-상단
타이틀이 상단에 위치. 비주얼은 하단 또는 우측.

```
┌──────────────────────────────────────────┐  top: 40px
│  [타이틀                ]                │
│  [타이틀 강조 줄         ]                │
│                                          │
│                  [ 비주얼 영역 ]         │
└──────────────────────────────────────────┘
```
| 항목 | 값 |
|------|----|
| 텍스트 위치 | `left: 40px / top: 40px` |
| 폰트 | Noto Sans KR Bold 36px / `#FFFFFF` (+ `#4DE98B` 또는 `#8F80FF` 강조) |
| 비주얼 | 하단·우측 자유 배치 (텍스트와 겹치지 않게) |

---

### Template 2 — 타이틀-하단
비주얼이 상단, 타이틀이 하단에 위치.

```
┌──────────────────────────────────────────┐
│                  [ 비주얼 영역 ]         │
│                                          │
│  [타이틀 강조 줄         ]                │  ↑
│  [타이틀                ]                │  bottom: 40px
│  [타이틀                ]                │
└──────────────────────────────────────────┘
```
| 항목 | 값 |
|------|----|
| 텍스트 위치 | `left: 40px / bottom: 40px` (줄 수에 따라 top값 가변) |
| 폰트 | Noto Sans KR Bold 36px / `#FFFFFF` (+ 강조) |
| 비주얼 | 상단·우측 위주 (텍스트와 겹치지 않게) |

---

### Template 3 — 타이틀+서브타이틀-상단
서브타이틀+타이틀이 상단에 위치.

```
┌──────────────────────────────────────────┐  top: 40px
│  [서브타이틀 — Medium 24px 강조색]        │
│  [타이틀 — Bold 36px #FFFFFF      ]      │
│  [타이틀                          ]      │
│                                          │
│                  [ 비주얼 영역 ]         │
└──────────────────────────────────────────┘
```
| 항목 | 값 |
|------|----|
| 텍스트 위치 | `left: 40px / top: 40px` |
| 서브타이틀 | Noto Sans KR Medium 24px / `#4DE98B` 또는 `#8F80FF` |
| 타이틀 | Noto Sans KR Bold 36px / `#FFFFFF` |
| 비주얼 | 하단·우측 자유 배치 |

---

### Template 4 — 타이틀+서브타이틀-하단
비주얼이 상단, 서브타이틀+타이틀이 하단에 위치.

```
┌──────────────────────────────────────────┐
│                  [ 비주얼 영역 ]         │
│                                          │
│  [서브타이틀 — Medium 24px 강조색]        │  ↑
│  [타이틀 — Bold 36px #FFFFFF      ]      │  bottom: 40px
│  [타이틀                          ]      │
└──────────────────────────────────────────┘
```
| 항목 | 값 |
|------|----|
| 텍스트 위치 | `left: 40px / bottom: 40px` |
| 서브타이틀 | Noto Sans KR Medium 24px / `#4DE98B` 또는 `#8F80FF` |
| 타이틀 | Noto Sans KR Bold 36px / `#FFFFFF` |
| 비주얼 | 상단 영역 자유 배치 |

---

### Template 5 — 텍스트 중앙
배경에 관련 이미지 깔고, 텍스트는 세로 중앙.

```
┌──────────────────────────────────────────┐
│  (배경: 관련 이미지 opacity 20%)         │
│                                          │
│  [타이틀                ]  [ 비주얼 ]   │  ← 세로 중앙
│  [타이틀                ]  [       ]    │
│  [타이틀                ]  [       ]    │
│                                          │
└──────────────────────────────────────────┘
```
| 항목 | 값 |
|------|----|
| 텍스트 위치 | `left: 40px / top: 50%` (세로 중앙) |
| 폰트 | Noto Sans KR Bold 36px / `#FFFFFF` (강조색 없이 전부 흰색) |
| 배경 | `#141414` 위에 관련 이미지 **opacity 20%** 오버레이 |
| 비주얼 | 우측 세로 중앙 정렬 |

## 5. 비주얼 요소

비주얼은 **역할**에 따라 두 가지로 나뉜다.

### 5.1. 주 비주얼 (Main) — 시선의 초점

| 유형 | 설명 | 준비 방법 | 크기·배치 규칙 | 출처 |
|------|------|-----------|--------------|------|
| **목업** | CdBd 앱 화면 + iPhone 프레임 | 피그마 목업 프레임의 `#FFFFFF` 영역에 캡처 화면 삽입 | 우측 여백 **40px** / 텍스트와의 간격 **≥ 30px** / 하단 = 텍스트 끝선과 정렬 / **크기는 가용 공간 안에서 자연스럽게** (텍스트가 길면 작게, 짧으면 크게 — 비율은 유지) | **프레임**: [피그마 목업 프레임](https://www.figma.com/design/1gduKu9Bg319AMqgFrgjTw/CdBd-블로그-템플릿?node-id=4639-226) <br>**화면 캡처**: `{템플릿 URL}/viewer` 사용 (예: `/templates/catalog/newarrival/viewer`) |
| **3D 오브젝트** | 개념을 상징하는 3D 아이콘 (집, 말풍선, 손 등) | 다운로드 후 삽입 | 250~300px 정도 (캔버스 1/2 이내) | [Thiings](https://www.thiings.co/things) |
| **배경 이미지** | 주제 관련 사진/스크린샷 (**Template 5 전용**) | 캡처 → opacity 20% 처리 | 캔버스 전체 / opacity **20%** | [CdBd 템플릿](https://www.cdbd.in/templates/all) |

### 5.2. 보조 비주얼 (Sub) — 보완·강조

| 유형 | 용도 | 예시 | 크기·배치 규칙 | 출처 |
|------|------|------|--------------|------|
| **이모지/캐릭터** | 정서·감정 강화 | memoji 캐릭터, 손 이모지 | 100~150px 이내 / 주 비주얼 옆 | Apple Memoji style |
| **데코** | 시선 유도·임팩트 | 스파클, 별, 마법 지팡이 | **50×50px 이하** / **주 비주얼과 겹치는 위치** (포인트 강조) | [Thiings](https://www.thiings.co/things), [Unicode Emoji](https://home.unicode.org/) |
| **앱/서비스 아이콘** | 비교 대상 명시 | 링크트리, Jasper 로고 | 60×60px 이하 / 주 비주얼 주변 산포 | 각 서비스 공식 로고 (SVG/배경 없는 PNG) |
| **UI 요소** | 맥락 추가 | 채팅 말풍선, 카드, 폼 | 주 비주얼의 1/3 이하 / 주 비주얼 근처 | 직접 디자인, [Figma Community](https://www.figma.com/community) |

> **공통 원칙**: 보조 비주얼은 주 비주얼보다 작아야 함. **시각적 무게 = 주 > 보조**

## 6. 조합 규칙

### 6.1. 개수
| 역할 | 개수 |
|------|-----|
| 주 비주얼 | **반드시 1개** (시각적 초점 분산 금지) |
| 보조 비주얼 | **0~3개** (그 이상이면 산만) |

> 목업 여러 개(2~3개 겹침)는 "한 덩어리" = 주 비주얼 1개로 취급

### 6.2. 원칙
1. **역할이 명확해야 함** — 주/보조 중 어느 것이 핵심인지 한눈에
2. **텍스트와 겹치지 않기** — 비주얼이 글자를 가리면 안 됨
3. **여백 확보** — 비주얼끼리, 그리고 텍스트와의 여백을 충분히

## ✅ 새 썸네일 만들 때 체크리스트

1. [ ] 어떤 **템플릿**을 쓸지 결정 (1~5번)
2. [ ] **타이틀** 작성 (2~4줄, 줄바꿈 직접 끊기)
3. [ ] (Template 3·4) **서브타이틀** 한 줄 작성
4. [ ] **강조 키워드** 1~2개 + **강조색** 1가지 선택 (그린 or 퍼플)
5. [ ] **주 비주얼** 1가지 선택 (목업 / 3D / 배경이미지)
6. [ ] **보조 비주얼** 필요 시 1~3개 추가 (선택)
7. [ ] 모든 요소가 **겹치지 않고 여백 확보**되었는지 확인
8. [ ] 캔버스 600×450, 배경 `#141414` 확인 후 PNG 내보내기
