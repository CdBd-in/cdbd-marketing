## 🧩 How — 3개 기둥

```
                  🌟 타이틀 → 자동 썸네일
                          │
   ┌──────────────────────┼────────────────────┐
   │                      │                    │
 [디자인 가이드]        [자동 캡처 인프라]      [Figma MCP]
 규칙 + 소재집            최신 자료 수집          제작 엔진
"어떻게 + 무엇을"         Playwright            생성 엔진
```

> **디자인 가이드**가 "어떻게 그릴까(규칙)"와 "무엇을 넣을까(소재집)"를 모두 포함.
> 소재집은 이미지 규칙이 정의한 슬롯에 넣을 실제 자산을 결정하므로 디자인 가이드 하위(`1-3. 이미지`)에 속함.

## ⚙️ 파이프라인 (타이틀 → 썸네일)

> **순서 원리 — 이미지 주도 + 베리에이션**: 타이틀 1개 → 이미지 유형 1개 → **자산 후보 1-2개 × 슬롯 변형 2 = 2-4안 자동 제작** → 사용자 선택. 단일 결정이 아니라 **다중 후보 + 변형 매트릭스**.

1. **입력 (intake)** — 타이틀(필수) + 서브타이틀(시리즈면, 선택)을 받음 → [[1-4. 프롬프트]] §1
2. **이미지 유형 결정** — 타이틀에서 이미지 유형 1개 확정 (A·B·C·D·E) → [[1-2-1. 레이아웃 규칙]] §1.1
3. **자산 후보 1-2개 추출** — 1a 기능·1b 산업·1d 톤 다층 분석 → 1·2순위 자산 후보 → [[1-3-2. 이미지 출처]] §1 Step 2
4. **자산 수집** — Microlink 캡처 / Thiings 다운로드 / Playwright (후보별)
5. **N안 자동 제작** — 자산 후보 1-2 × 슬롯 변형(상/하) 2 = **2-4안** 자동 생성. 각 안: 슬롯 clone → 타이틀 의미 단위 줄 나누기·강조색([[1-1. 스타일]]) + 이미지 슬롯에 의미 영역 크롭 fill + 보조 동적 배치
6. **검수·선택** (휴먼) — 2-4안 중 1개 선택 → home.cdbd.in/blog 발행

> 2단계에서 이미지 유형이 정해지면 → 4단계에서 (위치·서브만 더해) 레이아웃 1칸이 확정되고 → 5단계에서 슬롯의 정해진 자리에 텍스트·이미지를 채운다.
> 위치 기준: 슬롯 템플릿([[1-2-1. 레이아웃 규칙]] §2) — 주 이미지는 슬롯이 자동 정의 / 보조 이미지는 [[1-3-1. 이미지 규칙]] §1.2.a 알고리즘으로 동적 배치.
