# 🌟 목표 & 비전 — 블로그 썸네일 자동 생성

> 이 폴더(`1. 썸네일`)의 모든 작업이 향하는 **북극성(North Star)**.
> 새 세션은 항상 이 문서로 시작해 "지금 작업이 이 목표에 어떻게 기여하는가"를 점검한다.

---

## 한 문장으로

> **[home.cdbd.in/blog](https://home.cdbd.in/blog)에 발행되는 모든 블로그 글의 썸네일을, 타이틀(+시리즈면 서브타이틀)만 주면 Claude가 디자인 가이드에 맞춰 자동 생성한다.**

> 입력 = **타이틀(필수) + 서브타이틀(시리즈면, 선택)**. 강조 키워드·강조색·템플릿·비주얼은 Claude가 자동 제안/결정. (서브타이틀·시리즈 번호는 타이틀에서 추측 불가 → 입력 필요)

---

## 🎯 Why — 왜 이걸 하는가

- 블로그는 CdBd의 핵심 **마케팅·SEO·리드 채널**
- **글 발행 속도 ≠ 썸네일 제작 속도** → 콘텐츠 파이프라인의 가장 느린 구간

---

## 🔄 As-is → To-be

| | As-is (지금) | To-be (목표) |
|---|---|---|
| **입력** | 디자이너에게 구두 요청 | 타이틀 + (시리즈면) 서브타이틀 |
| **제작** | 사람이 매번 수작업 | Claude 자동 생성 |
| **시간** | 글 1개당 30분~1시간 | 분 단위 |
| **일관성** | 작업자마다 편차 | 디자인 가이드 100% 준수 |
| **사람 역할** | 제작자 | **검수·승인자** (80% 자동 / 20% 휴먼) |

---

## 🧩 How — 3개 기둥

```
                  🌟 타이틀 → 자동 썸네일
                          │
   ┌──────────────────────┼────────────────────┐
   │                      │                    │
 [디자인 가이드]        [자동 캡처 인프라]      [Figma MCP]
 규칙 + 소재집            최신 자료 수집          제작 엔진
"어떻게 + 무엇을"         Playwright            생성 엔진
```

> **디자인 가이드**가 "어떻게 그릴까(규칙)"와 "무엇을 넣을까(소재집)"를 모두 포함.
> 소재집은 비주얼 규칙이 정의한 슬롯에 넣을 실제 자산을 결정하므로 디자인 가이드 하위(`1-3. 이미지`)에 속함.

| 기둥 | 역할 | 위치 | 현재 상태 |
|------|------|------|----------|
| **디자인 가이드** | 어떻게 그릴까(규칙) + 무엇을 넣을까(소재집) | `1. 디자인 가이드/` — [[1-1. 스타일]] · [[1-2-1. 레이아웃 규칙]] · [[1-2-2. 레이아웃별 레퍼런스 노드]] · [[1-3-1. 이미지 규칙]] · [[1-3-2. 이미지 리소스 북]] · [[1-4. 프롬프트]] | 🟢 성숙 |
| **자동 캡처 인프라** | 최신 콘텐츠 자동 수집 (로그인 필요 화면 포함) | `scripts/cdbd-capture/` | 🟡 구축됨 |
| **Figma MCP** | 실제 제작 엔진 (공식 목업 + 규칙 적용) | CdBd 블로그 템플릿 파일 | 🟢 검증됨 |

## ⚙️ 파이프라인 (타이틀 → 썸네일)

> **결정 순서**: 템플릿이 정해져야 타이틀 스타일링(위치·서브타이틀·강조색)이 정해진다. 그래서 **분석 → 템플릿 결정 → 타이틀 스타일링** 순.
> **★ 타이틀이 주인공**: 타이틀의 줄 나누기·강조가 썸네일 인상을 좌우하는 가장 중요한 요소. 단 **타이틀·비주얼 위치는 템플릿/슬롯이 이미 규정**하므로 정해진 자리에 채운다.

```
입력: 타이틀(필수) + 서브타이틀(시리즈면, 선택)   ← intake로 받음 ([[1-4. 프롬프트]] §1)
   │
   ▼
① 분석 ([[1-3-2. 이미지 리소스 북]] §1)     ──→ 기능명 / 산업 / 형식 / 톤 + 주 비주얼 유형 추출
   │
   ▼
② 템플릿 결정 ([[1-2-1. 레이아웃 규칙]] §1)  ──→ ★ 서브타이틀 유무 + 비주얼 유형 → 슬롯 템플릿 or T1~5 확정
   │
   ▼
③ 타이틀 스타일링 ([[1-1. 스타일]])        ──→ (템플릿 확정 후) 의미 단위 줄 나누기 + 강조어 자동 제안 + 강조색
   │                                        (강조색·위치는 템플릿이 이미 규정 / 줄 수 2~4)
   ▼
④ 자산 수집                              ──→ Microlink 캡처 / Thiings 다운로드 / Playwright
   │
   ▼
⑤ Figma 생성                            ──→ ★ 슬롯이면 clone+채우기 / 레이아웃이면 직접 (템플릿이 정한 자리에 타이틀·비주얼 배치, 의미 영역 크롭)
   │
   ▼
⑥ 검수·승인 (휴먼)                        ──→ home.cdbd.in/blog 발행
```

> ②에서 템플릿이 확정되면 **타이틀·비주얼 위치가 모두 규정**된다 → ⑤에서 정해진 자리에 채운다.
> 위치 기준: 슬롯 템플릿([[1-2-1. 레이아웃 규칙]] §2) 또는 레이아웃 배치 기준([[1-3-1. 이미지 규칙]] §2.3).

## ✅ 성공 기준 (이게 되면 목표 달성)

1. **병목 제거** — 새 블로그 글 발행 시 썸네일이 즉시 따라옴
2. **일관성** — 100개 썸네일을 모아 봐도 하나의 룩앤필
3. **역할 전환** — 디자이너는 "검수·승인"만, "제작"은 Claude가
4. **자가 갱신** — CdBd에 신규 템플릿/기능 추가되면 소재집도 자동 동기화

## 🚧 목표까지 남은 큰 과제

1. **콘텐츠 완성** — 에디터 기능(팀공유·QR·AI 디자인) 캡처 + 매핑
2. **자동 매핑 정확도** — 타이틀 10~20개로 매핑 정확도 측정·튜닝
3. **공식 목업 자동 활용** — clone + fill 워크플로우 스크립트화
4. **휴먼 개입 최소화** — 현재 매 단계 확인 → 명백한 케이스는 무확인 자동 진행
5. **CdBd 자동 동기화** — 신규 템플릿/기능 주기적 크롤링 → 소재집 갱신
