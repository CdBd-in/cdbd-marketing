## 1. 레이아웃 적용 절차 (타이틀 → 썸네일)

> **핵심**: 타이틀을 받으면 **자동생성용 슬롯 템플릿(§2)을 먼저** 확인한다.
> 맞는 슬롯 템플릿이 있으면 그걸 clone해서 끼워넣고, **없으면** Template 1~5 레이아웃(§3)으로 직접 제작한다.

```
타이틀 입력
   │
   ▼
① 설계 파악
   - 서브타이틀? : 시리즈·카테고리 라벨 있나 ("시리즈 #N", "○○ 편:", "디지털 카탈로그 시리즈")
   - 주 이미지 유형? : 세로목업 / 3D 오브젝트 / 멀티목업 / 배경 이미지
   - 강조색은 서브타이틀 유무로 자동 ([[1-1. 스타일]])
   │
   ▼
② 맞는 슬롯 템플릿(§2)이 있나?
   ├─ YES → 그 TPL 프레임을 clone → TITLE/SUBTITLE·VISUAL_SLOT만 채움 (위치·크기 고정, 1순위)
   │
   └─ NO  → ③ 레이아웃(§3) Template 1~5로 직접 제작
              · 텍스트 우선 ([[1-3-1. 이미지 규칙]] §0)
              · 이미지 배치 기준 ([[1-3-1. 이미지 규칙]] §2.3)
```

### 1.1. 레이아웃 결정 기준 — (서브타이틀 유무 + 이미지 유형) → 레이아웃

> 레이아웃은 따로 고르는 게 아니라 **아래 두 가지가 정해지면 자동으로 확정**된다.
> "상단이냐 하단이냐"는 이미지 유형에 묶여 있어 별도로 판단하지 않는다.

**① 서브타이틀 유무** — 입력으로 받음 (타이틀에서 추측 불가). 시리즈·카테고리 라벨이 있으면 "서브 있음".

**② 주 이미지 유형** — 타이틀의 *형식*에서 도출 ([[1-3-2. 이미지 리소스 북]] §1c):

| 타이틀 형식 단서 | 주 이미지 유형 |
|---|---|
| "X 만들고 / 활용법 / 사용 사례" (단일 기능 데모) | 세로목업 |
| "X와 Y / A·B" (복수 화면) | 멀티목업 |
| "X란? / 왜 X? / X vs Y" (컨셉·비교) | 3D 오브젝트 |
| "Best N / 추천 / 리스트 / 노하우" (특정 화면 없음) | 배경 이미지 |

**→ (서브 유무 × 이미지 유형) = 레이아웃 확정** (이 매핑 = 슬롯 템플릿 5종과 일치):

| 주 이미지 유형 | 서브 없음 | 서브 있음 | 텍스트 위치 (이유) |
|---|---|---|---|
| **세로목업** | **T2** | **T4** | 하단 — 목업이 우측 전체 높이 차지·하단 블리드 → 타이틀 하단 대각선 |
| **멀티목업** | **T1** | T3 | 상단 — 목업들이 하단 밴드 차지 → 타이틀 상단 |
| **3D 오브젝트** | **T1** | T3 | 상단 — 오브젝트가 중앙우측 → 타이틀 상단 대각선 |
| **배경 이미지** | **T5** | T5 | 중앙 — 배경 전체 + 중앙 텍스트 |

> ⚠️ 데이터(예시 60개)상 세로목업은 상·하단 모두 쓰였으나, **자동화 일관성을 위해 위 매핑을 컨벤션으로 고정**한다 (자연법칙 아님).

> **현재 슬롯 템플릿은 5종** (§2.1): `T1+3D 정사각` · `T1+멀티목업` · `T5+배경` · `T2+세로목업` · `T4+세로목업`.
> 그 외 잔여 조합(T3 상단+서브, title-top 세로목업 등)은 아직 §3 레이아웃으로 직접 제작 → 자주 나오는 조합은 슬롯 템플릿으로 승격 예정.

## 2. 슬롯 템플릿 (자동생성용 — 1순위) ⭐

> 위치·크기·폰트·색·정렬이 **고정된 빈 슬롯**에 끼워넣기만 → 매번 좌표 계산 불필요.
> [[1-3-1. 이미지 규칙]] §2.3 실측 배치값을 **Figma 실물 템플릿**으로 만들어 둔 것.

- **Figma 파일**: CdBd 블로그 템플릿 (`1gduKu9Bg319AMqgFrgjTw`)
- **페이지**: 🧩 썸네일 자동생성 템플릿 (슬롯) — `4738:1822`

### 2.1. 제작된 템플릿 목록

| 템플릿 | node ID | 레이아웃 | 이미지 유형 (빈도) | 강조색 | 슬롯 node ID |
|--------|---------|---------|------------------|--------|-------------|
| **TPL · T1 + 3D 정사각** | `4746:1822` | 타이틀-상단 | 3D 정사각 (11, 최다) | 퍼플 | `VISUAL_SLOT 4746:1823` / `TITLE 4746:1824` |
| **TPL · T1 + 멀티목업**        | `4747:1822` | 타이틀-상단    | 멀티목업 (7)        | 퍼플            | `VISUAL_SLOT_1/2/3 4747:1823·1824·1825` / `TITLE 4747:1826`                                 |
| **TPL · T5 + 배경**          | `4748:1822` | 텍스트 중앙    | 배경 (6)          | 없음(흰색)        | `BG_SLOT 4748:1823` / `VISUAL_SLOT(보조) 4748:1824` / `TITLE 4748:1825`                       |
| **TPL · T4 + 세로목업 cutoff** | `4738:1823` | 타이틀+서브-하단 | 세로목업 (3)        | 그린 (서브+강조 통일) | `VISUAL_SLOT 4738:1824` / `TEXT_BLOCK 4738:1825` (`SUBTITLE 4738:1826` · `TITLE 4738:1827`) |
| **TPL · T2 + 세로목업 cutoff** | `4739:1822` | 타이틀-하단    | 세로목업 (5)        | 퍼플 (강조)       | `VISUAL_SLOT 4739:1823` / `TITLE 4739:1824`                                                 |

> **슬롯 위치 스펙** (실측, 600×450 기준):
> - **세로목업 cut-off** (T2·T4): `VISUAL_SLOT` = `x353 / y68 / w217 / h457`, 하단 블리드
> - **3D 정사각** (T1): `VISUAL_SLOT` = `x300 / y160 / w·h 260`, contain(블리드 X)
> - **멀티목업** (T1): `VISUAL_SLOT_1 x46/y215` · `_2 x229/y175` · `_3 x412/y215`, 각 `w143 / h340`, 하단 블리드(엇갈림)
> - **배경** (T5): `BG_SLOT` 전체 `600×450`(이미지 opacity 20%) + 우측 보조 `VISUAL_SLOT x320/y110/w·h230`
> - **텍스트**: 좌측 `x40` 고정 / 상단형 `top 40` · 중앙형(T5) 세로중앙 · 하단형 `bottom 40`
>
> **미제작 (확장 예정)**: T3(상단+서브)·title-top 세로목업·T2 3D 등 잔여 조합.

### 2.2. 사용 절차 (MCP `use_figma`)

1. **템플릿 clone** — 해당 `TPL` 프레임을 `clone()` → 새 위치에 `appendChild`
2. **`TITLE` 교체** — 폰트(`Pretendard Bold`) 로드 후 `characters` 설정
   - 줄바꿈은 의미 단위로 직접 → [[1-1. 스타일]] "텍스트 작성 규칙"
   - 강조어 구간 `setRangeFills` (그린/퍼플은 서브타이틀 유무로 자동 → [[1-1. 스타일]])
3. **(T4) `SUBTITLE` 교체** — `Pretendard Medium`, 그린
4. **`VISUAL_SLOT` 채우기**
   - 공식 목업 컴포넌트 `clone` ([[1-3-1. 이미지 규칙]] §1.1.a) → 슬롯 안에 배치, 슬롯 폭(217)에 맞춰 스케일
   - 목업 화면 영역에 viewer 캡처를 **의미 영역 크롭**으로 fill ([[1-3-1. 이미지 규칙]] §1.1.b)
5. **슬롯 placeholder 정리** — `VISUAL_SLOT`의 점선 stroke·반투명 fill 제거 (`node.strokes = []`, `node.fills = []`)
6. **하단 정렬 재조정** — 타이틀 줄 수가 기본(3줄)과 다르면 `TEXT_BLOCK`(T4)·`TITLE`(T2)의 `y = 410 - height`로 다시 맞춰 **하단 40px 유지**

### 2.3. 슬롯 이름 규칙 (노드 식별용)

| 이름 | 역할 |
|------|------|
| `VISUAL_SLOT` | 주 이미지(목업·3D) 자리 — 점선 placeholder |
| `VISUAL_SLOT_1/2/3` | 멀티목업 — 여러 개 슬롯 (좌→우) |
| `BG_SLOT` (T5) | 배경 이미지 자리 — 전체 캔버스, 이미지 opacity 20% |
| `TEXT_BLOCK` (T3·T4) | 서브타이틀+타이틀 묶음 (세로 auto-layout, 하단 정렬) |
| `TITLE` / `SUBTITLE` | 텍스트 노드 |

> ⚠️ 슬롯 이름은 자동화 스크립트가 `findOne`/`query`로 노드를 찾는 키이므로 **이름을 바꾸지 말 것**.

## 3. 레이아웃 5종 (슬롯 없을 때 직접 제작)
