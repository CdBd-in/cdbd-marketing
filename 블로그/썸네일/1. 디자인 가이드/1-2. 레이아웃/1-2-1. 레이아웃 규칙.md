# 레이아웃 규칙

> 레이아웃 = **이미지 유형 3종(목업·3D·멀티) × 타이틀 위치** + 서브타이틀(직교) + 배경(특수).
> 적용 절차(§1) → 슬롯 템플릿(§2, **1순위**) → 유형별 스펙(§3, 슬롯 없을 때 직접 제작).
> 기초 규칙(캔버스·컬러·타이포)은 → [[1-1. 스타일]] / 각 레이아웃 레퍼런스 노드 → [[1-2-2. 레이아웃별 레퍼런스 노드]]

---

## 1. 레이아웃 적용 절차 (타이틀 → 썸네일)

> 타이틀을 받으면 **이미지 유형 → 타이틀 위치 → 서브 유무** 순으로 좁힌다.
> 해당 칸의 슬롯 템플릿(§2)이 있으면 clone, 없으면 §3 스펙으로 직접 제작.

```
타이틀
   │
   ▼
① 이미지 유형 : 목업 / 3D 아이콘 / 멀티 목업              ← 타이틀에서 도출 (§1.1)
   │                                                  (특정 화면 없는 리스티클·컨셉 → 특수: 배경 §1.4)
   ▼
② 타이틀 위치 (변형) : 상단 / 하단                        ← 멀티=상단 고정 (§1.2)
   │
   ▼
③ 서브타이틀 유무 (직교 옵션) : 시리즈 라벨 있나 (입력)      ← 강조색도 여기서 자동 결정 (§1.3)
   │
   ▼
해당 칸의 슬롯 clone (§2) / 없으면 §3 스펙으로 직접
```

### 1.1. ① 이미지 유형 결정 (타이틀 → 유형)

> 핵심 질문: **"이 타이틀이 보여줄 CdBd 화면이 있는가? 하나인가 여럿인가? 없는가?"**
> (기존 썸네일 이미지 분석)

#### A. 목업 (단일) — 특정 CdBd 기능·페이지 **하나**를 시연
- **신호**: **기능명 직접 등장**(RSVP·예약 관리·프로필 링크·프로모션·상담 신청·룩북·서명), "X 활용법/제작/소개/**업데이트**", "X로 **끝내기/해결**"
- **실제 예시**:
  - "행사 **RSVP**, 엑셀 입력 말고 모바일 초대장으로 끝내세요"
  - "레이어 추가하기 **기능 업데이트**"
  - "**VIP 1:1 예약 관리**, 전화 핑퐁 모바일 초대장으로 끝내기"

#### B. 목업 + 에디터 기능 (A 목업의 결합 변형 — 별도 슬롯 없음)
타이틀이 CdBd **에디터/관리 기능**을 다루면 → 유형은 **목업**(복수면 멀티)이되, 주 이미지를 **"기능 UI(에디터 화면·표·카드) + 결과 목업" 결합**(한 덩어리)으로 구성. 목업/멀티 슬롯을 그대로 사용.
- **신호**: 에디터·관리 기능명 (레이어·카드 추가 / 팀 공유 / 데이터·CRM 업로드 / 통계 / QR / AI 디자인)
- 캡처 소스 → [[1-3-2. 이미지 리소스 북]] §3.2 (에디터 유래 기능)
- **실제 예시**:
  - "엑셀 업로드 → CRM 마케팅 자동화" = **데이터 표 + 목업**
  - "레이어 추가하기 **기능 업데이트**" = **카드 빌더 UI + 목업**

#### C. 멀티 목업 — 화면이 **둘 이상** 등장·암시
- **신호**: 복수 명시("A와 B", "명함과 브로셔"), "결합/여러 개", **카탈로그·룩북**(다중 페이지 속성), "페이지 빌더"(여러 종류 제작), 컬렉션·여정형
- **실제 예시**:
  - "모바일 명함**과** 브로셔 만들고 팀 전체에 공유하는 방법"
  - "코딩 없이 10분 완성! 모바일 **페이지 빌더** CdBd"
  - "한화 ANTO 모바일 브로셔 **+** 영업 명함 **결합** 운영"

#### D. 3D 아이콘 — 보여줄 특정 화면이 없는 **컨셉·주장**
- **신호**: "**왜 / 이유 / 진짜 이유**", 질문·주장형, 추상 개념(ESG·전환·신뢰), 비교("**대신 / vs / 갈아타는**"), "고집·주목"
- **실제 예시**:
  - "홈페이지 **대신** 프로필 링크로 갈아타야 하는 **이유**"
  - "기업이 비공개 초대장을 **고집해하는** 7가지 **이유**"
  - "상담 문의, 아직도 카톡으로 받으세요?" (문제 제기)

#### E. 배경 — CdBd 화면이 주인공이 **아닌** 외부 주제·리스티클 (특수, 매트릭스 밖 → §1.4)
- **신호**: "**Best N / N가지 / 추천**", 외부 툴·팁·일반 노하우, CdBd와 직접 무관한 마케팅 주제
- **실제 예시**:
  - "업무 효율 200% 높여줄, 직접 써보고 추천하는 **AI 툴 5가지**"
  - "일잘러를 위한 무료 이미지 사이트 **추천 Best 18**"

> **애매하면**: 기능명이 하나라도 명시되면 A(목업) 우선 / 에디터 기능이면 B / 복수 화면이면 C(멀티) / 화면 없으면 D·E. 끝까지 모호하면 사용자에게 확인.
> 더 깊은 분석(기능명·산업·형식·톤 4축) → [[1-3-2. 이미지 리소스 북]] §1

### 1.2. ② 타이틀 위치 (변형) — 3종 × 상단/하단

| 이미지 유형 | 타이틀 상단 | 타이틀 하단 |
|---|---|---|
| **목업** (우측 세로·하단 블리드) | ✅ | ✅ |
| **3D 아이콘** (중앙우측·contain) | ✅ | ✅ |
| **멀티 목업** (하단 밴드) | ✅ | ✗ (상단 고정) |

> **멀티 목업**: 하단 밴드를 목업이 차지 → 타이틀 **상단 고정** (하단 변형 없음).

### 1.3. ③ 서브타이틀 (직교 옵션)

위 각 칸은 **서브타이틀 유무로 2배 변형**된다 (시리즈·연재 글이면 +서브타이틀 한 줄).
- **강조색** (자동, [[1-1. 스타일]]): 서브 있으면 **그린**(서브+강조 통일) / 없으면 **퍼플**.

→ 핵심 매트릭스 = 3종 × 2위치 × 2서브 = **10칸** (멀티·하단 2칸 제외).

### 1.4. 특수 레이아웃 — 배경 (매트릭스 밖)

타이틀 **중앙 고정** + 전체 배경 이미지(opacity 20%). 위치 변형 없음.
- `배경·중앙` / `배경·중앙·서브` (서브는 직교) — 텍스트 **전부 흰색**(강조색 없음).

## 2. 슬롯 템플릿 (1순위) ⭐

> 위치·크기·폰트·색·정렬이 **고정된 빈 슬롯**에 끼워넣기만 → 매번 좌표 계산 불필요.
> **핵심 매트릭스 10칸 + 배경 특수 2종 = 12종** 모두 Figma 실물 템플릿으로 제작 완료.

- **Figma 파일**: CdBd 블로그 템플릿 (`1gduKu9Bg319AMqgFrgjTw`)
- **페이지**: 🧩 썸네일 자동생성 템플릿 (슬롯) — `4738:1822`

| 이미지 유형 | 변형 | 프레임 node ID | 슬롯 (이름) |
|---|---|---|---|
| **목업** | 목업·상단 | `4752:1822` | `VISUAL_SLOT` · `TITLE` |
| | 목업·상단·서브 | `4752:1825` | `VISUAL_SLOT` · `TEXT_BLOCK`(`SUBTITLE`·`TITLE`) |

| **3D 아이콘** | 3D·상단 | `4746:1822` | `VISUAL_SLOT` · `TITLE` |

### 2.2. 사용 절차 (MCP `use_figma`)

1. **템플릿 clone** — 해당 프레임을 `clone()` → 새 위치에 `appendChild`
2. **`TITLE` 교체** — 폰트(`Pretendard Bold`) 로드 후 `characters` 설정
   - 줄 나누기는 의미 단위로 직접 → [[1-1. 스타일]] "텍스트 작성 규칙"
   - 강조어 구간 `setRangeFills` (그린/퍼플은 서브 유무로 자동 → [[1-1. 스타일]])
3. **(서브 변형) `SUBTITLE` 교체** — `Pretendard Medium`, 그린
4. **이미지 슬롯 채우기**
   - 목업: 공식 목업 컴포넌트 `clone` ([[1-3-1. 이미지 규칙]] §1.1.a) → 슬롯 폭에 맞춰 스케일 + **의미 영역 크롭** fill ([[1-3-1. 이미지 규칙]] §1.1.b)
   - 3D: Thiings PNG fill / 멀티: 각 슬롯에 목업 / 배경: `BG_SLOT`에 이미지(opacity 20%)
5. **슬롯 placeholder 정리** — 점선 stroke·반투명 fill 제거 (`node.strokes = []`, `node.fills = []`)
6. **하단·중앙 정렬 재조정** — 타이틀 줄 수가 기본과 다르면 `TEXT_BLOCK`/`TITLE`의 `y`를 다시 계산 (하단형 `y = 410 - height`, 중앙형 `y = (450 - height) / 2`)

### 2.3. 슬롯 이름 규칙 (노드 식별용)

| 이름 | 역할 |
|------|------|
| `VISUAL_SLOT` | 주 이미지(목업·3D) 자리 — 점선 placeholder |
| `VISUAL_SLOT_1/2/3` | 멀티목업 — 여러 슬롯 (좌→우) |
| `BG_SLOT` (배경) | 배경 이미지 자리 — 전체 캔버스, 이미지 opacity 20% |
| `TEXT_BLOCK` (서브 변형) | 서브타이틀+타이틀 묶음 (세로 auto-layout) |
| `TITLE` / `SUBTITLE` | 텍스트 노드 |

> ⚠️ 슬롯 이름은 자동화 스크립트가 `findOne`/`query`로 노드를 찾는 키이므로 **이름을 바꾸지 말 것**.

## 3. 유형별 레이아웃 스펙 (슬롯 없이 직접 제작 시)

> 공통: 캔버스 600×450 / 배경 `#141414` / radius 24 / 좌측 여백 `x40` 고정 / `clipsContent` (블리드용).
> 텍스트 위치 — **상단** = `top 40` / **하단** = `bottom 40` (`y = 410 - height`) / **중앙** = 세로 중앙.
> 이미지 배치 원리(대각선 균형) → [[1-3-1. 이미지 규칙]] §2.3

### 3.1. 목업 (단일 세로 목업)
- **이미지 슬롯**: `x353 / y68 / w217 / h457` (우측, **하단 cut-off 블리드**) — 상단·하단 변형 공통
- **텍스트**: 좌측. 상단형 = top 40 / 하단형 = bottom 40
- 목업 화면에 viewer 캡처를 **의미 영역 크롭**으로 fill

### 3.2. 3D 아이콘
- **이미지 슬롯**: `w·h 260`, contain(블리드 X)
  - 상단형(타이틀 상단) → 슬롯 `x300 / y160` (중앙~하단 우측)
  - 하단형(타이틀 하단) → 슬롯 `x300 / y50` (상단 우측) — 타이틀과 대각선
- Thiings PNG 사용

### 3.3. 멀티 목업 (타이틀 상단 고정)
- **이미지 슬롯 3개**: `VISUAL_SLOT_1 x46/y215` · `_2 x229/y175` · `_3 x412/y215`, 각 `w143 / h340`, 하단 블리드(엇갈림)
- **텍스트**: 상단 (top 40)

### 3.4. 배경 (텍스트 중앙 고정)
- **`BG_SLOT`**: 전체 `600×450`, 관련 이미지 **opacity 20%** 오버레이
- **보조 `VISUAL_SLOT`**: 우측 `x320 / y110 / w·h 230` (3D 등, 선택)
- **텍스트**: 좌측 세로 **중앙**, 전부 흰색(강조색 없음)
