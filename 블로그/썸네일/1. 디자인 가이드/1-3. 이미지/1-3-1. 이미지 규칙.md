## 0. 작업 순서 — 이미지 주도 (Image-First) 🔴

> **핵심 원칙**: 타이틀에서 **이미지부터** 풀어간다. 타이틀이 어떤 이미지를 부르는지 먼저 정하고 → 이미지를 모으고 → 레이아웃(슬롯)을 확정한 뒤 → **마지막에 타이틀을 슬롯의 정해진 자리에 채운다**.
> 슬롯 16종(`1:1245`)이 텍스트 자리·이미지 자리·여백·정렬을 **모두 미리 정해놨기 때문에** "남은 공간 계산"이 필요 없다. **슬롯이 곧 정답**.
> 전체 파이프라인(intake → 검수) → [[0. 목표와 비전]] §⚙️

| 순서  | 단계                     | 내용                                                                                      | 출처                                   |
| --- | ---------------------- | --------------------------------------------------------------------------------------- | ------------------------------------ |
| 1   | **이미지 유형 결정 (A~E)**    | 타이틀에서 "보여줄 CdBd 화면이 있는가/하나/여럿/없는가" 판단 → A·B·C·D·E                                       | [[1-2-1. 레이아웃 규칙]] §1.1              |
| 2   | **이미지 자산 수집**          | 유형별 자산 결정 + 캡처·다운로드 (viewer/에디터/Thiings/외부 자료)                                          | §1.1 + [[1-3-2. 이미지 리소스 북]] §2·§3·§4 |
| 3   | **레이아웃 확정 → 슬롯 clone** | 유형 × 타이틀 위치(상/하/중앙) × 서브 유무 → 슬롯 16종 중 1칸 복제                                            | [[1-2-1. 레이아웃 규칙]] §2                |
| 4   | **슬롯에 텍스트 + 이미지 fill** | 타이틀 의미 단위 줄 나누기·강조색 → 슬롯의 `TITLE`/`SUBTITLE`에 입력 / 이미지 → `VISUAL_SLOT` 등에 의미 영역 크롭 fill | 타이틀 → [[1-1. 스타일]] / 이미지 → §1.1.b    |
| 5   | **검수·승인**              | 의미 영역이 잘 보이는가 / 시각 균형(대각선) / 텍스트 가림 없는가                                                 | §2.3 + 휴먼 검수                         |

> ✅ **슬롯 시스템 효과**: 좌표·크기·여백·정렬·줄 수 위치 보정이 자동 → "이미지가 텍스트를 가리지 않을까" 걱정할 필요 없음.
> 📐 줄나누기·강조색 규칙 → [[1-1. 스타일]] "텍스트 작성 규칙"
> 🎯 "왜 이미지부터?": 이미지 유형이 정해지면 슬롯이 결정되고, 슬롯이 결정되면 타이틀 자리도 결정됨. 반대 순서는 슬롯 시스템에서 불가능.

## 1. 이미지 요소 유형 — 무엇을 준비하나

이미지는 **역할**에 따라 두 가지로 나뉜다.

### 1.1. 주 이미지 (Main) — 5유형 (A~E)

콘텐츠 핵심을 시각화하는 요소. **시선의 초점**.
유형 결정은 → [[1-2-1. 레이아웃 규칙]] §1.1 (타이틀 → 유형 판단). 여기서는 각 유형의 **이미지 자산 준비·배치 규칙**만 정의.

| 유형 | 자산 구성 | 자산 출처 | 핵심 크기·배치 | 슬롯 |
|------|----------|----------|---------------|------|
| **A. 목업** | 공식 목업 컴포넌트 1개 + viewer 캡처(의미 영역 크롭 §1.1.b) fill | 컴포넌트: §1.1.a / viewer: [[1-3-2. 이미지 리소스 북]] §2 (템플릿) · §3.1 (viewer 기능) | `x≈353 / y≈68 / w≈217` — **우측 하단 블리드** (cut-off) | [[1-2-1#2.1\|목업 슬롯 4종]] (`VISUAL_SLOT`) |
| **B. 목업 + 에디터** | 공식 목업 1개(축소) + 에디터 UI 캡처 1개 → **한 덩어리(주 1개)** | 컴포넌트: §1.1.a / 에디터: [[1-3-2. 이미지 리소스 북]] §3.2 (에디터 기능) | 목업 `w≈176 / h≈360` 우측 블리드 + 에디터 `260×154` contain (좌중앙·상단) | [[1-2-1#2.1\|목업+에디터 슬롯 4종]] (`VISUAL_SLOT`·`EDITOR_SLOT`) |
| **C. 멀티 목업** | 공식 목업 컴포넌트 2~3개 (다른 카테고리·시리즈) → **한 덩어리(주 1개)** | 컴포넌트: §1.1.a / viewer: [[1-3-2. 이미지 리소스 북]] §2 | 각 `w≈143 / h≈340` 가로 배열(엇갈림), 하단 블리드 | [[1-2-1#2.1\|멀티 슬롯 2종]] (`VISUAL_SLOT_1/2/3`) |
| **D. 3D 아이콘** | 개념을 상징하는 3D 렌더링 오브젝트 1개 | [Thiings](https://www.thiings.co/things) PNG 다운로드 → `attachments/decorations/` | `w·h ≈ 260` contain (블리드 X), 우측 중앙~하단 | [[1-2-1#2.1\|3D 슬롯 4종]] (`VISUAL_SLOT`) |
| **E. 배경** | 풀 캔버스 외부 사진/스크린샷 1개 (BG) + 보조 3D/이미지(옵션) | 외부 자료(주제 관련), CdBd 페이지/에디터 캡처 | BG: 전체 `600×450` **opacity 20%** / 보조 `230×230` 우측 | [[1-2-1#2.1\|배경 슬롯 2종]] (`BG_SLOT`·`VISUAL_SLOT`) |

> **공통 규칙**: 텍스트와 간격 **≥ 30px** / 비율 유지 / 텍스트 가리지 않기
> **A·B·C 공통**: 공식 목업 컴포넌트(§1.1.a) **반드시 사용**, 의미 영역 크롭(§1.1.b) 적용
> **상단형 vs 하단형 위치 변형**: 슬롯 페이지 `1:1245`에서 좌표 고정 — [[1-2-1. 레이아웃 규칙]] §2~§3 참고
> **레이아웃 결정 흐름**: 타이틀 → 유형 (§1.1 [[1-2-1. 레이아웃 규칙]]) → 위치 변형 → 슬롯 clone → 이 § 1.1 자산 준비 → fill

| # | 목업 종류 | 컴포넌트 ID (symbol) | 원본 크기 | 화면 영역 (캡처 fill 위치) | 사용처 |

> **선택 가이드**:
> - **명함·프로필·일반 페이지** → 원페이지 목업-1

> - `oak_table` (1) → 원페이지 목업
> - `lookbook` (2) / `newarrival` (3) / `online_lookbook` (4) → **멀티페이지 목업**

**사용 방법** (Figma Plugin API):
1. 공식 컴포넌트(`1:1368`/`1:1369`/`1:1370`)를 `createInstance()` 또는 `clone()`해서 새 썸네일 프레임에 `appendChild`
2. 인스턴스 내부에서 화면 영역을 `findOne({name: "Mockup"})` (원페이지) 또는 중앙 #FFFFFF rect로 찾아 imageHash fill 적용
3. 위치를 `x=353, y=68` (하단형) 또는 우측 정렬 (상단형)로 이동
4. cut-off 패턴 시 부모 프레임에 `clipsContent = true` 보장

#### 1.1.b. 의미 영역 크롭 원칙 — viewer 전체 ❌ / 타이틀이 말하는 그 섹션 ⭕ 🔴

> **핵심**: 목업·배경 이미지의 캡처를 **viewer 페이지 통째로 넣지 않는다.**
> 타이틀이 말하는 **바로 그 기능·섹션**이 화면에 보이도록 **크롭**한다.
> (CdBd viewer는 세로로 매우 길어, 전체를 fill하면 정작 핵심 섹션이 안 보이고 상단 프로필만 노출됨)

| 순서 | 단계 | 내용 |
|------|------|------|
| 1 | **의미 영역 식별** | 타이틀이 가리키는 기능·섹션이 viewer의 어느 위치(상/중/하단)인지 결정 → [[1-3-2. 이미지 리소스 북]] §3.1 "영역 위치" 표 참조 |
| 2 | **CROP fill** | `scaleMode: 'CROP'` + `imageTransform`(Y offset)으로 그 섹션이 목업 화면에 오도록 이동 |
| 3 | **확인** | 목업 화면 안에 "타이틀이 말하는 그 UI"가 실제로 보이는가 점검 |

> 예: 타이틀이 "**상담 신청 폼**"이면 → `promotion` viewer의 **하단 폼 영역**을 CROP. 프로필·카드가 보이는 상단을 넣으면 ❌
> 영역 좌표·`scaleMode`·`imageTransform` 코드 → [[1-3-2. 이미지 리소스 북]] §3.1
> 프롬프트에 크롭 영역 명시하는 법 → [[1-4. 프롬프트]]

## 2. 이미지 조합 규칙 — 몇 개, 어떻게

### 2.1. 개수 규칙

| 역할         | 개수                        |
| ---------- | ------------------------- |
| **주 이미지**  | **반드시 1개** (시각적 초점 분산 금지) |
| **보조 이미지** | **0~3개** (그 이상이면 산만)      |

> 목업 여러 개(2~3개 겹침)는 "한 덩어리" = **주 이미지 1개**로 취급
> **에디터 기능 UI + 결과 목업** 결합형도 마찬가지로 한 덩어리 = 주 이미지 1개 (→ [[1-2-1. 레이아웃 규칙]] §1.1 결합형 / 캡처 [[1-3-2. 이미지 리소스 북]] §3.2)

---

### 2.2. 조합 원칙

1. **역할이 명확해야 함** — 주/보조 중 어느 것이 핵심인지 한눈에 보여야 함
2. **텍스트와 겹치지 않기** — 이미지가 글자를 가리면 안 됨
3. **여백 확보** — 이미지끼리, 그리고 텍스트와의 여백을 충분히

---

### 2.3. 이미지 배치 기준 — 어디에 놓나 (실측 기반)

> "자유 배치"가 아니라 **3개 레이어로 위치를 결정**한다.
> 기준은 블로그 썸네일 페이지(Figma `0:1` "블로그 썸네일")의 **실제 예시 60개를 측정**해 도출 (2026-05-29).
> 핵심: **타이틀(좌측)과 주 이미지(우측)이 대각선 균형**을 이룬다. → 작업 순서는 §0(텍스트 우선) 참조.

#### Layer 1 — 좌우 분할 (골격)
- 타이틀 = **좌측** (`x = 40` 고정)
- 주 이미지 = **우측** 정렬 (x 시작 대략 **250~360px**)
- 60개 예시 거의 전부가 이 좌(텍스트)–우(이미지) 대비를 따름

#### Layer 2 — 세로 위치 = 타이틀의 대각선 반대편
| 타이틀 위치 (레이아웃) | 주 이미지 세로 위치 |
|---|---|
| **상단형** | 우측 **중앙~하단** |
| **하단형** | 우측 **상단** (`y ≈ 68`에서 시작) |
| **중앙형(배경)** | 우측 **세로 중앙** |

> 타이틀과 이미지가 **대각선**을 이뤄 시각 무게가 균형을 잡는다.

#### Layer 3 — 5유형(A~E)별 앵커 레시피 (실측값)
| 유형 | 위치·크기 (실측) | 블리드(cut-off) |
|---|---|---|
| **A. 목업** (세로 1개) | `x ≈ 353 / y ≈ 68 / w ≈ 217` (h 자동) | **하단으로 블리드** — 60개 중 8개+ 동일 반복 (확정 상수) |
| **B. 목업+에디터** | 목업: `x ≈ 395 / w ≈ 176 / h ≈ 360` (우측 축소) + 에디터 UI: `260×154` contain (좌중앙·상단) | 목업만 하단 블리드, 에디터는 contain |
| **C. 멀티 목업** (2~3개) | 우측·중앙 하단에 나란히, 각 `w ≈ 143 / h ≈ 340` (엇갈림 — 중앙은 y=175, 양옆 y=215) | 하단으로 블리드 |
| **D. 3D 아이콘** | `w ≈ h ≈ 260`, 우측, 세로 중앙(상단형 `y ≈ 160` / 하단형 `y ≈ 50`) | contain (블리드 X) |
| **E. 배경** | BG: 캔버스 전체 `600×450` opacity 20% / 보조: `230×230` 우측(`x=320 / y=110`, 옵션) | BG 풀 블리드 |

> 위 좌표는 슬롯 페이지 `1:1245`의 슬롯 스펙과 동일 — [[1-2-1. 레이아웃 규칙]] §3 참고.

#### 공통 규칙
