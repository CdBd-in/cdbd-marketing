# 자동화 체크리스트 ⭐

> 블로그 썸네일 자동 생성 시 **매번 확인해야 할 항목**.
> Claude가 이미지 제작 **전·중·후** 모든 단계에서 체크하며 진행.
> 이 체크리스트는 [[1-1. 스타일]] / [[1-2-1. 레이아웃 규칙]] / [[1-3-1. 이미지 규칙]] / [[1-3-2. 이미지 출처]] 의 핵심 규칙을 한눈에 보기 위함.

---

## 🚨 자주 놓치는 핵심 항목 (사용자 강조)

이 5가지는 **매 작업마다 반드시 더블체크**:

1. **줄 나누기 ([[1-1. 스타일]] §3)** — 의미 단위·강조어 한 줄 안·8-10자/줄·가장 적은 줄 수
2. **서브타이틀 유무에 따른 슬롯 분기** — 없으면 1:1262만 / 있으면 1:1294만 (두 슬롯 섞지 말기)
3. **타이틀 → 레이아웃 선정 ([[1-2-1]] §1.1)** — 임의 추측 ❌ / 가이드 신호어 매칭 ⭕
4. **디자인 가이드 우선** — 코드에 임의 키워드 만들지 말고 가이드 §5.1·§5.4 인용
5. **보조 3D 아이콘은 Thiings에서** — AI 생성 ❌ / [[1-3-2. 이미지 출처]] §4.1 카탈로그 사용 ⭕

## ✅ 사전 체크 (이미지 제작 전)

### Step 0. 가이드 문서 우선 확인 ⭐⭐⭐
- [ ] [[1-1. 스타일]] — 캔버스(600×450)·컬러(#141414)·타이포(Pretendard Bold 36/24)·줄 나누기 원칙 확인
- [ ] [[1-2-1. 레이아웃 규칙]] — 5유형 분류 기준·슬롯 16종 확인
- [ ] [[1-3-1. 이미지 규칙]] — 자산 준비·조합 규칙 확인
- [ ] [[1-3-2. 이미지 출처]] — Step 1 다층 분석·§5.1·§5.4 매핑 사전 확인

> ⚠️ **임의로 추측하지 말 것**. 가이드에 있는 키워드와 규칙을 그대로 인용.

### Step 1. 타이틀 다층 분석 ([[1-3-2]] §1 Step 1)
- [ ] **1a. 명시적 기능명 추출** — RSVP, 초대장, 명함, 프로필 링크, 예약 관리, 카탈로그, 상담, 서명 등
- [ ] **1b. 산업·고객층 추출** — VIP, 치과·의료, B2B, 프리랜서, 패션 등
- [ ] **1c. 이미지 유형 결정** — A/B/C/D/E 중 하나 확정
- [ ] **1d. 톤·감정 추출** — AI, 안전, 글로벌, 프리미엄 등 ([[1-3-2]] §5.1)

### Step 2. 레이아웃 유형 선정 ([[1-2-1]] §1.1)
**우선순위 순서** (자동화에서 위→아래로 검사):
- [ ] **C 검사** — 화면 둘 이상 (복수 명시)
  - 신호: "A와 B" / "결합" / "카탈로그·룩북" / "페이지 빌더"
- [ ] **E 검사** — 외부 주제·리스티클 (CdBd 무관)
  - 신호: "Best N" / "AI 툴" / "추천" / "무료 사이트"
- [ ] **D 검사** — 개념·주장·이유
  - 신호: "왜" / "이유" / "대신" / "vs" / "고집" / 질문형
- [ ] **B 검사** — 에디터·관리 기능
  - 신호: CRM, 통계, 카드 추가, AI 디자인, 팀 공유
- [ ] **A 검사** — viewer 발행 페이지 기능
  - 신호: RSVP, 초대장, 명함, 프로필 링크 (단일)
- [ ] **폴백**: 질문형 + 미매칭 → E / 그 외 → A

### Step 3. 강조어 결정 ([[1-1. 스타일]] §3)
- [ ] **1순위: 제품·기능명** — "CdBd 모바일 명함", "RSVP", "프로필 링크"
- [ ] **2순위: 가치 제안 동사** — "끝내기", "사로잡는", "해결"
- [ ] **3순위: 차별점·혜택** — "대신", "안전하고", "무료로"
- [ ] **4순위: 핵심 명사·개념** — "진짜 이유", "Best N", "N가지"
- [ ] 강조어 길이: 12-14자 이내 (한 줄에 들어가야 함)
- [ ] **E 유형은 강조색 없음** (전부 흰색)

### Step 4. 자산 후보 추출
유형별로 자산 출처가 다름:

| 유형 | 자산 출처 | 자동화 지원 |
|------|----------|------------|
| **A 목업** | viewer 캡처 ([[1-3-2]] §3.1) + 공식 목업 컴포넌트 (`1:1368`/`1:1369`/`1:1370`) | ❌ Microlink 인프라 필요 |
| **B 목업+에디터** | 에디터 캡처 ([[1-3-2]] §3.2) + 목업 | ❌ Playwright 인프라 필요 |
| **C 멀티 목업** | viewer 2-3개 + 멀티 목업 (`1:1370`) | ❌ 인프라 필요 |
| **D 3D 아이콘** | Thiings PNG ([[1-3-2]] §4.1 카탈로그) | ⚠️ 등록된 데코만 |
| **E 배경** | 외부 사진 (AI 생성 OK) + Thiings 3D 보조 | ✅ 자동 |

### Step 5. 보조 3D 아이콘 매칭 ([[1-3-2]] §5.4 > §5.1)
- [ ] **§5.4 기능명 매칭 우선** (⭐⭐⭐)
  - 초대장 → envelope ✅
  - 예약 → calendar ✅
  - AI·자동화 → magic-wand ✅ (Figma 컴포넌트 4:167)
  - 명함 → card (미등록)
  - 카탈로그·브로셔 → book (미등록)
- [ ] **§5.1 톤 매칭** (1a 매칭 없을 때만)
  - 프리미엄 → crown ✅
  - 안전 → shield ✅
  - 글로벌 → globe ✅
- [ ] **폴백: sparkle 1-4 랜덤** ([[1-3-2]] §4.1)

### Step 6. 슬롯 선택 ([[1-2-1]] §1.2 베리에이션 규칙)
- [ ] **서브타이틀 유무 확인** (블로그 콘텐츠 입력 여부)
- [ ] **두 슬롯 섞지 말기** — 모든 안이 같은 슬롯
  - 서브 없음 → `1:1262`만 사용 (E)
  - 서브 있음 → `1:1294`만 사용 (E)
- [ ] 베리에이션 메인 축은 **이미지 자산** (다른 키워드·다른 결과)

## ⚙️ 작업 중 체크 (이미지 제작 중)

### Step 7. 줄 나누기 ([[1-1. 스타일]] §3) ⭐⭐⭐ 자주 놓침
- [ ] **의미 단위(어절·구문)로 끊기** — 어절 중간에서 자르지 않기
- [ ] **한 줄 한글 8-10자 이내** (폭 300px / 폰트 Bold 36px)
- [ ] **강조 키워드는 한 줄 안에 통째로** — 줄바꿈으로 쪼개지 않음
- [ ] **각 줄 길이 비슷하게** — 시각적 균형
- [ ] **가장 적은 줄 수** (보통 2-4줄)
- [ ] **`\n` 명시** — 자동 줄바꿈 fallback에 의존 ❌
- [ ] **자동 줄바꿈 차단** — `textAutoResize = WIDTH_AND_HEIGHT` 또는 보수적 maxLine

### Step 8. 색상 적용 ([[1-1. 스타일]] §2)
- [ ] 타이틀 기본 = #FFFFFF (흰색)
- [ ] 강조어 = #8F80FF (Purple) — A·B·C·D 유형
- [ ] 서브타이틀 = #4DE98B (Green) — 있을 때 전체
- [ ] **E 유형 = 전부 흰색** (강조색 ❌)
- [ ] 한 썸네일에 강조어 1개

### Step 9. 자산 fill ([[1-3-1]] §1.1.b 의미 영역 크롭)
- [ ] **A·B·C**: 공식 목업 컴포넌트 인스턴스 → 내부 흰색/회색 rect에 fill (CROP + imageTransform)
- [ ] **D**: VISUAL_SLOT에 Thiings PNG 직접 fill (FIT)
- [ ] **E**: BG_SLOT에 외부 사진 fill (FILL, opacity 20%) + 보조 VISUAL_SLOT에 Thiings 3D
- [ ] **의미 영역 크롭** — viewer 캡처 시 타이틀이 말하는 그 섹션이 보이도록

### Step 10. 텍스트 위치 보정
- [ ] **하단형 슬롯** (1:1251/1246, 1:1304/1314, 1:1274/1277): `y = 410 - height`
- [ ] **E 유형 중앙**: `y = (450 - height) / 2`
- [ ] TEXT_BLOCK 있으면 그것, 없으면 TITLE 단독

## 🔍 사후 체크 (이미지 제작 후) ⭐

### Step 11. 줄바꿈 검증 ⭐⭐⭐
- [ ] **어절 중간에서 잘렸는지** ("않 / 은 글쓰기" ❌)
- [ ] **강조어가 두 줄에 걸쳐있는지** (있으면 재시도)
- [ ] **줄 수가 가이드 범위 (2-4줄)인지**
- [ ] **자동 줄바꿈으로 추가 분리됐는지**

### Step 12. 베리에이션 규칙 ([[1-2-1]] §1.2)
- [ ] **E 유형**: 서브 없으면 모든 안이 1:1262 / 있으면 모든 안이 1:1294
- [ ] **두 슬롯 섞이지 않았는지**
- [ ] 자산만 다양화 (위치는 동일)

### Step 13. 시각적 검증
- [ ] **이미지가 텍스트를 가리지 않는지**
- [ ] **보조 3D가 텍스트 영역 침범 안 하는지** (x ≥ 280, 좌측 텍스트 회피)
- [ ] **이미지가 타이틀과 시각적으로 관련 있는지**
- [ ] **의미 영역이 화면에 보이는지** (A·B·C·E — 가이드 §1.1.b)

### Step 14. 슬롯 스펙 일치 ([[1-2-1]] §3)
- [ ] 슬롯 좌표가 가이드와 일치하는지 — 변경됐으면 가이드 업데이트
- [ ] 텍스트 폭이 가이드 권장값 (300/350)인지
- [ ] 보조 VISUAL_SLOT 위치가 정확한지 (E: x360/y125/w·h200)

## 🚦 사용자 검수 항목 (자동화 후 수동 확인)

자동화가 100% 완벽할 수 없으므로, 사용자가 마지막에 확인:

1. **이미지가 타이틀의 진짜 의미를 담고 있나?**
2. **줄바꿈이 자연스럽나? 강조어가 한 줄에 있나?**
3. **시각적 균형이 맞나? 한쪽으로 쏠리지 않았나?**
4. **2-4안 중 어느 게 가장 적합한가?**
