# 프롬프트 템플릿

> Claude에게 썸네일 이미지 제작을 요청하는 프롬프트.
> 레이아웃 규칙 → [[1-2-1. 레이아웃 규칙]] / 레퍼런스 노드 → [[1-2-2. 레이아웃별 레퍼런스 노드]]

> **사용 전제**
> - 디자인 규칙 노트들([[1-1. 스타일]]·[[1-2-1. 레이아웃 규칙]]·[[1-3-1. 이미지 규칙]])과 이미지 출처([[1-3-2. 이미지 출처]])를 컨텍스트로 함께 전달
> - 프롬프트는 **이번 썸네일의 변수만** 명시
> - 클로드는 규칙 노트를 참조해서 정확한 색상·폰트·레이아웃·에셋 출처를 따름
> - **작업 순서는 텍스트 우선** ([[1-3-1. 이미지 규칙]] §0): 타이틀 먼저 확정 → 남은 공간에 이미지. 목업은 **의미 영역만 크롭** (§1.1.b)
> - ⭐ 제작은 [[1-2-1. 레이아웃 규칙]] §2 **슬롯 템플릿**을 clone해서 끼워넣는 방식 권장

---

## 1. 시작 (intake) — "블로그 썸네일 만들거야"

> 사용자가 썸네일 제작을 시작하면, Claude가 **먼저 입력을 요청**한다.
> (타이틀·서브타이틀은 타이틀에서 추측 불가 → 반드시 사람이 줘야 함)

**Claude가 먼저 제시하는 입력 요청:**
```
썸네일 만들 정보를 알려주세요.

- 타이틀 (필수): 블로그 제목 한 문장 (줄바꿈 없이)
- 서브타이틀 (선택): 시리즈·연재면 라벨만 — 예) "CdBd 프로필 링크 시리즈 #6", "쇼호스트 편"
                     단독 글이면 비워두세요.
```

**입력을 받은 뒤 Claude가 자동으로 결정:**

| 항목 | 결정 방식 |
|------|----------|
| **강조 키워드** | Claude가 타이틀에서 **1~2개 자동 제안** → 사용자 확인 (사용자가 지정하면 그게 우선) |
| **강조색** | 서브타이틀 유무로 자동 — 있으면 그린 / 없으면 퍼플 ([[1-1. 스타일]]) |
| **레이아웃** | 서브타이틀 유무 + 이미지 유형으로 자동 ([[1-2-1. 레이아웃 규칙]] §1) |
| **줄 나누기** | 의미 단위 자동 ([[1-1. 스타일]] "텍스트 작성 규칙") |
| **주·보조 이미지** | 다층 분석으로 자동 추천 ([[1-3-2. 이미지 출처]] §1) |

> **사람이 주는 것 = 타이틀(필수) + 서브타이틀(시리즈면)** 둘 뿐.
> 나머지는 Claude가 제안하고, 명백하면 진행 / 애매하면 확인 (80% 자동 / 20% 휴먼).

## 2. (선택) 직접 변수 입력 — 기본 프롬프트 템플릿

> intake 대화 대신 변수를 한 번에 다 적고 싶을 때 사용.

```
[썸네일 디자인 규칙] 노트를 컨텍스트로, CdBd 블로그 썸네일을 만들어줘.

# 📐 레이아웃
- 이미지 유형: [목업 / 3D 아이콘 / 멀티 목업 / 배경]
- 타이틀 위치: [상단 / 하단]  (멀티=상단 고정 · 배경=중앙 고정)
 
# 📝 텍스트
- 타이틀: [제목 한 문장 — 줄바꿈 없이. 줄 나누기는 Claude가 의미 단위로 결정 → [[1-1. 스타일]] "텍스트 작성 규칙"]
- 서브타이틀 (서브 변형 시): [시리즈명·카테고리 등 한 줄]
- 강조 키워드: [비워두면 Claude가 자동 제안 / 지정하면 우선]
- 강조색: **자동** — 서브타이틀 있으면 그린 `#4DE98B`(서브+강조 통일) / 없으면 퍼플 `#8F80FF` ([[1-1. 스타일]] 규칙)

# 🎨 이미지
- 주 이미지 (1개): [목업 / 3D 오브젝트 / 배경 이미지(배경 유형)]
- 보조 이미지 (선택, 최대 3개): [이모지·캐릭터 / 데코 / 앱 아이콘 / UI 요소]

# 📌 추가 정보 (선택)
- 목업이라면 → 보여줄 CdBd 화면: [어떤 페이지/에디터 화면인지]
- 목업 크롭 영역 (의미 영역): [타이틀이 말하는 기능·섹션 — 예: "상담 신청 폼(하단)" / "예약 캘린더(중단)". **viewer 전체❌, 그 섹션만 보이게 CROP**]
- 3D 오브젝트라면 → 어떤 개념을 상징: [예: 집(홈페이지), 말풍선(상담)]
- 배경 이미지라면 → 출처 URL: [CdBd 템플릿/에디터 URL]
- 앱 아이콘이라면 → 어떤 서비스: [예: 링크트리, Jasper]
```

### 사용 예시

**예시 1 — 목업·하단·서브 (목업 + 보조)**
```
[썸네일 디자인 규칙] 노트를 컨텍스트로, CdBd 블로그 썸네일을 만들어줘.

# 📐 레이아웃
- 이미지 유형: 목업
- 타이틀 위치: 하단 (서브 있음)

# 📝 텍스트
- 타이틀: 인스타 이벤트 신청, 댓글보다 안전하고 구글폼보다 예쁜 프로필 링크 활용법
- 서브타이틀: CdBd 프로필 링크 시리즈 #7
- 강조 키워드: 안전하고
- 강조색: 그린 (서브타이틀 있음 → 자동 그린)

# 🎨 이미지
- 주 이미지: 목업
- 보조 이미지: 스파클 데코 2개

# 📌 추가 정보
- 보여줄 CdBd 화면: 이벤트 신청 폼이 있는 프로필 링크 페이지
- 목업 크롭 영역: 신청 폼 섹션(중·하단) — 폼이 목업 화면에 보이게 CROP (프로필 상단❌)
```

**예시 2 — 배경·중앙 (배경 이미지)**
```
[썸네일 디자인 규칙] 노트를 컨텍스트로, CdBd 블로그 썸네일을 만들어줘.

# 📐 레이아웃
- 이미지 유형: 배경
- 타이틀 위치: 중앙 (고정)

# 📝 텍스트
- 타이틀: 팔로워 구매 없이 인스타그램 브랜드 계정 키우기
- 강조 키워드: 없음
- 강조색: 없음 (배경은 전부 흰색)

# 🎨 이미지
- 주 이미지: 배경 이미지
- 보조 이미지: 3D 차트 아이콘 1개

# 📌 추가 정보
- 배경 이미지 출처: 인스타그램 관련 이미지 (외부 또는 자체 캡처)
- 3D 오브젝트 개념: 성장/상승 (차트)
```
