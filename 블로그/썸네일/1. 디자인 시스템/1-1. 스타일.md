# CdBd 블로그 썸네일 — 기본 스타일

> 캔버스·컬러·타이포그래피 — 모든 썸네일이 공유하는 **기초 토큰**.

---

## 1. 캔버스 스펙

| 항목 | 값 |
|------|-----|
| **크기** | 600 × 450 px |
| **비율** | 4 : 3 |
| **모서리** | **24px** (corner radius) |
| **포맷** | PNG |
| **해상도** | 72 dpi (웹 전용) |

---

## 2. 컬러 시스템

### 배경색
| 역할 | HEX | 설명 |
|------|-----|------|
| **Primary BG** | `#141414` | 모든 썸네일 공통 배경 (피그마 실측값) |

### 텍스트 색상
| 역할 | HEX | 사용 위치 |
|------|-----|-----------|
| **타이틀** | `#FFFFFF` | 메인 제목 전체 기본값 |
| **강조어 Green** | `#4DE98B` | **서브타이틀 있을 때** — 서브타이틀 전체 + 타이틀 강조 문구 |
| **강조어 Purple** | `#8F80FF` | **서브타이틀 없을 때** — 타이틀 강조 문구 인라인 |

### 강조색 사용 원칙
- 한 썸네일에 **1가지** 강조색만 사용 — **서브타이틀 유무로 결정**
- **서브타이틀이 있을 때** → **Green `#4DE98B`**: 서브타이틀 전체 + 타이틀 내 강조 문구를 **같은 그린**으로 통일
- **서브타이틀이 없을 때** → **Purple `#8F80FF`**: 타이틀 내 강조 문구에 인라인 적용

---

## 3. 타이포그래피

### 폰트 사양
| 역할 | 폰트 | 웨이트 | 크기 | 행간 | 색상 |
|------|------|--------|------|------|------|
| **타이틀** | Pretendard | Bold | 36px | 1.3 | `#FFFFFF` (+ 인라인 강조색) |
| **서브타이틀** | Pretendard | Medium | 24px | 1.3 | `#4DE98B` |

> **폰트 선정 이유**: 디자인 원본 폰트는 **Pretendard**. 과거엔 Figma에서 MCP 자동화로 접근 불가라 Noto Sans KR로 대체했으나, **2026-05-29 재검증 결과 Figma에서 Pretendard 전 weight(Thin~Black)가 사용 가능**함을 확인 (`listAvailableFontsAsync` + 실제 렌더링 테스트 통과). 따라서 원본 그대로 Pretendard 채택.
> - MCP 호출 시 `figma.loadFontAsync({ family: "Pretendard", style: "Bold" })` / `"Medium"` 로드 후 사용 (스타일명: Thin·ExtraLight·Light·Regular·Medium·SemiBold·Bold·ExtraBold·Black)

### 텍스트 작성 규칙
- 타이틀: **2~4줄** 구성
- 따옴표 `'키워드'`로 기능/서비스명 강조하는 패턴 자주 사용
- **줄바꿈은 `\n`으로 명시** — 자동 줄바꿈에 강조 키워드가 분리되지 않도록 작성자가 직접 줄을 끊어줘야 함
