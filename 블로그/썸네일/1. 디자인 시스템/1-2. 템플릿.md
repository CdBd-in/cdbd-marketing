# 템플릿 (피그마 공식 분류)

> 좌측 여백 `40px` 고정, 배경 `#141414`, 캔버스 600×450px
> 기초 규칙(캔버스·컬러·타이포)은 → [[1-1. 스타일]]

---

### Template 1 — 타이틀-상단
```
┌──────────────────────────────────────────┐  top: 40px
│  [타이틀 줄 1                ]           │
│  [타이틀 줄 2                ]           │
│  [타이틀 강조 줄             ]           │
│                                          │
│                   [ 비주얼 영역 ]        │
└──────────────────────────────────────────┘
```
| 항목 | 값 |
|------|----|
| 텍스트 위치 | `left: 40px / top: 40px` |
| 폰트 | Noto Sans KR Bold 36px |
| 색상 | 기본 `#FFFFFF` + 특정 줄/단어 `#4DE98B` 또는 `#8F80FF` |
| 비주얼 | 하단 또는 우측 자유 배치 (텍스트와 겹치지 않게) |

### Template 2 — 타이틀-하단
```
┌──────────────────────────────────────────┐
│                   [ 비주얼 영역 ]        │
│                                          │
│  [타이틀 강조 줄             ]           │  ↑
│  [타이틀 줄 2                ]           │  bottom: 40px
│  [타이틀 줄 3                ]           │  (줄 수에 따라
│  [타이틀 줄 4                ]           │   top값 가변)
└──────────────────────────────────────────┘
```

| 폰트 | Noto Sans KR Bold 36px |
| 색상 | 기본 `#FFFFFF` + 특정 줄/단어 `#4DE98B` 또는 `#8F80FF` |

### Template 5 — 텍스트 중앙
```
┌──────────────────────────────────────────┐
│  (배경: 관련 이미지 opacity 20%)         │
│                                          │
│  [타이틀 줄 1                ]  [ 비주얼]│  ← 세로 중앙
│  [타이틀 줄 2                ]  [      ]│
│  [타이틀 줄 3                ]  [      ]│
│                                          │
└──────────────────────────────────────────┘
```
| 항목 | 값 |
|------|----|
| 텍스트 위치 | `left: 40px / top: 50%` (세로 정중앙, translateY -50%) |
| 폰트 | Noto Sans KR Bold 36px |
| 색상 | `#FFFFFF` (강조색 없이 전부 흰색) |
| 배경 처리 | `#141414` 위에 관련 이미지 **opacity 20%** 로 오버레이 |
| 비주얼 | 우측 세로 중앙 정렬 (텍스트와 겹치지 않게) |
