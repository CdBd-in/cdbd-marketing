## 1. 템플릿별 레퍼런스 노드

> 피그마 파일에 정의된 공식 템플릿 예시. 각 노드는 해당 템플릿의 정답 레퍼런스로 사용.

### Template 1 — 타이틀-상단
| # | 노드 ID | 예시 텍스트 |

| #1 | `4648:106` | 상담 문의, 아직도 카톡으로 받으세요? 오픈채팅 없이 **더 편하게 상담하는** 방법 |
| #2 | `4648:112` | 마케터야 **프로필 링크** 좀 만들어봐? |
| #3 | `4648:129` | 기업이 **비공개 초대장**을 고집해하는 7가지 이유 |

### Template 2 — 타이틀-하단
| # | 노드 ID | 예시 텍스트 |
|---|---------|-------------|
| #1 | `4639:227` | **행사 RSVP**, 엑셀 입력 말고 모바일 초대장으로 끝내세요 |

### Template 3 — 타이틀+서브타이틀-상단

## 2. Claude에게 이미지 제작 요청하는 프롬프트 템플릿

> **사용 전제**
> - 디자인 규칙 노트들([[1-1. 스타일]]·[[1-2. 템플릿]]·[[1-3-1. 비주얼 규칙]])과 소재집([[1-3-2. 비주얼 아카이브]])을 컨텍스트로 함께 전달
> - 프롬프트는 **이번 썸네일의 변수만** 명시
> - 클로드는 규칙 노트를 참조해서 정확한 색상·폰트·레이아웃·에셋 출처를 따름

---

### 기본 프롬프트 템플릿

```
[썸네일 디자인 규칙] 노트를 컨텍스트로, CdBd 블로그 썸네일을 만들어줘.

# 📐 템플릿
- 번호: [1.타이틀-상단 / 2.타이틀-하단 / 3.타이틀+서브-상단 / 4.타이틀+서브-하단 / 5.텍스트 중앙]
 
# 📝 텍스트
- 타이틀: [제목 — 줄바꿈은 `\n`으로 명시. 강조 키워드가 잘리지 않게 직접 끊을 것]
- 서브타이틀 (Template 3·4만): [시리즈명·카테고리 등 한 줄]
- 강조 키워드: [1~2개 단어]
- 강조색: [그린 / 퍼플]

# 🎨 비주얼
- 주 비주얼 (1개): [목업 / 3D 오브젝트 / 배경 이미지(Template 5 전용)]
- 보조 비주얼 (선택, 최대 3개): [이모지·캐릭터 / 데코 / 앱 아이콘 / UI 요소]

# 📌 추가 정보 (선택)
- 목업이라면 → 보여줄 CdBd 화면: [어떤 페이지/에디터 화면인지]
- 3D 오브젝트라면 → 어떤 개념을 상징: [예: 집(홈페이지), 말풍선(상담)]
- 배경 이미지라면 → 출처 URL: [CdBd 템플릿/에디터 URL]
- 앱 아이콘이라면 → 어떤 서비스: [예: 링크트리, Jasper]
```

---

### 사용 예시

**예시 1 — Template 4 (목업 + 보조)**
```
[썸네일 디자인 규칙] 노트를 컨텍스트로, CdBd 블로그 썸네일을 만들어줘.

# 📐 템플릿
- 번호: 4.타이틀+서브-하단

# 📝 텍스트
- 타이틀: 인스타 이벤트 신청,\n댓글보다 안전하고\n구글폼보다 예쁜\n'프로필 링크' 활용법
- 서브타이틀: CdBd 프로필 링크 시리즈 #7
- 강조 키워드: 안전하고
- 강조색: 그린

# 🎨 비주얼
- 주 비주얼: 목업
- 보조 비주얼: 스파클 데코 2개

# 📌 추가 정보
- 보여줄 CdBd 화면: 이벤트 신청 폼이 있는 프로필 링크 페이지
```

**예시 2 — Template 5 (배경 이미지)**
```
[썸네일 디자인 규칙] 노트를 컨텍스트로, CdBd 블로그 썸네일을 만들어줘.

# 📐 템플릿
- 번호: 5.텍스트 중앙

# 📝 텍스트
- 타이틀: 팔로워 구매 없이\n인스타그램\n브랜드 계정 키우기
- 강조 키워드: 없음
- 강조색: 없음 (Template 5는 전부 흰색)

# 🎨 비주얼
- 주 비주얼: 배경 이미지
- 보조 비주얼: 3D 차트 아이콘 1개

# 📌 추가 정보
- 배경 이미지 출처: 인스타그램 관련 이미지 (외부 또는 자체 캡처)
- 3D 오브젝트 개념: 성장/상승 (차트)
```
