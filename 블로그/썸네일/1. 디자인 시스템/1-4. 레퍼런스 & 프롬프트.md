## 2. Claude에게 이미지 제작 요청하는 프롬프트 템플릿

> **사용 전제**
> - 디자인 규칙 노트들([[1-1. 스타일]]·[[1-2. 템플릿]]·[[1-3-1. 비주얼 규칙]])과 소재집([[1-3-2. 비주얼 아카이브]])을 컨텍스트로 함께 전달
> - 프롬프트는 **이번 썸네일의 변수만** 명시
> - 클로드는 규칙 노트를 참조해서 정확한 색상·폰트·레이아웃·에셋 출처를 따름
> - **작업 순서는 텍스트 우선** ([[1-3-1. 비주얼 규칙]] §0): 타이틀 먼저 확정 → 남은 공간에 비주얼. 목업은 **의미 영역만 크롭** (§1.1.b)

---

### 기본 프롬프트 템플릿

```
[썸네일 디자인 규칙] 노트를 컨텍스트로, CdBd 블로그 썸네일을 만들어줘.

# 📐 템플릿
- 번호: [1.타이틀-상단 / 2.타이틀-하단 / 3.타이틀+서브-상단 / 4.타이틀+서브-하단 / 5.텍스트 중앙]
 
# 📝 텍스트
- 타이틀: [제목 한 문장 — 줄바꿈 없이. 줄 나누기는 Claude가 의미 단위로 결정 → [[1-1. 스타일]] "텍스트 작성 규칙"]
- 서브타이틀 (Template 3·4만): [시리즈명·카테고리 등 한 줄]
- 강조 키워드: [1~2개 단어]
- 강조색: **자동** — 서브타이틀 있으면 그린 `#4DE98B`(서브+강조 통일) / 없으면 퍼플 `#8F80FF` ([[1-1. 스타일]] 규칙)

# 🎨 비주얼
- 주 비주얼 (1개): [목업 / 3D 오브젝트 / 배경 이미지(Template 5 전용)]
- 보조 비주얼 (선택, 최대 3개): [이모지·캐릭터 / 데코 / 앱 아이콘 / UI 요소]

# 📌 추가 정보 (선택)
- 목업이라면 → 보여줄 CdBd 화면: [어떤 페이지/에디터 화면인지]
- 목업 크롭 영역 (의미 영역): [타이틀이 말하는 기능·섹션 — 예: "상담 신청 폼(하단)" / "예약 캘린더(중단)". **viewer 전체❌, 그 섹션만 보이게 CROP**]
- 3D 오브젝트라면 → 어떤 개념을 상징: [예: 집(홈페이지), 말풍선(상담)]
- 배경 이미지라면 → 출처 URL: [CdBd 템플릿/에디터 URL]
- 앱 아이콘이라면 → 어떤 서비스: [예: 링크트리, Jasper]
```

## 3. 슬롯 템플릿 (자동생성용 — Figma 실물) ⭐

> 위치·크기·폰트·색·정렬이 **고정된 빈 슬롯**에 끼워넣기만 → 매번 좌표 계산 불필요.
> [[1-3-1. 비주얼 규칙]] §2.3 실측 배치값을 **Figma 실물 템플릿**으로 만들어 둔 것.

- **Figma 파일**: CdBd 블로그 템플릿 (`1gduKu9Bg319AMqgFrgjTw`)
- **페이지**: 🧩 썸네일 자동생성 템플릿 (슬롯) — `4738:1822`

### 3.1. 제작된 템플릿 목록

| 템플릿 | node ID | 레이아웃 | 강조색 | 슬롯 node ID |
|--------|---------|---------|--------|-------------|
| **TPL · T4 + 세로목업 cutoff** | `4738:1823` | 타이틀+서브-하단 | 그린 (서브+강조 통일) | `VISUAL_SLOT 4738:1824` / `TEXT_BLOCK 4738:1825` (`SUBTITLE 4738:1826` · `TITLE 4738:1827`) |
| **TPL · T2 + 세로목업 cutoff** | `4739:1822` | 타이틀-하단 | 퍼플 (강조) | `VISUAL_SLOT 4739:1823` / `TITLE 4739:1824` |

> **공통 슬롯 스펙**: `VISUAL_SLOT` = `x353 / y68 / w217 / h457` (하단 블리드, cut-off) / 텍스트 = `x40`, **하단 40px 정렬**.
> **비주얼 유형**: 세로 목업 1개(cut-off)만 제작됨. title-top(T1·T3)·3D 오브젝트·멀티 목업·배경(T5)은 **미제작 (확장 예정)**.

### 3.2. 사용 절차 (MCP `use_figma`)

1. **템플릿 clone** — 해당 `TPL` 프레임을 `clone()` → 새 위치에 `appendChild`
2. **`TITLE` 교체** — 폰트(`Pretendard Bold`) 로드 후 `characters` 설정
   - 줄바꿈은 의미 단위로 직접 → [[1-1. 스타일]] "텍스트 작성 규칙"
   - 강조어 구간 `setRangeFills` (그린/퍼플은 서브타이틀 유무로 자동 → [[1-1. 스타일]])
3. **(T4) `SUBTITLE` 교체** — `Pretendard Medium`, 그린
4. **`VISUAL_SLOT` 채우기**
   - 공식 목업 컴포넌트 `clone` ([[1-3-1. 비주얼 규칙]] §1.1.a) → 슬롯 안에 배치, 슬롯 폭(217)에 맞춰 스케일
   - 목업 화면 영역에 viewer 캡처를 **의미 영역 크롭**으로 fill ([[1-3-1. 비주얼 규칙]] §1.1.b)
5. **슬롯 placeholder 정리** — `VISUAL_SLOT`의 점선 stroke·반투명 fill 제거 (`node.strokes = []`, `node.fills = []`)
6. **하단 정렬 재조정** — 타이틀 줄 수가 기본(3줄)과 다르면 `TEXT_BLOCK`(T4)·`TITLE`(T2)의 `y = 410 - height`로 다시 맞춰 **하단 40px 유지**

### 3.3. 슬롯 이름 규칙 (노드 식별용)

| 이름 | 역할 |
|------|------|
| `VISUAL_SLOT` | 주 비주얼(목업) 자리 — 점선 placeholder |
| `TEXT_BLOCK` (T3·T4) | 서브타이틀+타이틀 묶음 (세로 auto-layout, 하단 정렬) |
| `TITLE` / `SUBTITLE` | 텍스트 노드 |

> ⚠️ 슬롯 이름은 자동화 스크립트가 `findOne`/`query`로 노드를 찾는 키이므로 **이름을 바꾸지 말 것**.
