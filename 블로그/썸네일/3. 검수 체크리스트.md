## 🚨 실제로 일어났던 사고 3종 — 반드시 통과

> 과거 사용자가 직접 지적했던 사고. 같은 실수 반복 = 신뢰 손실.

### ☐ ① 원본 텍스트 손대지 않았나
**과거 사고 (2026-06-04)**: "고객도 지치는," "전화 핑퐁 모바일," 쉼표 임의 추가 → 정정 시도에서 "줄 끝 쉼표 제거" 룰을 또 임의로 만듦 → 결국 사용자가 "원본 그대로 + `\n` 추가만"으로 룰 단순화.

- **체크**: 입력 타이틀 원문 vs 각 안 `TITLE.characters` (단 `\n` 제거 후) 문자 단위 비교.
- **❌ 실패**: 쉼표·마침표·느낌표·물음표 추가 / 띄어쓰기 추가·삭제 / 글자 변경 — **1개라도 있으면 전체 재작업**.
- 📌 [[블로그/썸네일/2. 자동화 체크리스트.md|2. 자동화 체크리스트]] §텍스트 절대원칙 ① / [[1-1. 스타일]] §3.

### ☐ ② 어절이 두 줄에 걸쳐 잘리지 않았나
**과거 사고**: 자동 줄바꿈에 맡겨서 "고객도 지치는 전 / 화 핑퐁" 같은 사고. 폭 검수 누락 사례 06-04에도 명시.

- **체크**: 각 줄 끝 글자와 다음 줄 첫 글자가 한 어절을 이루지 않는지 육안 + `TITLE` 노드 width = 350 + `textAutoResize = HEIGHT` 둘 다 강제 적용됐는지.
- **❌ 실패**: 어절 중간 잘림 / 강조 키워드가 두 줄에 걸침 / width 350 아님.

### ☐ ③ 가이드 표를 그대로 인용했나 (임의 추측·즉석 키워드 ❌)
**과거 사고**: 레이아웃 유형을 임의 키워드로 분류 (06-01 사용자 강조) / 코드에 즉석 매핑 키워드 추가 (06-01 "자꾸 임의 키워드 만들지 말고 §5.1·§5.4 그대로 인용") / 3D 아이콘 AI 생성 (Thiings 카탈로그 무시).

- **체크 1 — 레이아웃 유형**: [[1-2-1. 레이아웃 규칙]] §1.1의 신호어 표에서 매칭된 근거가 있는가? 임의 추측이면 ❌.
- **체크 2 — 자산 매핑**: [[1-3-2. 이미지 출처]] §5.1·§5.4 표에 있는 키워드만 인용했는가? 즉석에서 만든 키워드면 ❌.

## 🟡 사용자가 첫눈에 알아채는 마무리 4종

> 사고는 아니지만 빠뜨리면 사용자가 보자마자 "이건 좀…"하고 지적하는 항목.

### ☐ ④ 강조색 1개 적용 / 서브 그린
- TITLE 강조 키워드 **1개**만 Purple `#8F80FF` 인라인 / SUBTITLE 전체 Green `#4DE98B` / E 유형은 전부 흰색.
- ❌ 흰색 그대로 / 2개 이상 강조 / E인데 강조색.
- 📌 [[1-1. 스타일]] §2.

### ☐ ⑤ 의미 영역 크롭 — viewer 상단만 보이지 않나
- A/B/C 유형 `VISUAL_SLOT`에 **타이틀이 가리키는 그 기능·섹션**이 실제로 보이는가.
- ❌ `scaleMode: 'FILL'`만 적용 → 프로필·헤더만 보이고 핵심 기능 안 보임 / "예약 관리" 타이틀인데 viewer 상단 명함만 보임.
- 📌 [[1-3-1. 이미지 규칙]] §1.1.b / [[1-3-2. 이미지 출처]] §3.1 영역 좌표 표.

### ☐ ⑥ 슬롯 점선 placeholder 안 남았나
- 모든 슬롯 노드 순회 — `strokes` 비어있고 임시 회색 fill 없는지.
- ❌ 점선 stroke 그대로 출력 / 빈 fills 슬롯 노출.

### ☐ ⑦ 베리에이션 2–4안 출력 위치 맞나
- A·B·D: 2–4안 / C·E: 2안. 1안만 또는 5안 이상이면 ❌.
- **💻 AI 블로그 썸네일 제작 (`26:2`)** 페이지에 있는가. 슬롯 원본 페이지(🧩 `1:1245`)에 부착됐으면 ❌.
