# 0. 목표와 비전

## 목표

디자이너가 아닌 사람도 블로그 이미지를 손쉽게 만들 수 있도록, **Claude에 내용을 던져주면 Figma에 자동으로 이미지를 생성**하는 워크플로우를 구축한다.

## 비전

- **누구나 디자이너처럼**: 디자인 지식이 없어도 텍스트만 입력하면 완성도 있는 블로그 이미지가 나온다.
- **Claude → Figma 자동화**: 사용자가 Claude에게 블로그 내용(제목, 본문, 키워드 등)을 전달하면, Claude가 Figma MCP를 통해 자동으로 이미지를 생성한다.
- **일관된 브랜드 톤**: 자동 생성이지만 CDBD 브랜드 가이드와 일관된 스타일을 유지한다.

## 핵심 원칙

1. **입력 최소화**: 사용자는 "내용"만 던지면 된다. 레이아웃, 색상, 폰트 등은 Claude가 가이드에 따라 자동 결정.
2. **Figma 네이티브 결과물**: 결과물은 편집 가능한 Figma 파일로 산출되어, 필요 시 미세 조정이 가능하다.
3. **재현 가능성**: 같은 내용이면 같은 품질의 결과가 일관되게 나와야 한다.

## 사용자 시나리오

> "이번 블로그 글 '모바일 명함이 주목받는 이유'에 들어갈 본문 이미지 만들어줘"
> 
> → Claude가 본문 핵심 키워드와 메시지를 추출
> → 디자인 가이드(레이아웃·스타일·이미지 규칙)에 맞춰 Figma에 자동 생성
> → 사용자는 완성된 Figma 링크를 받음
