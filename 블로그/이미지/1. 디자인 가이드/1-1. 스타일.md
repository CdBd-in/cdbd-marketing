# CdBd 블로그 이미지 — 기본 스타일

> 캔버스·컬러·타이포·데코 — 모든 블로그 본문 이미지가 공유하는 **기초 토큰**.

> ℹ️ **썸네일과의 구분**
> - **썸네일** (`블로그/썸네일/`) — 글 대표 이미지. **타이틀 텍스트가 박혀 있음** (1개).
> - **이미지** (이 폴더) — **글 본문에 삽입되는 이미지**. 텍스트는 거의 없거나 **컨텍스트 라벨**만 사용. 시각으로 메시지 전달.

> 🧩 **공식 컴포넌트 사용 필수** — 모든 시각 요소(목업·캔버스·에디터 캡처)는 [[1-3. 이미지 규칙]]에 정리된 **instance만 사용**. 직접 그리지 말 것.

> 🧭 **자동화 진입점은 [[1-0. 장르]]** — 글 전체 장르를 먼저 분류해 이미지 세트를 정하고, 각 이미지의 구성은 [[1-2-1. 레이아웃 유형 — 합성 (A~K)]]에서 결정. 본 토큰은 그 결과물 전체가 공유.
> 🆕 **본문 이미지는 CdBd 목업(A~K)만이 아니다** — 사례·소트리더십·라운드업 글의 실사진·외부캡처·인포그래픽 등 신규 유형(L~R)은 [[1-2. 레이아웃/1-2-2. 외부·실사 유형 (L~R)]] 참조. 그 유형들도 본 캔버스·컬러·라운드 토큰을 공유하되 일부는 캡처/소싱(합성 X).

## 1. 캔버스 스펙

블로그 이미지는 **2개의 출력 크기**를 가진다. 본문 내 역할에 따라 선택.

| 크기 | 비율 | 용도 | 포맷 |
|------|------|------|------|
| **1920 × 1200 px** | 16 : 10 (≈ 8:5) | **랜드스케이프 본문 이미지** — 화면 가로폭 가득 차는 메인 시각. 히어로·비교·시연. | PNG |
| **1000 × 1000 px** | 1 : 1 (정사각) | **스퀘어 인-바디** — 본문 흐름 중간에 끼우는 컴팩트 강조. 디테일·강조·모달. | PNG |

- **해상도**: 72 dpi (웹 전용, 2x 리테일 대응은 본 픽셀 그대로 사용)
- **모서리**: 40px. 이미지 내부 카드·목업 요소는 각자의 굴림 유지
- **보조 크기**: 일부 슬롯에서 `880 × 970.64` / `880 × 1025`가 카드형 변형으로 사용됨 (정식 출력 X, 합성용 내부 카드 단위)

> 🎯 **선택 기준**
> - 본문 흐름의 **핵심 시각 / 비교 / 사용법 / 히어로** → `1920×1200`
> - **포인트 강조 / 디테일 줌인 / 모달 캡처 / 부분 강조** → `1000×1000`

## 2. 컬러 시스템

### 배경색 (캔버스)

| 역할 | HEX | 사용처 |
|------|-----|--------|
| **Primary BG (White)** | `#FFFFFF` | 기본 캔버스 배경 — 대부분의 프레임 |
| **Soft Gray BG** | `#F4F4F4` ~ `#EDEDED` | 에디터/통계 등 UI 캡처 강조 시 부드러운 톤 |
| **Brand Purple BG** | `#6C4CFF` (실측 — 글로우 컬러와 동일) | **강조 카드 배경**(전체 또는 절반 블록) — 시선 집중용 |
| **Lavender BG** | `#B5A8FF` ~ `#C9BFFF` | 부드러운 강조 블록 — 카드·코너 악센트 |
| **Dark Navy BG** | `#0E1430` ~ `#141414` | 어둠 톤 강조 (드물게, 럭셔리·고급감) |

### 강조색 (라벨·악센트)

| 역할 | HEX | 사용 위치 |
|------|-----|-----------|
| **Brand Purple** | `#6C4CFF` (Primary) / `#8F80FF` (Light) | 상단 **컨텍스트 라벨 pill**, sparkle, 카드 배경 |
| **Accent Green** | `#4DE98B` | 긍정/완료/CTA 강조 (드물게) |
| **Neutral Text** | `#141414` (Title) / `#6B6B6B` (Sub) | 라벨·캡션 텍스트 |

### 컬러 사용 원칙

1. **흰색 캔버스 우선** — 본문 이미지의 80% 이상은 흰색 배경. 시각 노이즈 최소화.
2. **퍼플은 시선 도구** — 상단 라벨 pill, sparkle, 부분 강조 카드 배경 등 **시선 진입점**으로만 사용. 전면 도배 ❌.
3. **한 이미지 1 강조 톤** — 라벤더와 진한 퍼플을 같은 이미지에 섞지 않음 (선택 1).
4. **다크 톤은 예외** — viewer 자체가 다크 테마(럭셔리 룩북 등)일 때만 다크 배경 매칭 허용.

## 3. 타이포그래피

> 블로그 이미지는 **타이틀이 박히지 않는다**. 텍스트는 **컨텍스트 라벨**과 **인-목업 캡처**에만 등장.

### 컨텍스트 라벨 (상단 Purple Pill)

| 항목 | 값 |
|------|-----|
| **폰트** | Pretendard |
| **웨이트** | Medium / SemiBold |
| **크기** | `1920×1200` → 28~32px · `1000×1000` → 22~26px |
| **색상** | `#FFFFFF` (퍼플 pill 배경 위) |
| **배경** | `#6C4CFF` pill, 둥근 모서리 ≥ 999px (full round) |
| **패딩** | 가로 24~32px / 세로 10~14px |
| **위치** | 프레임 상단 중앙 또는 좌측 상단 |

**라벨 작성 규칙**
- **5~12자 이내** — 한 줄로 들어가는 짧은 명사구
- 컨텍스트(무엇을 보여주는지)만 적시 — 가치 제안·CTA ❌
- 예: "기존 카탈로그 - PDF", "디지털 카탈로그", "독서 카탈로그 - PDF", "정장의 구입통", "PDF·플립북 카탈로그"
- "vs" 비교 시 2개 라벨 사용 가능 (좌·우 각각)

### 캡션 / 보조 텍스트 (드물게)

| 항목 | 값 |
|------|-----|
| **폰트** | Pretendard |
| **웨이트** | Regular / Medium |
| **크기** | 18~22px |
| **색상** | `#141414` (본문) / `#6B6B6B` (서브) |
| **사용** | 비교 이미지의 화살표 옆 라벨, 통계 수치 |

### ❌ 하지 말 것

- **메인 타이틀을 이미지 안에 박지 않는다** — 본문에 H2/H3로 들어감
- **긴 설명문 박지 않는다** — 본문 텍스트 영역이 처리
- **여러 폰트 섞기** — Pretendard 단일

## 4. 시그니처 시각 요소

### 4.1. 기울인 폰 목업 (Tilted Mockup)

- 블로그 이미지의 **핵심 시그니처** — 모든 mockup·비교·multi 유형의 기본
- **각도**: 약 **-12° ~ -18°** (좌측 위로 기울임) — 시리즈 내 통일 유지
- **그림자**: `DROP_SHADOW` — color `#000000` 10~20% opacity / blur 30~40 / y-offset 10~20
- **글로우 (선택)**: 강조 시 `#6C4CFF` 보라 글로우 — blur 20 / spread 0 (썸네일 가이드와 동일)
- **2개 페어**: 한 프레임에 2개일 때 서로 살짝 겹치거나 V자형으로 마주봄
- **3개 multi**: 가운데가 양옆보다 위/아래로 -40px 엇갈림 (썸네일 C유형 패턴 동일)

### 4.2. 컨텍스트 Pill 라벨

- 상단에 작은 **purple pill** — 이 이미지가 "무엇을 보여주는지" 한 단어 컨텍스트
- 비교형 이미지에는 좌·우 **2개의 pill** ("Before" vs "After" 역할)

### 4.3. Sparkle 데코 ✨

- 강조 카드·모달·부분강조 유형에 자주 등장
- **컴포넌트 화이트리스트** (썸네일과 동일): `sparkle2/3/4` 만 사용 (`sparkle1` ❌)
- **크기**: `1920×1200` → 100~140px · `1000×1000` → 60~80px
- **개수**: 한 이미지 **최대 2개** (강조어 1개 원칙의 확장)
- **위치**: 강조 대상의 모서리 (대각선 코너)

### 4.4. 화살표 & 단계 표시 (사용법 유형 전용)

- **`>`** 모양의 V 화살표 — Pretendard Bold 또는 SVG, 그레이 `#9A9A9A`
- 폰 → `>` → 폰 → `>` → 폰 형태로 3~4단계 시연
- 단계 라벨: 작은 숫자 원 (`①②③`) 또는 라벨 pill
