# 레이아웃 유형 — 합성 (A~G)

> 🔄 **2026-06-23 현재 템플릿 구성으로 재정의.** (옛 "11유형 A~K" 명칭 폐기 — 구 G(목업+목업sq)·I·J·K 삭제, I 통계는 D에 통합, **구 H(목업+에디터sq)→G로 개명**해 A~G 연속, L~R 슬롯 폐지)

> 레이아웃 = **출력 크기(1920×1200 · 1000×1000) × 구성 유형**. 구성 유형은 **두 갈래(형제)**로 나뉜다:
> - **① 합성 유형 (CdBd 화면)** — 목업·에디터·통계를 슬롯에 채워 만드는 유형. **A·B·C·D·E·F** + 정사각 변형 + **G(sq)**. → **이 문서**
> - **② 외부·실사 (L~R)** — 실사진·외부캡처·인포그래픽·문제신·가격표·콜라주·수치일러스트. **전용 슬롯 폐지 → 콘텐츠 "사전"**(만들 땐 A/C 차용·자유합성). → [[1-2-2. 레이아웃 유형 — 외부·실사 (L~R)]]
>
> 공통 인프라 — **결정 매트릭스(§1) · 슬롯 운영(§2) · 자동화 절차(§4)** — 는 두 갈래 모두에 적용된다.
> ⬆️ 상위: 주제→세트 [[1-0. 주제]] · 노드 인덱스 [[1-2-3. 유형별 레퍼런스]] · 토큰 [[1-1. 스타일]] · 카피 [[1-4. 카피 규칙 (라벨·캡션 텍스트)]] · 컴포넌트 [[1-3. 이미지 규칙]]
>
> **현 템플릿 한눈에** (정식 = **v2 자산교체형**, §3.9 — **v1 빈 슬롯 폐지·삭제 2026-06-23**): A 히어로 · B 비교 · C 목업×4 · D 에디터/통계 · E 목업+에디터 · F 사용법 / 정사각 C·D·G.

## ⚡ 30초 사용법

이미지 1장을 만들 때 순서:

1. **크기** 정하기 — 메인/도입=가로(L) · 본문중간 보조=정사각(S) → **§1 Step 1**
2. **유형** 정하기 — 출처·의도로 A·B·C·D·E·F·G 중 1개 → **§1 Step 2~3** (헷갈리면 §1 "혼동 페어 판별")
3. **노드 clone** — §2 표에서 해당 유형 슬롯 노드(`15:xx`/`160:xx`)를 출력 페이지(`1:20182`)로
4. **슬롯 fill** — §2 "fill 2-스텝" + §3 해당 유형 상세 스펙대로 채움
5. **검수** — [[블로그/이미지/2. 검수 체크리스트]] 통과 후 제시

## 목차

- **§1 결정 매트릭스** — 크기(Step1) · 유형군(Step2) · **정밀 픽(Step3 카테고라이징)**
- **§2 슬롯 템플릿** — 노드 표 + 운영 규칙(BG·라벨·fill)
- **§3 유형별 상세** — A·B·C·D·E·F·G · 정사각 변형 · **§3.9 v2 자산교체형(정식)**
- **§4 자동화 절차** · 갱신 로그

## 1. 결정 매트릭스 — 어떤 유형을 쓸 것인가

> ⚠️ **전제**: 이 매트릭스는 [[1-0. 주제]]에서 **글 주제 → 이미지 세트(유형 시퀀스)**가 정해진 뒤, **개별 이미지 1장의 크기·패턴**을 고르는 단계다. 유형이 L~R(외부·실사)로 결정됐다면 본 매트릭스 대신 [[1-2-2. 레이아웃 유형 — 외부·실사 (L~R)]]을 따른다.
>
> 입력: **본문 한 단락 + "이 자리에 어떤 메시지의 이미지가 필요한가"**
> 출력: **출력 크기 1종 + 구성 패턴 1종**

### Step 1 — 출력 크기 결정

| 문맥 신호 | 선택 |
|---------|------|
| 글의 **메인 시각** / 섹션 도입부 / 비교·시연 핵심 | **1920×1200 (Landscape)** |
| 본문 흐름 중간 **포인트 강조** / 모달·디테일 줌인 / 짧은 보조 시각 | **1000×1000 (Square)** |
| 같은 내용을 가로·세로 두 곳에 모두 보여줘야 할 때 | **두 크기 모두 제작** |

### Step 2 — 구성 유형 결정 (본문 메시지 → 유형)

> **먼저 유형군 분기**: 만들 이미지가 **CdBd 화면(목업·에디터·통계)**인가 → 아래 **① 합성 유형(A·B·C·D·E·F·G)**. **외부 화면·실사진·개념도·문제신·수치 일러스트**인가 → **② 외부·실사 (L~R)** ([[1-2-2. 레이아웃 유형 — 외부·실사 (L~R)]]). 주제별 유형군은 [[1-0. 주제]] §2.1 플랜이 지정.

**🟧 1920×1200 (Landscape) — 합성 유형 6가지 (A~F)**

| 유형                        | 신호 (본문이 무엇을 말하는가)                        | 시각 구성                            |
| ------------------------- | ---------------------------------------- | -------------------------------- |
| **A. 히어로 이미지 (목업)**       | 글의 도입부·결론·메인 비주얼. "X라는 제품/페이지를 소개"       | **3개 정자세 폰**이 가로 일렬로 배치 (중앙 폰 -128px elevation). 각 화면에 viewer 캡처 (서로 다른 섹션 or vertical scroll position) (상세 §3.1) |
| **B. 비교 (vs)**            | "A 대신 B" / "기존 vs 신규" / "PDF vs 디지털"     | 좌·우 분할 — 각 사이드에 라벨 pill + 아이콘·캡처 |
| **C. 목업 + 목업**            | 같은 viewer의 **다른 페이지** 또는 **같은 기능의 여러 사례** | **폰 4개 (2×2 그리드, 대각선)** (상세 §3.3) |
| **D. 에디터**                | "**편집 / 관리** 화면에서 일어나는 일" — 빌더·통계·CRM    | 에디터 UI 캡처 단독 (일부는 폰 small inset) |
| **E. 목업 + 에디터**           | "에디터에서 만든 결과 = 폰의 viewer" 인과 관계          | 좌측 에디터 UI + 우측 폰 목업              |
| **F. 사용법 (Step-by-Step)** | 단계적 시연 — "이렇게 → 이렇게 → 이렇게"               | 폰 3~4개를 `>` 화살표로 연결, 단계 라벨       |

**🟦 1000×1000 (Square) — 정사각 변형** *(본문 흐름 중간 포인트·보조 삽입용. G·J·K 삭제됨)*

| 유형 | 신호 | 시각 구성 |
|------|------|----------|
| **G. 목업 + 에디터 (square)** | 폰(결과 화면) + 보조 카드(에디터 발췌·QR·뱃지) | 좌 폰 + 우 화이트 카드 + 상단 라벨 (라운드 프레임) — sq 전용 |
| **B (square)** | 좁은 곳에서 Before/After 대비 | 좌·우 분할 축소판 |
| **C (square)** | 결과물 2개 컴팩트 나열 | 폰 2개 |
| **D (square)** | 에디터·통계 화면 1장 보조 | 풀스크린 단독 (통계는 EMPHASIS) |

> ※ **통계**는 별도 유형이 아니라 **D(에디터/통계)** 가 담당 — 통계 화면일 때 `EMPHASIS_SLOT`로 핵심지표 강조 (구 "I 통계"는 D에 통합).

### Step 3 — 상황 → 템플릿 정밀 선택 (카테고라이징) ⭐

> 템플릿이 압축되며 **한 템플릿이 여러 상황을 겸한다.** 비슷한 후보가 겹칠 때 아래 **4축 → 결정 절차 → 혼동 페어 판별 → 상황 색인** 순으로 좁힌다.

**선택을 가르는 4축**

| 축     | 질문                | 값                                               |
| ----- | ----------------- | ----------------------------------------------- |
| ① 이미지 | 무엇을 **보여주나**      | viewer(결과화면) / 에디터·통계 / 대비 / 단계 / 외부·실사·개념(L~R) |
| ② 의도  | 무엇을 **말하나**       | 소개 · 나열(다양성) · 대비 · 인과 · 시연 · 성과 · 강조           |
| ③ 크기  | 어디에 **놓이나**       | 메인/도입=가로(L) · 본문중간 포인트=정사각(S)                   |
| ④ 주제  | 글 종류([[1-0. 주제]]) | 세트를 편향(후보 풀)                                    |

**결정 절차 (3단)**

```
1단 — 출처로 유형군 분기
  ├ 모바일 결과화면(viewer)      → A · C · G(좌폰)
  ├ 에디터/관리/통계 화면         → D · E
  ├ 두 방식의 대비               → B
  ├ 1·2·3 단계 흐름             → F
  └ 외부·실사·개념·수치(구 L~R)   → 캡처/실사 후 A·C 차용 or 자유합성
2단 — 의도로 템플릿 확정 (아래 매트릭스)
3단 — 크기 변형 (L 기본 / 본문중간 보조면 정사각 B·C·D·G)
```

**의도 × 출처 매트릭스**

| 의도 | viewer 결과화면 | 에디터/통계 | 대비/외부/개념 |
|------|----------------|------------|---------------|
| **소개·대표** | **A** 히어로(폰3) | — | 실사=실사진 풀스크린 |
| **나열·다양성** | **C** 목업×4 (2개=C-sq) | — | **C**틀에 외부캡처 |
| **대비** | — | — | **B** 비교 |
| **인과**(만들면→나온다) | — | **E** 에디터+결과폰 | — |
| **화면 자체** | — | **D** 단독 | — |
| **성과·데이터** | — | **D**(통계모드+EMPHASIS) | 수치 훅=자유합성 |
| **시연**(단계) | **F** 사용법 | — | — |
| **포인트 강조**(보조) | **G**(폰+카드 sq) | **D-sq** | **B-sq** |

**🔑 혼동 페어 판별 규칙** (가장 헷갈리는 지점)

- **A ↔ C** — A=제품/페이지 **대표 1개** 소개(같은 결과물의 다른 섹션, 폰3) / C=**여러 개**(여러 페이지·여러 사례, 폰4). 개수: **3→A · 4→C · 2→C-sq**.
- **B ↔ 수치 훅** — B=두 **방식/화면**을 좌우 대비(좌우 라벨+자산) / 숫자 **하나**를 크게(0원·N% 절감)=전용 슬롯 없음 → **자유합성**.
- **D ↔ E** — D=화면 **단독**으로 충분 / E=에디터+**결과폰 인과 한 쌍**("만들면→나온다"). 결과폰 동반이면 E.
- **D-에디터 ↔ D-통계** — 같은 틀. 통계/대시보드면 **`EMPHASIS_SLOT`로 핵심지표 확대 필수**(단순 캡처 ❌).
- **L(가로) ↔ S(정사각)** — L=도입/섹션 메인·비교/시연 / S=본문 중간 포인트·짧은 보조.

**구 L~R 라우팅** (전용 슬롯 폐지 후)

| 구 유형 | 지금 |
|---|---|
| L 실사진 | 실사진 소싱 → 풀스크린/A틀 차용 |
| M 외부캡처(경쟁사·툴·인스타) | 캡처 → **C틀(나열)** 또는 단순 배치 |
| N 개념도·O 문제신·R 수치 | **자유합성**(다이어그램/메모지+아이콘/큰 숫자) |
| P 가격표·Q 콜라주 | 캡처 또는 freeform |

**상황별 빠른 색인**

| 상황(본문 메시지)        | 템플릿                      |
| ----------------- | ------------------------ |
| 제품/페이지 소개·도입      | **A**(L)                 |
| 결과물 여러 페이지/사례 나열  | **C**(L) · 2개 **C-sq**   |
| 기존 방식 vs CdBd 대비  | **B**(L) · 본문중간 **B-sq** |
| 에디터에서 만드는 법(결과까지) | **E**(L)                 |
| 관리/CRM/설문 화면 자체   | **D**(L)                 |
| 성과·페이지뷰·통계        | **D**(L, 통계모드+EMPHASIS)  |
| 단계별 사용법 1·2·3     | **F**(L)                 |
| 현장 사진·고객 사례       | 실사진 소싱(A틀)               |
| 경쟁사·외부 툴 화면       | 캡처→**C**/단순              |
| 큰 숫자 훅(0원·N%)     | 자유합성(수치)                 |
| QR 배포·폰+보조카드      | **G**(sq)                |
| 가격 플랜 비교표         | 캡처/자유합성(가격표)             |

> 📌 **역할 분리**: [[1-0. 주제]] §2.1 = 주제별 **후보 풀** / 본 §1 = 개별 이미지 1장의 **최종 픽**. 파트(divider)별 매핑 원칙은 [[1-0. 주제]] §2.2.
