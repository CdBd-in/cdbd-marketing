# 외부·실사 콘텐츠 유형 (L ~ R)

> 기존 11유형(A~K, [[1-2-1. 레이아웃 규칙]])은 전부 **CdBd viewer 목업·에디터 캡처** 합성 유형이다.

## L. 브랜드 실사진 / 현장 포토 〔소싱/촬영〕

> 사례·소트리더십 글에서 **실제 매장·팝업·전시·제품·인물**을 보여줄 때. CdBd UI 아님.

- **언제**: 장르 ① 사례 / ⑤ 소트리더십
- **하위 종류**:
  - 현장 외관/내부 (팝업스토어·전시부스·플래그십) — 귤메달 prika, 뷰미디어 박람회, 넷플릭스 하우스
  - 제품/굿즈 디테일, UGC 먹방 스틸 (성심당 시루)
  - 오피스 인물 (뒷모습으로 CdBd 에디터 편집 장면) — "사람들이 이미 쓴다" 신뢰 샷
  - 흑백 권위자 인물 (Jakob Nielsen 등 — 인용 신뢰)
- **제작**: Figma 합성 ❌. **실사진 아카이브에서 선택** → 캔버스에 배치(라운드 40px). 촬영본 없으면 케이스 담당자 제공분 사용.
- **자동화**: 본문이 실사진을 요구하면 → "실사진 필요" 플래그 + 슬롯 비워두고 사람 큐로.
- **토큰**: 캔버스 라운드만 적용, 그 외 viewer 톤 따름. 라벨 pill 거의 없음.

## M. 외부 화면 캡처 (경쟁사·외부툴·인스타·구글) 〔캡처〕

> 라운드업·비교·소트리더십 글에서 **CdBd 밖의 화면**을 근거로 보여줄 때. **생성 불가, 반드시 실제 캡처.**

- **언제**: 장르 ③ 비교 / ⑦ 프로필링크 / ⑧ 라운드업 / ⑤ 소트리더십
- **하위 종류**:
  - **경쟁사 화면**: 링크트리·리틀리·인포크링크 홈/에디터/요금 (프로필링크 비교)
  - **외부 SaaS 툴**: Jasper·Surfer·Midjourney·Lexica·Manychat·Vrew·Meta Edits (AI툴 라운드업)
  - **레퍼런스 사이트**: Pexels·Pixabay·open.ads 등 (무료이미지/마케터 레퍼런스 — **항목당 1장**)
  - **인스타 앱 화면**: 실제 프로필/피드/릴스 (프로필링크 한계, 실브랜드 케이스) — 폰 2~3개 스트립
  - **구글 AI Overview**: "프로필 링크 추천" 검색 결과에 CdBd가 인용된 화면 + **빨간 박스 강조** (소셜프루프)
- **제작**: **Playwright 헤드리스 캡처** — [[1-3. 이미지 규칙]] §4.1 CdBd viewer 캡처 인프라를 **URL만 외부로 바꿔** 재활용. 캡처 후 캔버스에 카드로 배치(라운드·그림자).
- **자동화**: 본문이 특정 외부 URL/툴을 지목하면 → 캡처 큐(URL 리스트) → 캡처 → 슬롯 fill. 라운드업은 "항목 N개 → 캡처 N장" 루프.
- **주의**: ⚠️ **저작권/상표** — 경쟁사·외부 로고 노출은 비교·인용 목적 한정. 구글 AI Overview는 CdBd 강조 박스만 추가.

## N. 개념 인포그래픽 / 다이어그램 〔Figma 합성 — 신규 슬롯 필요〕

> "구조·로직·관계"를 그림으로 설명. CdBd 화면이 아니라 **개념도**.

- **언제**: 장르 ⑤ 소트리더십 / ⑦ 프로필링크 / ② 가이드 (로직 설명 섹션)
- **하위 패턴**:
  - **분기 링크 다이어그램**: `URL(cdbd.in/brand/26spring) → A/B/C/D 고객` 개인화 링크 (손그림 wavy 커넥터 + 보라 노드박스)
  - **2×2 사분면 / 조건 그리드**: "참석자 명단 자동화 4조건" 등 — 중앙 알약 타이틀 + 셀마다 3D 아이콘+라벨
  - **팬아웃**: `엑셀 1장 → 전 직원 명함` 분기
  - **개념 대비**: 검색시대 vs 발견시대, 로봇→인간화→인간 (3D 메모지 + 점선 화살표)
  - **아이소메트릭 일러스트**: CTA·AI글쓰기 인사이트 커버 (전구-연필 등, 스톡 일러스트성)
- **제작**: Figma 합성. **신규 슬롯 템플릿 필요** — `NODE_BOX_*` · `CONNECTOR_*`(SVG 손그림 화살표) · `CENTER_PILL` · `ICON_SLOT_*`(3D). 라벤더/화이트 격자 캔버스.
- **토큰**: 보라 노드박스 `#6C4CFF`/라벤더, 손그림 검정 화살표, 3D 아이콘(Thiings), 격자 BG.

## O. 문제 드라마신 (Pain Scene) 〔Figma 합성 + 3D 자산〕

> 페인포인트를 과장해 보여줌 — "이게 지금 당신의 문제죠".

- **언제**: 장르 ③ 비교 / ⑦ 프로필링크 (도입 훅)
- **하위 패턴**:
  - **3D 아이콘 클러스터**: 무채색 레거시 오브젝트(메일·전화·체크리스트) + 생각구름 + 고민 메모지 (흩어진 채널)
  - **메시 콜라주**: 구글폼+스프레드시트+카톡 스크린 콜라주 + 날리는 종이 + 스트레스 메모지(머리 위 새) (야근/수기취합 고통)
  - **구독비용 걱정**: 동전/달력/시계 생각구름 + 고민 메모지 (요금 부담)
- **제작**: Figma 합성. 3D 자산(Thiings) + 메모지 + 말풍선 배치. `BG`·`ICON_SLOT_*`·`MEMOJI_SLOT`·`BUBBLE_*`.
- **토큰**: 보라/그레이 BG, 무채색 3D(문제 강조), 메모지 표정(고민/현기증), 말풍선.

## P. 가격 비교 표 〔Figma 합성 또는 캡처〕

> 경쟁사 요금제를 항목별로 비교.

- **언제**: 장르 ④ 비용(무료 vs 유료) / ⑧ 라운드업(서비스 비교)
- **구성**: 플랜 카드 N개(플랜명 + $가격 + 원화 알약) + 기능 체크리스트. 추천 플랜은 강조 배지.
- **제작**: ① 실제 요금표 **캡처**(M과 동일 인프라) 또는 ② Figma 표 합성(`PLAN_CARD_*`·`FEATURE_ROW_*`).
- **토큰**: 흰 카드 + 보라 강조, 추천 플랜 라임 배지. 원화/달러 병기.

## Q. 스티커 콜라주 〔Figma 합성〕

> 폰트·이미지모양 등 **샘플 칩을 흩뿌려** 다양성/풍부함을 표현.

- **언제**: 장르 ⑥ 기능출시(폰트·이미지모양 소개) / ⑦ 프로필링크(커스터마이즈) / ④(올리브영 패러디 프로모)
- **구성**: 흰 배경에 기울인 텍스트/모양 칩 다수(블루+화이트), 3D 구미(gummy) 로고, 메모지 신체부위, 스퀴글 악센트. 정적/gif 모두.
- **제작**: Figma 합성. `CHIP_*`(랜덤 회전) · `LOGO_3D` · `SQUIGGLE`.
- **토큰**: 블루 `#2B6BFF`+화이트 칩, 세이지/화이트 BG, 옐로 스퀴글.

## R. 효익·수치 일러스트 〔Figma 합성 + 3D 자산 — 신규 슬롯 필요〕

> 비용/ROI를 **큰 숫자 + 상징 오브젝트**로 각인. (기존 **I. 에디터+통계**는 실제 통계 카드 — R은 일러스트형으로 구분)

- **언제**: 장르 ④ 비용/ROI (도입 훅)
- **하위 패턴**:
  - **시소(저울)**: 종이명함 더미+돈자루(무거움) vs "월 500원" 배지(가벼움), 아치 텍스트 "90% 절감"
  - **돈자루 + 종이더미 vs 모바일 명함** 대비
  - **ESG형**: 발광 원 안 지구+새싹, "17그루 / 80%" 배지
  - **다크 stat 히어로**: 니어블랙 배경 + 큰 숫자 + 폰 1대 (시리즈 인트로 톤)
- **제작**: Figma 합성. **신규 슬롯 템플릿 필요** — `BIG_NUMBER` · `OBJECT_SLOT_*`(시소/돈자루/지구새싹, Thiings) · `BADGE`.
- **토큰**: 보라/다크 BG, 큰 숫자 Pretendard Bold 60~120px, 3D 상징 오브젝트, 아치/배지 텍스트.

## 기존 11유형(A~K)과의 관계 / 변형 메모

- **갤러리 스트립(폰 4~5개 가로 일렬)**: 기존 **C(목업+목업, 2×2 4폰)**의 가로 변형. 별도 유형 추가 대신 **C-가로 변형**으로 처리.
- **A 히어로 다크 변형**: 시리즈/인사이트 글은 니어블랙 배경 + 폰 1대 + 좌측 헤드라인. → A의 다크 변형(커버성). 본문용은 기존 A(3폰) 유지.
- **커버/썸네일(타이틀 박힘)**: 본 폴더(이미지) 아님 → [[블로그/썸네일]]에서 관리.

> 📌 참고: 초기 분석 메모는 역할 기반 글자(A~P)를 썼으나, 본 디자인 가이드의 **구성 기반 A~R 글자**(기존 11 + 신규 7)가 정식 체계다.
