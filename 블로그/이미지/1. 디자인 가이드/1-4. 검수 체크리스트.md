## A. 캡처 의도 (캡처 전 — 가장 중요) 🎯

> "사람이 이 화면을 보면 무엇에 주목하나"를 먼저 정하고, **그 영역만** 캡처/크롭한다. 풀 화면 덤프는 의도가 사라진다.

- [ ] **이 이미지가 전달할 메시지 1줄**이 정해졌는가? (예: "RSVP 폼을 이렇게 만든다")
- [ ] 그 메시지의 **초점 요소**가 무엇인지 정했는가? (특정 카드/패널/섹션)
- [ ] **풀 에디터 3분할 덤프를 그대로 쓰지 않았는가?** → 의미 영역으로 크롭하거나 해당 컴포넌트만 사용
  - 예: "RSVP 폼" = 질문과답변 폼 자체 / "카드 조립" = 카드 빌더(중앙) 영역 / 통계 = 통계 패널
- [ ] viewer 멀티폰(A·C·F)은 **같은 캡처 복붙 ❌** → 의미 섹션 N개로 분할 ([[1-3. 이미지 규칙]] §4.1)
- [ ] 캡처가 **빈 화면(lazy-load 실패)** 아닌가? (흰/단색 PNG면 다른 슬러그·재시도)
- [ ] 라벨과 **콘텐츠가 일치**하는가? (예: 라벨 "카드 조립"인데 우측 "페이지 테마" 패널 캡처 ❌)

## B. 정렬·맞춤 (fill 후)

- [ ] 슬롯/요소가 **프레임 중앙**에 맞는가? (좌우뿐 아니라 **상하 중앙도**) — `x=(W-w)/2`, `y=(H-h)/2`
- [ ] 캡처 **aspect = 슬롯 aspect** 인가? (다르면 FILL이 의도치 않게 crop → 핵심이 잘림)
- [ ] 이미지가 **왜곡(늘어짐)** 없는가? (identity `imageTransform` + 정확한 aspect)
- [ ] **z-order**: 폰 프레임(`MOCKUP_PHONE`) 아래, 캡처(`SCREEN`) 위 — 화면이 폰 뒤로 안 숨었나
- [ ] 여백이 과하지 않은가? 초점 요소가 **너무 작게 떠 있지 않은가** (필요시 키우되 C 주의)

## C. 텍스트·컴포넌트 무결성 ⚠️

- [ ] **컴포넌트의 숫자·텍스트가 살아있는가?** (예: 통계 430/150/34.88%)
  - 🔴 **`rescale()`은 컴포넌트 텍스트를 깨뜨릴 수 있다** → 컴포넌트는 **원본 크기로 배치** 권장. 키워야 하면 관련 폰트 전부 `loadFontAsync` 후 시도하고 반드시 재확인.
- [ ] 한글이 **두부(□□□)로 안 깨졌는가** — 라벨은 **Pretendard** 로드 후 작성
- [ ] 차트/축 라벨 등 디테일이 누락되지 않았는가

## D. 라벨 (컨텍스트 pill)

- [ ] 라벨이 **필요한 유형**인가? (B·E·F 등) — A·C·I 등은 시각 자체로 명확 → **라벨 없음**
- [ ] D 유형은 **라벨 슬롯 없음**(2026-06-22 규칙) — 콘텐츠가 자체 설명
- [ ] 라벨이 있다면: **Pretendard SemiBold · 흰 텍스트 · `#6C4CFF` 알약 · 상단 중앙**
- [ ] 라벨 텍스트 = **컨텍스트(무엇을 보여주는지) 5~12자** — 가치제안·CTA ❌
- [ ] 자연스러운 라벨이 안 나오면 → 억지로 넣지 말고 `remove()`

## E. 콘텐츠 정확성

- [ ] 이미지의 **수치가 본문과 모순되지 않는가** (제품 데모 수치 사용 시: 본문 주장과 충돌 ❌)
- [ ] **더미 데이터** 사용 — 실명·실제 고객 로고·실제 개인정보 노출 ❌ (THE SAGE·황영기 등 더미)
- [ ] 오타·잘린 글자 없음

## F. 브랜드 일관성

- [ ] 캔버스 = 공식 `BG_CANVAS` (locked, 직접 안 그림) — 컬러/그리드 정상
- [ ] 강조색 = CdBd 퍼플 `#6C4CFF` 계열, 한 이미지 1 강조 톤 ([[1-1. 스타일]])
- [ ] 모서리 라운드·그림자 등 시그니처 요소 일관

## G. 정리 (cleanup)

- [ ] 모든 슬롯의 **점선 placeholder stroke 제거**(`strokes=[]`)
- [ ] 안 쓰는 슬롯 `remove()` / 숨김 처리 (빈 회색 박스 노출 ❌)
- [ ] `upload_assets`가 만든 **임시 프레임 삭제** (⚠️ `nodeId` 직접배치는 fill 안 됨 → 해시 받아 `use_figma`로 대입)
- [ ] 출력 페이지(`💻 AI 블로그 이미지 제작` `1:20182`)에 정돈 배치

## H. 최종 게이트

- [ ] **`get_screenshot`으로 최종 1장 육안 확인** — 위 A~G가 실제 렌더에서 모두 OK
- [ ] 통과 못 한 항목이 있으면 **사용자에게 보여주기 전에 수정**
