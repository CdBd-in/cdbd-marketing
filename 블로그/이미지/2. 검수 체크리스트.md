## 🔴 사고 빈발 TOP 7 — 먼저 확인 (실제 사고 재발 방지)

> 이 7개에서 사고가 가장 많이 났다. **여기부터 점검.**

1. [ ] **멀티페이지 목업 `98:2643`** — `Change-This` 2개 중 **내부 화면(height 큰 쪽, aspect 0.462)** 에만 FILL / **외부 오버레이는 `visible=false`**. (외부에 채우면 콘텐츠 띠로 찌부러짐)
2. [ ] **상단 로고/헤더 잘림 ❌** — 풀페이지(y=0부터) 캡처 + 화면비 **FILL**. "화보만 확대"로 로고 사라지면 실패.
3. [ ] **통계/대시보드 단순 캡처 ❌** — 핵심 지표 카드를 **확대·팝업**(`EMPHASIS_SLOT`)해 시선 유도. (안 하면 뭐가 핵심인지 안 보임) ※ 통계는 **D. 에디터/통계** 템플릿 사용(I→D 통합, 2026-06-23) — 통계 화면일 때 EMPHASIS_SLOT 필수.
4. [ ] **`rescale()` ❌** — 컴포넌트는 **원본 크기 배치**. (rescale이 컴포넌트 텍스트/숫자 파손)
5. [ ] **콘텐츠 점유율 ≥ 55%** (빈 공간 ≤ 45%) — 모든 시각 요소를 감싸는 **bounding box 면적 ÷ 캔버스 면적 ≥ 0.55**. 또한 **상단·하단 단일 여백 각 ≤ 25%**.
   - **미달 시 (= 너무 휑함)**: 본문을 **재분석**해 보강안 결정 — ① 전후 대비(예 "재인쇄 100%"(취소선)→↓→"0원") · ② 보조 수치/요소 추가 · ③ **1000×1000(Square) 전환**.
   - 🔴 **수정 전 사용자 확인 필수** — 점유율 미달로 이미지를 고쳐야 하면, **"여백 N% / 점유 M% → 이렇게 보강하겠다(또는 1000×1000 전환)"** 를 먼저 보고하고 **사용자 승인 후 수정**. 임의 보강 ❌.
6. [ ] **aspect = 슬롯 aspect** — 다르면 FILL이 핵심을 crop. identity `imageTransform` + 정확한 비율.
7. [ ] **`upload_assets` nodeId 직접배치 ❌** — 해시 받아 `use_figma`로 fill. (nodeId 배치는 fill 안 됨)

## ✅ 기본 검수 (빠르게 훑기)

**의도·내용**
- [ ] 이미지가 **해당 divider 파트와 직접 관련** (무관한 파트에 억지 삽입 ❌)
- [ ] 전달 메시지 1줄 + **그 영역만** 캡처 (풀 에디터 덤프 ❌)
- [ ] 멀티폰(A·C·F)은 **같은 캡처 복붙 ❌** (의미 섹션 N개 분할)
- [ ] 라벨 ↔ 콘텐츠 일치 / 빈 화면(lazy-load 실패) 아님
- [ ] 수치가 본문과 모순 ❌ / 더미 데이터(실명·실로고 ❌) / 오타 없음

**배치·무결성**
- [ ] 중앙 정렬 (**상하도** — `y=(H-h)/2`)
- [ ] z-order: 캡처(`SCREEN`)가 폰(`MOCKUP_PHONE`) 위
- [ ] 이미지 왜곡(늘어짐) 없음
- [ ] 한글 안 깨짐 (Pretendard 로드 후 작성) / 컴포넌트 숫자 살아있음

**라벨·카피** (상세 → [[1. 디자인 가이드/1-4. 카피 규칙 (라벨·캡션 텍스트)]])
- [ ] 라벨 **필요 유형만** (A·C·I·D는 없음) / 컨텍스트 5~12자 / 자연스럽지 않으면 `remove()`
- [ ] 카피 = **명사형 종결·마침표 없음** / 문장체·광고체·CTA ❌ / 추상어→구체어 / 비교 좌우 대칭 / 본문 용어와 일관

**정리**
- [ ] 점선 placeholder stroke 제거 / 빈 슬롯 `remove()` / 임시 프레임 삭제
- [ ] 출력 페이지(`1:20182`)에 정돈 배치
