## 🔴 사고 빈발 TOP 7 — 먼저 확인 (실제 사고 재발 방지)

> 이 7개에서 사고가 가장 많이 났다. **여기부터 점검.**

> 🔴🔴 **0. (절대 최우선) 캡처 의미 적합성 — 사람이 이 이미지만 보고 블로그 내용을 이해하는가**
> 캡처할 **페이지/영역을 템플릿·이미지 분석으로 의도적으로 선택**했는지부터 확인. "아무 페이지나/스크롤 아무 데나" ❌ → **"이 메시지를 가장 잘 설명하는 화면"** 을 골라 캡처.
> - [ ] **카탈로그 = 표지(cover) 캡처** — 브랜드명·컬렉션 타이틀이 보여 "모바일 카탈로그"임이 한눈에. **상품 상세 페이지 캡처 ❌**(그냥 제품 사진으로 읽혀 의미 전달 실패).
> - [ ] **여러 목업은 표지로 통일** (목업마다 제각각 상품 페이지 ❌).
> - [ ] 글을 모르는 사람이 이 이미지만 보고 **"무엇을 말하는지" 즉시 이해**되는가.
> - 📌 사례: 2026-06-23 TCO 환경 — 상품 상세(p3) 캡처 → 표지로 교체.

1. [ ] **멀티페이지 목업 `98:2643`** — `Change-This` 2개 중 **내부 화면(height 큰 쪽, aspect 0.462)** 에만 FILL / **외부 오버레이는 `visible=false`**. (외부에 채우면 콘텐츠 띠로 찌부러짐)
2. [ ] **상단 로고/헤더 잘림 ❌** — 풀페이지(y=0부터) 캡처 + 화면비 **FILL**. "화보만 확대"로 로고 사라지면 실패.
3. [ ] **통계/대시보드 단순 캡처 ❌** — 핵심 지표 카드를 **확대·팝업**(`EMPHASIS_SLOT`)해 시선 유도. (안 하면 뭐가 핵심인지 안 보임) ※ 통계는 **D. 에디터/통계** 템플릿 사용(I→D 통합, 2026-06-23) — 통계 화면일 때 EMPHASIS_SLOT 필수.
   - 🔴 **페이지명 헤더 크롭 제외** — 캡처에 "◯◯ 통계 확인하기" 같은 **특정 페이지 이름이 노출되면 ❌** (글 주제와 안 맞아 보임). **통계 요약 영역만** 크롭해 토픽 무관하게.
   - 🔴 **EMPHASIS = 글이 강조한 지표** — 본문이 강조하는 데이터(예 "어떤 세트가 가장 많이 클릭" → 링크별 클릭 요약)를 파악해 **그 지표를 EMPHASIS_SLOT에** 넣음. 아무 지표나 강조 ❌.
   - 🔴 **통계는 로그인 캡처 대신 벡터 컴포넌트 사용** — **`페이지 통계` 컴포넌트(`159:6406`)** 인스턴스 → 필요 섹션(통계요약 / 링크별 클릭 / 제출 답변 / 예약·구독 현황) **크롭** → **데이터를 글에 맞게 편집**(기본값 0/placeholder). 벡터라 무한 선명·빨간박스 없음·헤더(페이지명) 크롭으로 제외. (구 캡처 방식 폐기 — 흐림·페이지명·빨간박스 문제)
     - 폰트 주의: 숫자가 `Indivisible`(미설치)이면 `loadFontAsync` 실패 → **Pretendard로 폴백** 후 편집.
4. [ ] **`rescale()` ❌** — 컴포넌트는 **원본 크기 배치**. (rescale이 컴포넌트 텍스트/숫자 파손)
5. [ ] **콘텐츠 점유율 ≥ 55%** (빈 공간 ≤ 45%) — 모든 시각 요소를 감싸는 **bounding box 면적 ÷ 캔버스 면적 ≥ 0.55**. 또한 **상단·하단 단일 여백 각 ≤ 25%**.
   - **미달 시 (= 너무 휑함)**: 본문을 **재분석**해 보강안 결정 — ① 전후 대비(예 "재인쇄 100%"(취소선)→↓→"0원") · ② 보조 수치/요소 추가 · ③ **1000×1000(Square) 전환**.
   - 🔴 **수정 전 사용자 확인 필수** — 점유율 미달로 이미지를 고쳐야 하면, **"여백 N% / 점유 M% → 이렇게 보강하겠다(또는 1000×1000 전환)"** 를 먼저 보고하고 **사용자 승인 후 수정**. 임의 보강 ❌.
6. [ ] **aspect = 슬롯 aspect** — 다르면 FILL이 핵심을 crop. identity `imageTransform` + 정확한 비율.
7. [ ] **`upload_assets` nodeId 직접배치 ❌** — 해시 받아 `use_figma`로 fill. (nodeId 배치는 fill 안 됨)

## ✅ 기본 검수 (빠르게 훑기)

**의도·내용**
- [ ] 이미지가 **해당 divider 파트와 직접 관련** (무관한 파트에 억지 삽입 ❌)
- [ ] 전달 메시지 1줄 + **그 영역만** 캡처 (풀 에디터 덤프 ❌)
- [ ] 멀티 화면(A 3폰 · **B 우측 폰** · C 4폰 · F 단계)은 **같은 캡처 복붙 ❌** — **서로 다른 viewer** 또는 **같은 viewer의 다른 페이지/섹션**을 각 화면에 넣음
- [ ] **소재 일치**: "모바일 카탈로그"를 보여줄 땐 **카탈로그 viewer**(oak_table·newarrival·lookbook 등) 캡처 — 초대장·예약 viewer로 대체 ❌
- [ ] 🔴 **한 게시글에 같은 유형 2장+ → 서로 다른 자산** (장끼리 동일 이미지 ❌) — 3D 오브젝트는 다른 아이콘(예 paper booklet↔book), 목업은 다른 카탈로그 또는 다른 페이지. 같은 글에서 똑같아 보이는 2장 금지
- [ ] **B 비교**: 좌=비교대상(부정)·우=우리 제품(긍정) / **좌측 자산 채도 다운(무채색, `filters.saturation=-1`)** · 우측 컬러 유지
- [ ] 라벨 ↔ 콘텐츠 일치 / 빈 화면(lazy-load 실패) 아님
- [ ] 수치가 본문과 모순 ❌ / 더미 데이터(실명·실로고 ❌) / 오타 없음

**배치·무결성**
- [ ] 중앙 정렬 (**상하도** — `y=(H-h)/2`)
- [ ] z-order: 캡처(`SCREEN`)가 폰(`MOCKUP_PHONE`) 위
- [ ] 이미지 왜곡(늘어짐) 없음
- [ ] 한글 안 깨짐 (Pretendard 로드 후 작성) / 컴포넌트 숫자 살아있음

**라벨·카피** (상세 → [[1. 디자인 가이드/1-4. 카피 규칙 (라벨·캡션 텍스트)]])
- [ ] 라벨 **필요 유형만** (A·C·I·D는 없음) / 컨텍스트 5~12자 / 자연스럽지 않으면 `remove()`
- [ ] 카피 = **명사형 종결·마침표 없음** / 문장체·광고체·CTA ❌ / 추상어→구체어 / 비교 좌우 대칭 / 본문 용어와 일관

**정리**
