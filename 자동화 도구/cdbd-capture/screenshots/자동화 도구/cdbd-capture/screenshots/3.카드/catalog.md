## 🎯 매핑 의사결정 트리 (Claude용)

```
타이틀에 CdBd 카드 키워드 ?
├── "예약/RSVP" → 예약-카드 + viewer (A 유형도 가능)
├── "답변/Q&A/폼" → Q&A-카드 OR gitbook-demo 답변-pie차트 ⭐ (데이터 풍부)
├── "통계/분석" → gitbook-demo 통계요약-페이지뷰28 ⭐ (데이터 풍부)
├── 단일 카드 키워드 (메뉴/프로필/텍스트/이미지/...) → 해당 카드 패널
├── "다단/조합/비교" → 2단 카드 (텍스트+이미지가 가장 흔함)
├── "다양한 기능/카드 종류" → 카드-추가-모달
└── 카드 키워드 없음 → 가이드 §3.2 다른 화면 검토
```

> ⚠️ **시각 임팩트 약한 캡쳐** (작은 파일 < 25KB): 구분선·코드·상품·유튜브 — 사용자 검수 시 데이터 추가 또는 다른 안 권장.
> ⭐ **데이터 풍부 (B 유형 최우선)**: 갤러리·Q&A·예약 (existing full screenshots) + gitbook-demo 통계/답변.
