### 6. ⭐ 레이아웃 결정 체계 ([[1-2-1. 레이아웃 규칙]])
- **이미지 유형(1차) × 타이틀 위치(2차) + 서브타이틀(직교) + 배경(특수)**
- 유형 결정 기준 (§1.1):
  - **A. 목업** — viewer(발행 페이지)에 보이는 기능 (RSVP·예약·프로필링크 등 → [[1-3-2. 이미지 리소스 북]] §3.1)
  - **B. 목업+에디터** — 에디터/관리 화면 기능 (레이어·팀공유·CRM·통계·QR·AI → §3.2). "기능 UI + 결과 목업" 결합
  - **C. 멀티 목업** — 화면 둘 이상 (타이틀 상단 고정)
  - **D. 3D 아이콘** — 개념을 상징 오브젝트로 (왜/이유/비교)
  - **E. 배경** — 외부 주제·리스티클 (Best N/추천), 매트릭스 밖·텍스트 중앙
  - **A vs B 핵심**: viewer에 보이면 A / 에디터 화면이면 B
- 적용 절차: 유형 파악 → 위치 변형 후보 제시 → 슬롯 clone
