## 핵심 기술적 노하우 (다른 기기에서 재현 시 참고)

### Microlink 호출 패턴
```bash
curl -s "https://api.microlink.io/?url={URL_ENCODED}&screenshot=true&meta=false&viewport.width=375&viewport.height=812&waitUntil=networkidle0&waitForTimeout=5000&full-page=true"
```
- `waitUntil=networkidle0` + `waitForTimeout=5000` 없으면 JS 렌더링 전 캡처되어 빈 페이지 나옴
- 모바일 뷰포트 권장 (`375×812`)

### Thiings 3D 오브젝트 URL 패턴
- `https://www.thiings.co/things/{slug}` → 페이지에서 PNG 다운로드 URL 추출
- 예: calendar, ai-sparkle, magic-wand 등

### Figma 이미지 업로드 패턴
1. `mcp__claude_ai_Figma__upload_assets` 호출 → submitUrl 받기
2. POST 파일 → imageHash 반환
3. `use_figma`로 노드의 `fills`에 `{ type: 'IMAGE', scaleMode: 'FILL', imageHash }` 적용

### Chrome headless PDF 변환
```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf="/path/to/output.pdf" \
  "file:///path/to/input.html"
```

### Figma MCP 텍스트 작업 시 주의사항
- 폰트는 **반드시 `loadFontAsync` 먼저** 호출
- Pretendard는 Figma MCP 환경에서 로드 불가 (시스템 폰트 한정)
- 사용 가능 한글 폰트: Noto Sans KR, IBM Plex Sans KR, NanumGothic 등
- 텍스트 내 색상 강조: `setRangeFills(start, end, [{...}])`
