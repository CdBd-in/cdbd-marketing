## 🆕 B 유형 자동화 — 신규 구조

### applyEditor 함수 (code.js)
```js
/**
 * B 유형 — EDITOR_SLOT 처리 (에디터/관리 화면 캡쳐)
 * 1-2-1 §3.2: contain — FIT scaleMode
 * 슬롯 좌표 (슬롯 템플릿 기정의):
 *   - 상단형 (1:1300/1:1308): x195/y250/w260/h154
 *   - 하단형 (1:1304/1:1314): x111/y50/w260/h154
 */
function applyEditor(parentSlot, editorImageHash) {
  const editorSlot = parentSlot.findOne((n) => n.name === "EDITOR_SLOT");
  if (!editorSlot || !("fills" in editorSlot)) return { success: false };
  editorSlot.fills = [
    { type: "IMAGE", imageHash: editorImageHash, scaleMode: "FIT" },
  ];
  if ("strokes" in editorSlot) editorSlot.strokes = [];
  return { success: true };
}
```

### variants JSON 신규 필드
- `editorImageHash` — B 유형에서 EDITOR_SLOT fill용

### B 유형 검증 예시 자산 (Figma 업로드 완료)
| 자산 | imageHash | 용도 |
|------|-----------|------|
| viewer (reservation hero) | `0de2ec3c8b98c465969192c4196881cdb5b15696` | VISUAL_SLOT 공통 |
| editor (예약 카드 추가 모달) | `336c582f7c737d5d6527d7d7022968a7acf3501c` | B 유형 EDITOR_SLOT |

> 💡 viewer는 Microlink로 캡쳐 (`https://api.microlink.io/?url=...&viewport.width=375&viewport.height=812`). 캐시 회피는 URL에 `?cb=timestamp` 추가.

| 항목 | 플러그인 | Claude 단순 | Claude 목업 |

- use_figma도 **목업 포함 동등 자동화 가능** 검증 — 단발 fallback으로 보존.
