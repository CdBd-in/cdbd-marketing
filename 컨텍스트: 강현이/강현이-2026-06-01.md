### E 유형 (배경·리스티클·외부 주제)
```
타이틀 입력
  ↓
selectLayoutType() → E 자동 판단
  ↓
selectDecoration() → §5.4·§5.1 매칭 → Thiings 3D (예: magic-wand)
  ↓
extractEmphasis() + autoLineBreak() → 의미 단위 3줄
  ↓
Lexica API → AI 배경 이미지 4개
Thiings URL 다운로드 → 보조 3D 아이콘
  ↓
applyBackground(opacity 20%) + applySecondaryIcon()
  ↓
1:1262 또는 1:1294 슬롯 4개 베리에이션
```

### A 유형 (목업·viewer 기능)
```
타이틀 입력
  ↓
selectLayoutType() → A 자동 판단
  ↓
selectViewerAssets() → §3.1·§2 17개 매핑 → cdbd.in viewer URL
  ↓
Microlink API → 375×812 모바일 캡처
  ↓
applyMockup() → 공식 목업 컴포넌트(75:34) 인스턴스 + CROP+imageTransform
  ↓
상단 1:1266 + 하단 1:1251 베리에이션 (서브 있으면 1:1269 + 1:1246)
```

## 📋 확정된 결정 (이번 세션)

### 1. 레이아웃 유형 자동 분류 우선순위 (가이드 §1.1 기준)
**C(복수) > E(외부주제) > D(주장·이유) > B(에디터) > A(viewer) > 폴백(A)**
- 각 단계에서 가이드 §1.1 신호어로 매칭
- 임의 키워드 만들지 말고 가이드 인용
- 질문형 + 미매칭 → E 폴백 (외부 주제 추정)

### 2. 강조어 자동 추출 우선순위 (가이드 §3 기준)
**1순위 제품·기능명 > 2순위 가치 제안 동사 > 3순위 차별점 > 4순위 핵심 명사**
- E 유형은 강조색 없음 (전부 흰색)

### 3. 줄 나누기 (autoLineBreak)
- 의미 단위(어절) 분리 + 그리디 알고리즘
- maxLine = 8.0 (E·A·B·C·폭300) / 9.5 (D·폭350)
- 공백 가중치 0.3em (`countDisplayLen`과 일치)
- `textAutoResize = WIDTH_AND_HEIGHT`로 자동 줄바꿈 fallback 완전 차단

### 4. 데코 자동 매칭 (가이드 §5.4·§5.1·§5.5)
- 1순위: §5.4 CdBd 기능명 (초대장→envelope, AI→magic-wand, 예약→calendar)

- 폴백: sparkle 1-4 랜덤
- Thiings URL 있으면 다운로드 fill, 없으면 Figma 컴포넌트 인스턴스화

### 5. E 유형 슬롯 분기 (가이드 §1.2 베리에이션 규칙)
