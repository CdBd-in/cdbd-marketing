## 🎯 가장 큰 발견 — CROP imageTransform 비율 보존 매트릭스

### 사고

올인컴플리트 첫 시안 제작 → A 안 2 / C 안 1·2에 풀페이지 캡처(750×8090, aspect 10.79)를 mockup screen(aspect 2.21)에 fill → **모자 grid 가로로 늘어남**

**잘못된 매트릭스**: `imageTransform: [[1, 0, 0], [0, 1, 0.55]]` (y-scale=1)

### 원인

Figma `imageTransform`은 **슬롯 좌표 → 이미지 좌표 매핑**. y-scale=1로 두면 슬롯 100% = 이미지 100% → 비율 무시 stretch.

### 정답

```js
const imgSize = await figma.getImageByHash(hash).getSizeAsync();
const yScale = (screen.height / screen.width) / (imgSize.height / imgSize.width);
screen.fills = [{
  type: "IMAGE", imageHash: hash, scaleMode: "CROP",
  imageTransform: [[1, 0, 0], [0, yScale, ty]],
}];
```

- `yScale = slot_aspect / image_aspect`
- `ty 범위 = 0 ~ (1 - yScale)`
- aspect 10.79 풀페이지면 yScale ≈ 0.205

mockup screen 찾을 때 모든 INSTANCE를 순회하면 sparkle/crown 데코 instance 내부 IMAGE fill까지 잡힘 → 데코 비율도 같이 깨짐. **방어 3종**:
