## 🆕 정착된 룰

### 1. sparkle instance — `rescale(0.75)` 필수 (resize 금지)

**문제**: sparkle3 instance(100×100)를 `resize(75, 75)`만 하면 외곽만 줄고 **내부 image rect(101×93)는 원본 좌표 유지** → frame `clipsContent`로 우/하 25px 잘림.

**해결**: `instance.rescale(0.75)` — 자식 vector까지 비례 축소. 비율 유지 + 잘림 ❌.

```js
const sparkle = master.createInstance();
deco.appendChild(sparkle);
sparkle.rescale(75 / sparkle.width);  // 0.75 — 자식까지 따라옴
sparkle.x = 0; sparkle.y = 0;
```

→ [[1-2-1. 레이아웃 규칙]] §2.4 판단 절차 #4에 정착.

### 2. 강조어 — "단어 1개" 폐기 → "의미 단위 1개"

**옛 룰**: "개수 항상 1개" — 단어 수 제한으로 오해.

**새 룰** ([[1-1. 스타일]] §3 재정립):
- **사람 직관 1차** — "이 글이 알리고 싶은 핵심 메시지"
- 강조 **영역**은 1개 (시각 균형)
- 그 영역 안 내용은 **의미 단위 1개** — 단어 1개일 수도, 한 구(phrase)일 수도
- 우선순위 4유형 표는 "참고용"으로 격하

**대표 예시**: "자사몰 상품 큐레이션 카탈로그를 5분에 만드는 법"
→ **"5분에 만드는 법"** (7자, 4어절 한 의미 단위) ⭕

**⛔ 금지**:
- 영역 2개로 갈라짐 ("**5분**에 만드는 **법**") ❌
