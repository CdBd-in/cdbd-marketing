## 4. 캡처 인프라 진화 — thum.io → Microlink → Playwright

### 4.1. thum.io fullpage 한계 발견
- TRINTAS personalized viewer: 750×7618 캡처 받았지만 콘텐츠는 y=0~1500만 (그 이후 빈 dark red)
- seminar (Heritage Summit) viewer: 동일 문제 — y=0~843만 콘텐츠 (그 이후 빈 흰 BG)
- **모든 CdBd 템플릿에 공통** — Next.js + React **scroll-triggered lazy load** 때문에 thum.io의 정적 fullpage 캡처가 RSVP form·연락처 섹션을 못 잡음

### 4.2. Microlink 시도 모두 실패
- 27s 타임아웃 빈번 (CdBd 페이지가 너무 무거움)
- `waitUntil=networkidle0`·`load`·`domcontentloaded` 다 시도 — 모두 fail
- `?page=N` URL parameter도 seminar에서는 무시됨 (seminar는 scroll viewer, swiper viewer 아님)

### 4.3. Fallback — 같은 hero의 zoom 변형 (사용자 거부)
- TRINTAS hero를 3개 다른 zoom으로: 전체 hero / 타이틀 zoom / 본문 zoom
- 사용자 피드백: "지금 보면 목업 안 캡쳐본이 동일한 내용이 들어가있어"
- 이때 캡처 유의사항 체크리스트 추가 (§4.1)

### 4.4. 사용자 결정: Playwright 인프라 구축 (길 2)
- 사용자가 길 2 선택
- 썸네일에 이미 있는 `자동화 도구/cdbd-capture/` 패턴 재사용

## 5. Playwright 캡처 스크립트 구축 — `capture-seminar-3sections.mjs`

### 5.1. 스크립트 설계
- Playwright + Chromium 사용
- viewport 390×838 (A 유형 SCREEN aspect 0.4654 정확 매칭)
- 풀스크롤 → lazy-load 트리거
- 키워드 매칭으로 3개 의미 섹션 자동 탐지
- A 유형 SCREEN_1/2/3 매칭 PNG 3장 생성

### 5.2. 사용자 셋업 (Node.js + Playwright)
- 사용자 처음에 `npm: command not found` → Node.js 미설치
- nodejs.org에서 LTS 설치 안내 → 사용자 설치 완료 (v24.17.0 + npm 11.13.0)
- `npm install` + `npx playwright install chromium` (Chromium 169MB 다운로드)
- 첫 실행 시 스크립트 파일이 잘못 nested된 경로에 있어 `mv`로 교정

### 5.3. 스크립트 1차 버그 — 키워드 모두 hero에 매칭
```
1-hero: y=393 (✓ matched)
2-rsvp: y=393 (✓ matched)  ← 같은 y!
3-contact: y=393 (✓ matched)  ← 같은 y!
```
원인: hero 텍스트에 "참석하시어 고견을", "문의" 등 후속 섹션 키워드가 다 들어있음

### 5.4. 1차 fix — zone-restricted 키워드 검색
- 페이지 height를 3등분 (0~35% / 30~75% / 65~100%)
- 각 zone 안에서만 키워드 검색
- 결과: `1-hero y=393 / 2-rsvp y=2864 / 3-contact y=4243` ⭐ 3개 다른 y

### 5.5. 2차 fix — hero `forceY: 0` 강제 ⭐
- 1차 fix 후에도 hero가 y=393에서 잡혀서 **THE SAGE 로고 + "2025 The Heritage Summit" 타이틀이 잘림**
- 사용자 피드백: "템플릿의 히어로 섹션은 안 잘리게끔 수정 가능해?"
- 수정: `SECTION_HINTS[0]`에 `forceY: 0` 추가 → 키워드 매칭 스킵, 무조건 페이지 진짜 상단부터
- 모든 CdBd viewer hero가 페이지 상단에 있으므로 **일반 룰로 채택** (다른 viewer 스크립트에도 동일 적용)

## 8. 다음 세션 / 미해결 / 개선

- 자동화 코드(`code.js`) 작성 시 주의

### 8.3. B 유형 (비교) — placeholder rect만 있고 비유 자산 카탈로그 없음
- B는 PDF 아이콘·종이 더미·자물쇠 등 비유적 오브젝트 사용
