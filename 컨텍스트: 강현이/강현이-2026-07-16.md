## 🔴 반드시 기억할 함정 — 없는 슬러그도 HTTP 200을 반환

Thiings는 **존재하지 않는 슬러그도 200 + 사이트 기본 OG 이미지**를 준다. `response.ok`만 믿으면 **엉뚱한 기본 이미지를 아이콘인 줄 알고 다운로드**함.

**반드시 `og:image:alt`로 검증**:

```bash
curl -sL -A "Mozilla/5.0" "https://www.thiings.co/things/{slug}" \
  | grep -oE '<meta property="og:image:alt" content="[^"]+"'
# "<Name> 3D icon"           → 진짜 ✅
# "Thiings — AI-Generated…"  → 없는 슬러그 ❌
```

PNG URL은 같은 페이지 `og:image` content에서 확보.

| 검증 예시 | 결과 |
|---|---|
| `lantern` · `gift` · `lightbulb` | ✅ "Lantern/Gift/Lightbulb 3D icon" |
| `moon-cake` · `hands` · `bogus-xyz` | ❌ 200이지만 기본 OG |

## 🛠️ 자동화 파일 수정 (충돌 5건 발견 → 해결)

`자동화 도구/cdbd-thumbnail-plugin/`

| # | 문제 | 조치 |
|---|---|---|
| 1 | **컴포넌트 ID가 전부 죽어 있었음** — `code.js`의 `4:141`·`4:164~167`, `decorations.json`의 `14:2~5` → Figma 조회 결과 **전부 NULL** | 실제 `338:32xx`로 교체 (문서 §4.1이 정답이었음) |
| 2 | **금지된 sparkle1이 폴백 기본값** — 랜덤 풀에 포함 + 유일하게 URL이 유효했음 | 풀에서 제거 → `sparkle2/3/4`만 |
| 3 | `selectDecoration()`이 **13종 하드코딩에서만 선택** — 미등록이면 skip → sparkle 폴백 수렴 (= 반복의 원인) | **검색어 후보만 산출**하도록 재작성 |
| 4 | `ui.html`이 `thiings_url` 없으면 **다운로드 자체를 안 함** | `searchTerms` 루프 + `og:image` 해석 구현 |
| 5 | `manifest.json`에 `www.thiings.co` 누락 (`thiings.co`만) | 추가 |

**새 `selectDecoration()` 시그니처**
```js
selectDecoration(title, content, { topicTerms, avoidSlugs })
→ { searchTerms: [...], fallback: {slug, figma_id}, note }
```
- `topicTerms` = 글 고유 명사(가장 구체적, 최우선)
- `avoidSlugs` = 직전 썸네일 슬러그 회피

**새 흐름**: 고유 명사 → 검색어 후보 → Thiings 페이지 → `og:image` 해석(+alt 검증) → PNG 다운로드 → 실패 시 다음 후보 → 전부 실패해야 sparkle 폴백

> ⚠️ **플러그인 실행 테스트는 Figma 데스크탑에서 직접** 해야 함 (MCP로는 플러그인 UI 실행 불가). 문법·JSON 유효성은 통과 확인.
