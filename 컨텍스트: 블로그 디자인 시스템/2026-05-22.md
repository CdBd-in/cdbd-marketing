## 미완성 항목

### 섹션 5 — 비주얼 요소 유형 재정리 필요
현재 Type A/B/C/D로 임의 분류되어 있으나, **기준이 불명확**함.

방향: "썸네일 제작 시 어떤 이미지를 준비해야 하는가" 기준으로 재정리 필요.
논의된 대안:

| 유형 | 설명 | 준비 방법 |
|------|------|-----------|
| **목업** | CdBd 앱 화면 + iPhone 프레임 | 직접 캡처 후 목업에 삽입 |
| **3D 오브젝트** | 개념을 상징하는 3D 아이콘 | 외부 3D 에셋 사용 |
| **배경 이미지** | 주제 관련 사진/스크린샷 (Template 5 전용) | 직접 촬영 또는 캡처 |
| **앱/서비스 아이콘** | 비교하거나 언급하는 앱 로고 | 공식 로고 다운로드 |
| **데코** | 스파클, 이모지 등 보조 요소 | 이모지 또는 에셋 활용 |

→ 사용자 확인 후 섹션 5 업데이트 필요

---

## 주요 결정 사항

- 템플릿 분류 기준: **텍스트 위치(상단/하단/중앙) × 서브타이틀 유무** (피그마 공식 분류 따름)
- 비주얼 소재는 분류 카테고리가 아닌 **조합 가능한 요소**로 취급
- 강조색은 한 썸네일에 **1가지**만 사용
- Template 2, 4의 텍스트 위치는 `bottom: 40px` 고정 (줄 수에 따라 top값 가변)
- Template 5는 배경에 관련 이미지 opacity 20% 오버레이 처리
- 타이틀은 정해서 전달할 것이므로 텍스트 작성 규칙은 최소화
