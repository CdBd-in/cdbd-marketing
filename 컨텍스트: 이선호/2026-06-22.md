## 핵심 설계 결정사항 (= 확립된 규칙)

- **페이지 유형 = 표지/본문/뒷표지 3 카테고리**, 콘텐츠 받으면 유형 선택→슬롯 채우기.
- **표지 기본값 = Cover-IMG BG**, 설명 텍스트 없으면 슬롯 삭제. 뒷표지 마무리 문구는 **템플릿 기본 문구 고정**(CTA·URL로 임의 변경 ❌).
- **본문 배경 타입 통일**: 한 세트 본문은 img/solid/texture 중 하나로 통일. (이번 #01 = **다크 차콜 #1A1A1A solid**, 흰 텍스트)
- **본문 유형 호환성**: Half ✗ Collage·Article (혼용 금지). Collage+Article은 같은 배경이면 혼용 OK.
- **Half = 가로 비율 이미지 전용**, 세로 원본은 Full Bleed/Article(세로 이미지 블록). 이미지 영역 세로 길이 가변(제품 과크롭 금지).
- **이미지**: 부모 프레임 fill ❌ → 내부 RECTANGLE 레이어, 여백 없이 풀필(clip). 인물은 룩북 2-4 배치 규칙.
- **이미지 소싱**: Illust 3D 아이콘 = **Thiings**, 그 외 = 보유 이미지 가공. 실제 브랜드 이미지 사용 시 **출처 필수 표기**.
- **누끼(배경 제거) = 사용자 요청 사항** (직접 처리 ❌). 원본 흰배경 업로드→Remove background 요청→완료 후 **alpha bbox 크롭 + 면적 균등화**(`w=√(S·a), h=√(S/a)`).
- **포인트 컬러 1색 세트 내 통일**.
- **하이라이트**: 색은 **템플릿 원본 색**(#FFB700 앰버 / #CCFF00 라임 / #FFCD4E 골드)에서 선택. 디자인은 **템플릿 형광펜 스타일**(square 모서리 cr=0, 글자폭에 딱, 높이≈폰트×1.12, 어두운 글자 #141414 위). Illust 페이지엔 #FFCD4E.
- **dim 그라데이션 표준**: 세로(투명→검정) + **paint opacity 0.5**. (이미지/목업 위 텍스트용)
- **페이지 번호 전부 삭제** (템플릿 원본에서 사용자가 삭제함).
- **CdBd 카드명·기능 정확**: 카피의 기능 설명은 디자인 시스템 「4. 카드 기능 정의」 기준. 없는 카드명 금지. (이번 수정: "응답 카드"❌→**질문과 답변 카드**, "예약"❌(시간대 예약용)→**RSVP**(참석여부), "5분 제작"(미검증)→"빠르게 직접 제작")
- **카피 톤**: 친근한 구어체(~요/~죠), 절 단위 줄바꿈. 이 사례는 **과거형**(매장 오픈 지난 일).

## Figma MCP 기술 메모 (다음 세션 주의)

1. **imageHash 캐시 버그(중요)**: 사용자가 Figma "Remove background" 후에도 MCP `fills[].imageHash` 읽기는 **제거 전 원본 해시를 캐시**해서 반환함. → fill을 해시 문자열로 **새로 조립하면 흰배경 원본으로 되돌아감**. **반드시 기존 fill 객체를 spread(`{...f}`)해서 scaleMode/imageTransform만 덮어쓸 것** (실제 이미지 참조 보존). 한 번 이 실수로 사용자 누끼가 날아가 재요청한 사례 있음.
2. **node.query() 셀렉터에 한글 불가** (`Invalid selector` 0xed). 한글 이름 매칭은 `children.find(c=>c.name===...)` 으로.
3. **upload_assets**: nodeId 지정은 count=1만. 다중은 count=N→POST(bash `/bin/bash`로, 기본 zsh라 `${!arr[@]}` 등 실패)→imageHash 회수→use_figma로 fills 설정.
4. **auto-layout 자식 오버레이/스크림**: VERTICAL auto-layout에 스크림 추가 시 `layoutPositioning="ABSOLUTE"` 안 주면 flow에 끼어 텍스트가 밀려남. 절대배치 필수.
5. **중심 고정 회전**: `node.rotation` 대신 relativeTransform로 `M*(local center)=고정 center` 풀어서 e,f 계산 → 회전 방향 무관 중심 유지.
6. **CROP+면적정규화**: 누끼/아이콘 여백 제거는 로컬 원본에서 콘텐츠 bbox 측정 → `scaleMode:"CROP" + imageTransform:[[bw,0,bx],[0,bh,by]]` + `resize(√(S·a),√(S/a))`. (배경제거는 재처리 X, 받은 투명본 사용)
7. **get_screenshot**: URL 반환 → `curl -o`로 받아 Read. 한 번에 여러 프레임 병렬 요청 가능.
