## Figma MCP / 캡처 기술 메모 (다음 세션 주의)

1. **Playwright 설치 = bun으로**. 이 환경엔 `node`(1.3.14 더미)·`npm` 없음, **`bun`만** 있음(`~/.bun/bin/bun`). `cd cdbd-capture && bun install && bunx playwright install chromium`. 실행 `bun script.mjs`.
2. **textAutoResize 변경 전 폰트 로드 필수**. `t.textAutoResize='HEIGHT'`는 reflow를 일으켜 폰트 미로드 시 throw. (1차 sweep 때 try/catch가 에러를 skip으로 집계해 "0 변경"으로 오판한 사례)
3. **auto-layout 텍스트 프레임은 자식 `.y` 설정 안 먹힘** → `itemSpacing`으로 제목-본문 간격 조절.
4. **하이라이트 박스 trailing space**: `createText`로 "단어 앞 텍스트+공백" 측정 시 끝 공백이 트림돼 폭이 짧게 나옴 → 박스 좌측 치우침. **`W(라인시작~단어끝) − W(단어)`** 방식으로 우측 기준 계산하면 해결.
5. **node.query() 한글 셀렉터 불가**(재확인). `children.find(c=>c.name===...)` 사용.
6. **upload_assets**: count=1 + nodeId로 해당 노드 fill 설정. URL 받아 `curl -F "file=@..."` POST → 응답 imageHash 회수.
7. **텍스처 frame fill 순서**: `[{SOLID 흰색}, {IMAGE FILL}]` — 이미지가 **배열 마지막(=위)**이어야 보임. 흰색을 위에 두면 텍스처 가려짐.
8. **frame.clone() → 다른 section으로 이동**: `clone()`은 같은 부모에 생성 → `targetSection.appendChild(clone)` 후 x/y 재설정. 텍스처 버전은 다크 페이지 clone + frame fill 텍스처 + 직속 흰 텍스트 dark 재색.
