## 핵심 설계 결정사항 (다음 세션이 따라야 할 새 기준)

- **캡션이 진실의 원천**: CdBd 블로그 본문엔 이미지 자리마다 `*캡션*`이 박혀 있다. **글을 장르로 분류하거나 이미지 수를 추론하지 않는다** — 캡션 1개 = 이미지 1장, 위치·개수·내용은 캡션이 결정. 캡션 없는 자리엔 이미지 안 만듦.

- **Wix MCP API URL은 대화 컨텍스트에서만** — `SearchWixAPISpec`로 `lightIndex` 검색해 `method.publicUrl` 확보 후 `CallWixSiteAPI`. `body`는 실제 JSON 객체로 전달(문자열 ❌).
