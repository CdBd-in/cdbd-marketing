## Figma MCP 기술 메모

1. 🔴 **한글 레이어명 매칭 실패(NFD/NFC)** — Figma 노드명 "스크린샷…"은 **NFD(자모 분리)** 로 저장돼, 코드의 NFC 문자열 리터럴로 `findAll(n=>/스크린샷/.test(n.name))`·`indexOf('스크린샷')===0` 하면 **매칭 0**. → **명시적 노드 ID** 또는 **구조(phone→Frame 427324063→RECTANGLE child)** 로 식별할 것.
2. **rounded-rectangle의 실제 type은 `RECTANGLE`** — get_metadata XML의 "rounded-rectangle"은 표시명. `findAll(type==='ROUNDED_RECTANGLE')`는 항상 빈 배열.
3. **오토레이아웃 프레임 내 rect는 `y` 설정 무효** — 세로 위치는 프레임 `primaryAxisAlignItems`('MIN'/'CENTER'/'MAX') 또는 `paddingBottom`으로 제어. 여백 노출 시 **프레임 fill=페이지 배경색**으로 이음새 제거.
4. **롱스크롤 이미지 프레이밍 = CROP `imageTransform` 복사** — 승인본 rect의 `fills[0].imageTransform`을 그대로 재사용(명함 A1 = `[[1,0,0],[0,0.2735,0]]`).
5. **screenshot 범위 = 그 노드 서브트리만** — 마킹 박스를 clone(프레임)의 형제로 붙이면 phone 노드만 스크린샷할 때 안 보임 → **clone 전체를 스크린샷**해 확인.
6. **삭제는 명시 노드 ID로만**(좌표·이름 휴리스틱 금지 — 과거 무관 프레임 대량삭제 사고). 구 C4 `422:1692`·구 C5 `423:1663`만 `remove()`.
7. **use_figma는 원자적** — 스크립트 오류 시 아무 변경 안 됨. 오류 문구 읽고 수정 후 재시도.
