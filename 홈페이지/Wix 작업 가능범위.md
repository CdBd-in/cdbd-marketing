# Wix(CdBd) 작업 가능범위 분류

Claude가 연결된 **Wix MCP(REST API)** 를 통해 **직접 작업 가능한 것**과 **불가능한 것**을 분류한 문서입니다.
요청하실 때 이 표를 참고하면, 제가 처리할 수 있는지 미리 가늠할 수 있습니다.

> 핵심 원칙
> - **MCP가 다루는 것** = 비즈니스/백엔드 데이터 + 사이트 관리 (REST API로 노출된 영역)
> - **MCP가 못 다루는 것** = Wix Studio 에디터 캔버스의 시각적 디자인/레이아웃 (디자인 타임 영역)

---

## ✅ 직접 작업 가능 (MCP REST API)

| 분류 | 작업 예시 |
|------|-----------|
| **사이트 조회/관리** | 사이트 목록·정보 조회, 도메인 검색·구매, 게시(Publish) |
| **사이트 속성** | 결제 통화 변경, 지역·언어 설정 확인 |
| **블로그** | 블로그 글 생성·수정·게시, 카테고리/태그 지정, 이미지 업로드 |
| **CMS(컬렉션)** | 컬렉션 생성/스키마 수정, 데이터 항목 CRUD, 일괄 등록/수정, 참조 관계 관리 |
| **상품(Stores)** | 상품 생성·수정·검색, 옵션/변형 관리, 카테고리, 재고/예약판매, 이미지로 상품 생성 |
| **이커머스** | 쿠폰·할인 규칙, 배송 옵션/지역/요율, 무료배송 임계값 설정 |
| **예약(Bookings)** | 서비스 생성·수정, 직원/근무시간, 리소스, 예약 정책, 결제 연동 |
| **연락처(CRM)** | 연락처 일괄 라벨링/삭제, 폼 생성 |
| **결제(Get Paid)** | 결제 링크 생성, Wix Payments 설정 |
| **미디어** | 외부 URL → Wix 미디어 매니저 업로드, 사이트 이미지 업로드 |
| **앱** | 설치된 앱 조회, Wix 앱 설치 |
| **리치 콘텐츠** | Ricos ↔ HTML/Markdown 변환 |
| **사이트 생성** | AI로 신규 Wix 사이트 생성/빌드 |

---

## ❌ 직접 작업 불가 (에디터에서 직접 해야 함)

| 분류 | 작업 예시 | 이유 |
|------|-----------|------|
| **레이어/요소 이름(nickname) 변경** | `floatingbtn` → `floatbtn` 등 | 에디터 디자인 데이터, REST API 미노출 |
| **요소 ID 변경** | `#myButton` ID 수정 | 에디터에서만 변경 가능 |
| **레이아웃/위치/크기 조정** | 요소 드래그, 정렬, 간격 조정 | 캔버스 시각 편집 영역 |
| **디자인 스타일** | 색상·폰트·테두리·그림자 등 요소 스타일 | 에디터 디자인 패널 영역 |
| **섹션/페이지 시각 구성** | 섹션 추가·삭제, 페이지 레이아웃 변경 | 에디터 캔버스 영역 |
| **애니메이션/인터랙션** | hover 효과, 스크롤 애니메이션 | 에디터 설정 영역 |
| **Velo 코드 직접 편집** | 페이지 코드(.js) 수정 | 로컬 Wix CLI 프로젝트 필요 (MCP 아님) |

---

## ⚠️ 조건부 가능 / 별도 환경 필요

| 작업 | 조건 |
|------|------|
| **Velo 코드 검색·수정** | 로컬에 `wix-cli`로 받은 사이트 코드 프로젝트가 있어야 함. 파일 경로를 알려주면 검색·수정 가능 |
| **요소 ID 참조 영향 확인** | 위와 동일하게 로컬 코드 프로젝트가 있어야 정확히 확인 가능 |

---

## 빠른 판단 기준

- **"데이터를 넣고/빼고/바꾸는" 작업** → 대체로 ✅ 가능 (상품, 글, 컬렉션, 예약 등)
- **"보이는 모습을 손보는" 작업** → 대체로 ❌ 불가 (에디터에서 직접)
- **"코드를 고치는" 작업** → ⚠️ 로컬 코드 프로젝트가 있으면 가능
